How This Course Will Work

イントロダクション

こんにちは、The Odin ProjectのReactコースへようこそ。このコースでは、まずReactの基礎について学び、それからより高度な概念に進んでいきます。学習の過程でプロジェクトを構築していき、それらをポートフォリオに加えて、あなたのReactスキルで採用担当者にアピールできます。

このコースを始める前に、必ずJavaScriptコースを修了しておいてください。Reactに飛び込む前に、JavaScriptについてしっかりとした理解を持っておくことがどれほど重要か、いくら強調してもし過ぎることはありません。結局のところ、Reactはまさに素のJavaScriptなので、JavaScriptを使いこなせることが、Reactプロジェクトを成功させるために最も重要なのです。

この先の道のり

すべてのレッスンは、これまでのコースで慣れ親しんできたのと同じような構成、つまりレッスンの内容の後に課題が続く、という構成に従っています。また、それらのレッスンで学ぶ概念を示すために、CodeSandboxを使ったインタラクティブな例も取り入れています。

いつものように、まず最初に伝えておきたいのは、新しい技術を学ぶことはもどかしい試みになり得るということですが、あなたならきっとやり遂げられると確信しています。「素のJavaScriptでもできるのに、なぜわざわざReactを学んでいるのだろう?」と思うときがあるかもしれませんが、それは問題ありません。レッスンを進めていくうちに、Reactがフロントエンド開発においてどれほど便利かに、すぐに気づくはずです。JavaScriptコースの、あの恐ろしいTodoリストプロジェクトを覚えていますか?Reactでは、通常、コア機能を構築するのにかかる時間はもっと短くなります。それを聞けば、わくわくしてくるはずです。このコースを終える頃には、あなたはReactの達人になっているでしょう!

それでは、Reactを始めましょう!
