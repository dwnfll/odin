Setting Up A React Environment

イントロダクション

あなたはReactが何であるかを知っており、どこでそれを使うかについてのイメージもすでに持っているかもしれません。今度は、どうやって使うのかを理解し始めるときです。

このレッスンでは、自分のマシン上で新しいReactプロジェクトを始める方法と、その過程で役立ついくつかの便利なツールについて扱います。また、発生する可能性のある問題(とその避け方)についても説明します。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • Reactプロジェクトの作成方法。
  • Viteを使って新しいReactプロジェクトを作成する方法。
  • Reactプロジェクトのコードをフォーマットする方法。
  • React Developer Toolsとは何か。

さまざまな方法

プロジェクトでReactを使い始める方法は複数あります。CDNからReactを配信する<script>タグ一式を追加する方法から、高度に設定可能で、スケーラビリティと最適化を向上させることができる、堅牢なツールチェーンやフレームワークを使う方法まで、さまざまです。

これらのツールチェーンの例には、以下のようなものがあります:

  • Vite's React Config
  • Gatsby
  • NextJS
  • Create React App (非推奨)

なぜこれらのツールチェーンが必要なのでしょうか?自分たちで好きなように作ることはできないのでしょうか?

できますが、それは大変です。Reactは複雑な代物で、たくさんの可動部分があります。機能を提供するようなコードを書き始める前に、少なくとも以下のものを設定する必要があります:

  • パッケージ管理(NPM、Yarn)
  • モジュールバンドリング(Webpack、Parcel)
  • コンパイル(Babel)
  • React自体

Reactプロジェクトと開発環境を立ち上げて動かすためには、これらすべて、そして時にはそれ以上のものが必要になります。

Create React Appについての注記

Create React App、略してCRAは、2016年の導入以来、新しいReactプロジェクトの雛形を作成するための公式な方法でした。残念ながら、さまざまな理由により、CRAは2023年初頭に非推奨になりました。CRAの人気の高さから、多くのチュートリアルやガイドでその名前を目にすることになるでしょう。しかし、新しいプロジェクトでそれを使うことはもはや推奨されていません。

プロセスを単純化する

Reactプロジェクトをゼロから始めるために何が必要かを理解したところで、実はたった一つのターミナルコマンドで始められることを知って、ほっと一息つけるはずです。私たち自身のテンプレートリポジトリを作って使うのと同じように、Vite独自のReactテンプレートを使ってプロジェクトの雛形を作成していきます。

Viteは開発者のためのフロントエンドツールを構築しており、内部では最新の技術を活用して、優れた開発者体験を提供しています。幸いなことに、Reactのエコシステムにも対応しています。ここでは、ViteのCLIを使って、テンプレートのReactプロジェクトを素早く作成します。設定はほとんど必要なく、非常に便利なツールがすぐに使える状態で用意されているため、学習そのものにすぐ取りかかることができます。それでは始めましょう!

Reactアプリを作成する

最新のLTSバージョンのNodeを使っていることを必ず確認してください。そうでないとエラーが発生する可能性があります。ターミナルと、あなたのプロジェクトが入っているフォルダを開いてください。それから、以下のコマンドを入力してください(my-first-react-appは好きな名前に置き換えてかまいません):

npm create vite@latest my-first-react-app -- --template react

create-viteパッケージをインストールするかどうか尋ねられることがあります。その場合は、yと入力してからEnterを押して、承諾してください。実験的な機能を使うかどうかについて質問された場合は、いいえと答えてかまいません。最後に、Install with npm and start now?には、はいと答えてください。

コマンドが実行されると、以下のような出力が表示されるはずです:

➜  Local:   http://localhost:5173/
➜  Network: use --host to expose
➜  press h + enter to show help

すべてが計画通りに進んでいれば、localhost:5173にアクセスすると、以下のページが表示されるはずです:

おめでとうございます!最初のReactアプリを作成しました。これで、開発サーバーを終了し(Ctrl + C)、プロジェクトディレクトリにcdで移動できます。開発サーバーは、プロジェクトディレクトリ内でいつでもnpm run devを実行することで起動できます。

ローカルのプロジェクトディレクトリをGitHubリポジトリにリンクするには、GitHub上に新しい空のリポジトリを作成し、その新しいリポジトリのページに記載されている手順に従って、ローカルのプロジェクトディレクトリと接続してください。

既存のリポジトリを使う

代わりに、すでにGitHubリポジトリを作成してクローンしている場合は、クローンしたリポジトリにcdで移動し、プロジェクト名として.を使って、上記のViteコマンドを実行することもできます:

npm create vite@latest . -- --template react

これにより、指定されたプロジェクト名で新しいディレクトリを作成する代わりに、Viteに現在のディレクトリをプロジェクトとして使うよう指示できます。このクローンされたディレクトリは、すでにgitリポジトリとして初期化されており、正しいリモートに接続されています。

さらに深く掘り下げる

新しいプロジェクトをもっと詳しく見ていきましょう。中には、いくつかのフォルダに加えて、package.json、package-lock.json、.gitignore、README.mdといったファイルがあります。README.mdには役立つ情報が含まれているので、今のうちに時間を取ってざっと目を通しておくとよいでしょう。

publicフォルダは、あなたのアプリに関連するすべての静的アセットが置かれる場所です。これには、画像、アイコン、ブラウザ用の情報ファイルなどが含まれます。

srcフォルダの中には、あなたのアプリを動かすコードがあります。ここにあるmain.jsxファイルは、アプリケーションのエントリーポイントとして機能します。main.jsxファイルを開いて、何が起こっているのか理解できるか見てみましょう:

import { StrictMode } from "react";
import { createRoot } from "react-dom/client";
import App from "./App.jsx";
import "./index.css";

createRoot(document.getElementById("root")).render(
  <StrictMode>
    <App />
  </StrictMode>,
);

うわ!ここにはかなりたくさんのことが詰まっていますね。今の時点で、この内容をあまり(あるいはまったく)理解できていなくても問題ありません。ここで何が起こっているのか、簡単に説明します:

  1. reactパッケージとreact-domパッケージから、それぞれStrictModeとcreateRootをインポートします。
  2. App.jsxからAppコンポーネントをインポートします。これにより、それをDOM内に配置(レンダー)できるようになります。
  3. いくつかのCSSスタイルをインポートします(この構文はWebpackの教材で見覚えがあるかもしれません)。
  4. index.htmlからの要素を使ってcreateRootを呼び出すことで、rootオブジェクトを作成します。
  5. rootオブジェクトに付随しているrenderメソッドを、かっこの中に非常に興味深く見える構文を入れて呼び出します。

これらはすべて、これまで見たことのないもののように見えるのも無理はありませんが、恐れないでください。このコースに時間をかければ、これらすべてが何をしているのか、そしてそれ以上のことを、きちんと理解できるようになります。

開発者ツール

Reactの学習を進めていくにつれて、あなたのプロジェクトは間違いなくどんどん大きくなり、より多くのコンポーネントを含むようになり、機能のレベルも上がっていきます。

そうなったとき、アプリ内の可動部分を追跡し(そしてライブで変更を加え)て、コードを理解しデバッグできると便利です。そのために、React Developer ToolsというChrome拡張機能を使うことができます。

効果的なReact開発にとって非常に貴重なツールなので、これをインストールし、できるだけ早く使いこなせるようになっておくことをお勧めします。

課題

  1. ViteのGetting Startedページを読んで、この教材を復習してください。
  2. このReact Developer Toolsのガイドをチェックして、使い方を学び始めてください(まだ細かい部分が理解できなくても心配いりません)。
  3. my-first-react-appプロジェクトを整理して、デフォルトのページが表示されないようにしてみてください。代わりに「Hello, World!」というメッセージを表示できるか試してみてください。
