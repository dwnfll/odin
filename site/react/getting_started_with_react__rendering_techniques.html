Rendering Techniques

イントロダクション

コンポーネント、props、JSXについて学んだので、このレッスンでは、複数の要素をレンダーする方法や、JSXでUIを条件付きでレンダーする方法について扱います。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • JSXでコンポーネントのリストをレンダーする。
  • UIを条件付きでレンダーする。

JSXで要素のリストをレンダーする

複数の動物をリストするコンポーネントを作りたいとしましょう:

function App() {
  return (
    <div>
      <h1>Animals: </h1>
      <ul>
        <li>Lion</li>
        <li>Cow</li>
        <li>Snake</li>
        <li>Lizard</li>
      </ul>
    </div>
  );
}

これはまったく問題ありませんが、もし4つ以上をレンダーしたい場合はどうでしょうか?それは面倒で長くなってしまいますし、ほとんどの場合、各動物をハードコードするのではなく、(配列のような)データ構造を扱うことになります。あなたはすでに、波かっこを使ってJSXの中に式を埋め込めることを学んでいます。それでは、まさにそれをやってみましょう:

function App() {
  const animals = ["Lion", "Cow", "Snake", "Lizard"];

  return (
    <div>
      <h1>Animals: </h1>
      <ul>
        {animals.map((animal) => {
          return <li key={animal}>{animal}</li>;
        })}
      </ul>
    </div>
  );
}

animalsという配列を定義します。次に、JSXの中でmapを使って、li要素の新しい配列を返し、そのテキストとしてanimalを追加します。これで、先ほど書いたスニペットと同じようにレンダーされるはずです。これは、JSXが配列を自動的にレンダーする機能を持っているためです。以下のコードは同じものです:

function App() {
  const animals = ["Lion", "Cow", "Snake", "Lizard"];
  const animalsList = animals.map((animal) => <li key={animal}>{animal}</li>)

  return (
    <div>
      <h1>Animals: </h1>
      <ul>
        {animalsList}
      </ul>
    </div>
  );
}

私たちの<li>要素の中にあるkeypropが何なのか、気になっているかもしれません。コンポーネントのリストを動的にレンダーする際は、トップレベルのコンポーネントにkeyを与える必要があります。これは今のところ、コンポーネントのIDのようなものだと考えてください。このレッスンでは、なぜこのkeyが必要なのか、あるいはそれがどう機能するのかを知る必要はありません。keyについては次のレッスンで詳しく見ていきます。

JSXでコンポーネントのリストをレンダーする

function ListItem(props) {
  return <li>{props.animal}</li>
}

function List(props) {
  return (
    <ul>
      {props.animals.map((animal) => {
        return <ListItem key={animal} animal={animal} />;
      })}
    </ul>
  );
}

function App() {
  const animals = ["Lion", "Cow", "Snake", "Lizard"];

  return (
    <div>
      <h1>Animals: </h1>
      <List animals={animals} />
    </div>
  );
}

私たちは<ul>要素を、Listという別のコンポーネントに移動しました。それでも<ul>要素を返していますが、独自のコンポーネントとして、それに対してもっと多くのことができるようになります。Listは、動物の配列をpropとして受け取り、それぞれの動物を個別にListItemコンポーネントへpropとして渡します。

もちろん、私たちは<li>だけに限定されているわけではありません。「リスト」と言うとき、それは非常に一般的な意味で使っています。<select>の中で複数の<option>要素を動的にレンダーすることもできますし、グリッドの一部として複数の<div>をレンダーすることもできます。

「Missing in props validation」

上の<ListItem />コンポーネントの中のanimalのように、propsの下に波線が表示されることに気づくかもしれません。

これらにカーソルを合わせると、missing in props validationと表示されます。今のところは、これは安全に無視してかまいません。これは単に、prop typesについてのデフォルトのESLintルールの警告であり、このコースの後半で扱う内容です。

eslint.config.jsファイルに以下を追加することで、このルールをオフにすることもできます:

  rules: {
    // Your other rules
    "react/prop-types": "off"
  }

UIを条件付きでレンダーする

コンポーネントの中で、いくつかの判断を行ってみましょう。もし、文字Lで始まる動物だけをレンダーしたいとしたらどうでしょうか?このような判断を行うには、何らかの条件式を使うことになります。上記のコードを引き続き使いますが、簡潔にするために<ListItem />コンポーネントは取り除くことにします。

三項演算子を使う

要素を条件付きでレンダーする一つの方法は、真偽値を使って何をレンダーするかを決める、三項演算子を使うことです:

function List(props) {
  return (
    <ul>
      {props.animals.map((animal) => {
        return animal.startsWith("L") ? <li key={animal}>{animal}</li> : null;
      })}
    </ul>
  );
}

function App() {
  const animals = ["Lion", "Cow", "Snake", "Lizard"];

  return (
    <div>
      <h1>Animals: </h1>
      <List animals={animals} />
    </div>
  );
}

文字列メソッドstartsWithを使って、animalが文字Lで始まるかどうかを確認しています。このメソッドは、trueまたはfalseのどちらかを返します。

動物が文字Lで始まる場合、私たちはその特定の動物をレンダーする<li>要素を返します。そうでない場合は、何もレンダーしないことを示すためにnullを返します。

&&演算子を使う

要素を条件付きでレンダーするもう一つの手早い方法は、&&演算子を使うことです。

function List(props) {
  return (
    <ul>
      {props.animals.map((animal) => {
        return animal.startsWith("L") && <li key={animal}>{animal}</li>;
      })}
    </ul>
  );
}

function App() {
  const animals = ["Lion", "Cow", "Snake", "Lizard"];

  return (
    <div>
      <h1>Animals: </h1>
      <List animals={animals} />
    </div>
  );
}

&&演算子を使って、startsWithの戻り値を活用します。startsWith関数の結果がtrueであれば、2番目のオペランドである<li>要素が返され、それがレンダーされます。そうでなく、条件がfalseである場合は、falseが返され、JSXはその場所に何もレンダーしません。

論理AND(&&)と数値 - よくある落とし穴

条件付きレンダリングに&&を使う際は、左側に数値を置かないようにしてください。conditional renderingについてのReactドキュメントの、&&についてのセクションにあるPitfallボックスで、これについてより詳しく説明されています。

条件付きでレンダーする他の方法

何かを条件付きでレンダーするために、if、if/else、switchを使うこともできます。

今回は、2つの条件を用意します:

  1. animalsプロパティが渡されているかを確認する
  2. animalsの長さが0より大きいかを確認する

今後、私たちは頻繁にリストを扱うことになりますが、リストが空だったり、そもそも存在しなかったりする場合に何をレンダーするかについても考える必要があります。真っ白なページなど、確かに見たくはないですよね?それを実装してみましょう:

function List(props) {
  if (!props.animals) {
    return <div>Loading...</div>;
  }

  if (props.animals.length === 0) {
    return <div>There are no animals in the list!</div>;
  }

  return (
    <ul>
      {props.animals.map((animal) => {
        return <li key={animal}>{animal}</li>;
      })}
    </ul>
  );
}

function App() {
  const animals = [];

  return (
    <div>
      <h1>Animals: </h1>
      <List animals={animals} />
    </div>
  );
}

私たちの<List />コンポーネントには、条件に基づいて即座に要素を返すガードとして機能する、2つのif文があります。

一つはanimalsプロパティが存在するかを確認するもので、もう一つはリストの長さが0より大きいかを確認するものです。この場合、私たちのリストは空なので、2つ目のif文が実行され、「There are no animals in the list」というテキストを含む<div>要素が即座に返されます。

もしanimalsプロパティを取り除くと:

function App() {
  const animals = [];

  return (
    <div>
      <h1>Animals: </h1>
      <List />
    </div>
  );
}

今度は最初のif文が実行され、「Loading...」というテキストを含む<div>が返されます。これは、APIからデータを取得しているときによくあるケースです。実際にデータを取得するのに時間がかかることがあるため、そのためのインジケーターを表示しておくのは良いプラクティスです。

これらのチェックのいずれにも該当しなかった場合、私たちはリストを正しくレンダーするために必要なデータを持っていることになります。animalsリストにアイテムを追加し、プロパティを元に戻して、実際に試してみてください。

もちろん、これは三項演算子と&&演算子だけでも実現できます。

function List(props) {
  return (
    <>
      {!props.animals ? (
        <div>Loading...</div>
      ) : props.animals.length > 0 ? (
        <ul>
          {props.animals.map((animal) => {
            return <li key={animal}>{animal}</li>;
          })}
        </ul>
      ) : (
        <div>There are no animals in the list!</div>
      )}
    </>
  );
}

// or
function List(props) {
  return (
    <>
      {!props.animals && <div>Loading...</div>}
      {props.animals && props.animals.length > 0 && (
        <ul>
          {props.animals.map((animal) => {
            return <li key={animal}>{animal}</li>;
          })}
        </ul>
      )}
      {props.animals && props.animals.length === 0 && <div>There are no animals in the list!</div>}
    </>
  );
}

function App() {
  const animals = [];

  return (
    <div>
      <h1>Animals: </h1>
      <List animals={animals} />
    </div>
  );
}

ネストした三項演算子や複数の&&演算子は、見ていて威圧的に感じられることがあるので、必ず実際に試してみてください!

課題

  1. Reactのドキュメントには、条件付きレンダリングについての素晴らしいガイドがあります。それを読み、すべての例に取り組むことで、理解を深めてください!
  2. 同じドキュメントから、Rendering Listsの記事に取り組むことで、リストで何ができるかについてさらに詳しく見ていってください。keyについての最後の部分は、次のレッスンで学ぶことになるので、心配する必要はありません。
