CV Application

イントロダクション

おめでとうございます、あなたはついに最初のReactプロジェクトにたどり着きました。このプロジェクトでは、ユーザーが自分の情報を入力し、履歴書(CV/résumé)を生成できる小さなアプリケーションを作成します。これは、大きな複雑さを伴うことなく、これまで学んできた基本的な概念の多くを含んでいるため、始めるのにぴったりのプロジェクトです。

課題

二重レンダリング

このプロジェクトに取り組んでいる際、コードの一部が2回実行される(例えば、コンソールログが2重に表示される)ことに気づくかもしれません。これはReact.StrictModeによるもので、意図された挙動です。これについては次のレッスンでさらに詳しく扱うので、今のところは心配しないでください。

  1. 新しいReactプロジェクトを作成してください。
  2. アプリケーションをどのようにコンポーネントに構造化するか考えてください。あなたのアプリケーションには、以下を含める必要があります:
    1. 名前、メールアドレス、電話番号のような一般的な情報を追加するセクション。
    2. あなたの学歴(学校名、専攻名、在学期間)を追加するセクション。
    3. あなたの職歴(会社名、役職名、仕事の主な職務内容、その会社で働いていた開始日と終了日)を追加するセクション。
  3. 各セクションごと、または履歴書全体に対して、編集ボタンと送信ボタンを必ず含めてください。送信ボタンは、フォームを送信し、入力フィールドの値をHTML要素の中に表示するようにしてください。編集ボタンは、それまで表示されていた情報を値として持つ入力フィールドを再び追加(表示)するようにしてください。それらの入力フィールドの中で、内容を編集して再送信できるようにする必要があります。stateとpropsを大いに活用することになるので、これらの概念をしっかり理解しておいてください。
  4. srcディレクトリの下にcomponentsディレクトリを作成し、あなたのコンポーネントを追加してください。
  5. CSSファイルのために、srcディレクトリの下にstylesディレクトリを含めてください。これらを使うには、コンポーネントファイルの中でインポートする必要があります。
  6. 結果をプッシュし、以下に挙げるいずれかのオプションでデプロイしてください。カリキュラムのこの時点では、あなたのプロジェクトがインターネット上に公開されている限り、どのプラットフォームを選んでも問題ありません!

Reactアプリをデプロイする

これまでは静的なウェブページをデプロイするためにGitHub Pagesを使ってきましたし、多少強引な方法を使えば今後もそうすることは間違いなく可能です。しかし、PaaS(Platform as a Service)に同じことをやってもらうほうが、はるかに簡単です!このようなサイトをホスティングするための選択肢はたくさんあり、Viteのホスティングに関するドキュメントでは、その中でも特に人気のあるものが紹介されています。

これらのサービスの中には、コードをGitHubにプッシュした後の追加のステップを取り除いてくれるものがあります。これは、これらのサービスが自動的にプッシュ時にデプロイするツールを持っているためです。それだけでなく、カリキュラムのこの先で出てくる、ルーターやビルドステップといった他の問題についても心配する必要がなくなります。今のところは、いくつか厳選したオプションを使うことにします。課題が終わったら、以下のオプションのいずれかを選んで、デプロイしましょう!

Netlify

Netlify(Netlifyドキュメント)へのデプロイ方法は、distを直接アップロードしたり、netlify-cliを使ったりと、たくさんありますが、最も便利な方法は、GitHubリポジトリを直接Netlifyにインポートすることです。

  1. あなたのReactアプリケーションをGitHubにプッシュしてください。
  2. ログインして、あなたのリポジトリを選択することで、プロジェクトをNetlifyにインポートしてください。
  3. デプロイ元にするブランチを選択し(デフォルト設定のmainからで問題ありません)、「Deploy site」を押してください!
  4. 必要であれば、ここでさらに多くの設定にアクセスできます!

Vercel

Netlifyと同様に、Vercel(Vercelドキュメント)もいくつかのデプロイ方法を提供しており、ここでもGitHubリポジトリをインポートすることで、プッシュ時のデプロイのような利点を得ることにします。

  1. 改めて、あなたのReactアプリケーションをGitHubにプッシュしてください。
  2. プロジェクトをVercelにインポートしてください。
  3. Vercelは、あなたがViteを使っていることを自動的に検出します。名前を好きなように設定し、「Deploy」を押してください!

Cloudflare Pages

Cloudflare Pages(Cloudflare Pagesドキュメント)も、他の2つのオプションと同様のプロセスと利点を持っています: GitHubリポジトリをインポートし、正しいビルドコマンドと出力ディレクトリを設定します。

  1. はい、あなたのReactアプリケーションをGitHubにプッシュしてください。
  2. プロジェクトをCloudflare Pagesにインポートしてください。アプリケーションを作成する際は、Workerではなく、必ずPagesで作成するようにしてください。
  3. 「Save and Deploy」を押して、アプリケーションが動き出す様子を見届けましょう!
