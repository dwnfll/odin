React Components

イントロダクション

このレッスンでは、Reactコンポーネントの基本、つまりコンポーネントが何をするものなのか、そしてどうやって書くのかについて見ていきます。前のレッスンでセットアップしたプロジェクトを必ず使ってください。ただし、一緒にコーディングしていく際に、コードをコピー&ペーストしないようにしてみてください。

コンポーネントとは何ですか?

Reactの素晴らしいところは、UI(ユーザーインターフェース)を、独立した再利用可能な塊、つまり私たちがコンポーネントと呼ぶものに分解できるという点です。以下の画像は、非常に基本的なアプリを構築する際に、それをどのように行うかのイメージを与えてくれるはずです。

例えば、このウェブサイトは以下のようなコンポーネントに分解できます:

  • App。これはあなたのメインアプリケーションを表し、他のすべてのコンポーネントの親になります。
  • Navbar。これはナビゲーションバーになります。
  • MainArticle。これはメインコンテンツをレンダーするコンポーネントになります。
  • NewsletterForm。これは、ユーザーが週刊ニュースレターを受け取るためにメールアドレスを入力できるフォームです。

これらの再利用可能な塊は、何らかの入力を受け取り、Reactの要素を返すことができるJavaScript関数だと考えてください。

コンポーネントの作り方

コンポーネントを扱う感覚をつかむために、関数コンポーネントを作る練習をしていきます。関数コンポーネントとは何でしょうか?JavaScriptの関数です!見てみましょう。

function Greeting() {
  return <h1>"I swear by my pretty floral bonnet, I will end you."</h1>;
}

これは、あなたにとってほぼ見覚えのあるものに見えるかもしれません。これはJavaScriptの関数で、JSXを返します。作業していたプロジェクトを開き、Greeting.jsxという名前の新しいファイルを作成し、そのファイルの中に、自分で手作りした関数コンポーネントを書いてください。名前は好きなものを付けてかまいませんし、好きなJSXを返すようにしてかまいません。

できましたか?関数の名前を確認してみてください!大文字で始まっていますか?この重要な違いを覚えておいてください。Reactコンポーネントは大文字で始める必要があります。そうしないと期待通りに機能しません。だからこそ、私たちはGreeting()を大文字で始めたのです。これについては後で詳しく説明します。

私のJavaScriptの中でHTMLは何をしているのですか?

それはJSXです。最初は違和感があるように見えますが、すぐにそれがどれほどかっこいいものかに気づくはずです。この後のレッスンで、それについてすべて学んでいきます!

コンポーネントはどこにあるのですか?

さて、私たちのコンポーネントが、自分専用のファイルの中にただ存在していたことを覚えていますか?これにより、コンポーネントはコードベースの他の部分から独立しています!とはいえ、独立していることは素晴らしいことですが、コンポーネントには、他の場所で作られた機能を使ったり、自分自身を他のコンポーネントと共有したりしてほしいものです。どうすればそれができるのでしょうか?importとexportです!React開発において、Reactコンポーネントを使うJavaScriptファイルでReactをimportすることが必要な期間が長く続きましたが、React v17.0以降はもはや必要ありません。プロジェクト全体で親コンポーネントが子として使えるように、新しく作成したコンポーネントをexportしましょう。

function Greeting() {
  return <h1>"I swear by my pretty floral bonnet, I will end you."</h1>;
}

export default Greeting;

これで終わりでしょうか?少し考えてみましょう。コンポーネントを宣言し、それをエクスポートしましたが、main.jsxはまだそれを知っているでしょうか?いいえ!それを直しましょう。main.jsxを見てみると、render()がAppコンポーネントをレンダーしていることがわかります。そのAppコンポーネントを、新しく作成したgreetingに置き換えましょう。その際、まず正しくインポートされていることを確認する必要があります。最終的な結果は、次のようになるはずです:

import { StrictMode } from "react";
import { createRoot } from "react-dom/client";
import App from "./App.jsx";
import Greeting from "./Greeting.jsx";
import "./index.css";

createRoot(document.getElementById("root")).render(
  <StrictMode>
    <Greeting />
  </StrictMode>,
);

<Greeting />は大文字で始める必要があることを忘れないでください!インポート、関数名、コンポーネントを小文字にして、何が起こるか試してみてください!JSXがパースされる際、Reactは大文字かどうかを使って、HTMLタグとReactコンポーネントのインスタンスを区別します。<greeting />は、あなたが作ったピカピカの新しいReactコンポーネントではなく、特別な意味を持たない普通のHTML要素として解釈されてしまいます。

それ以外は、これだけで、あなたは最初の自作コンポーネントのインポートと使用に成功しました。おめでとうございます!

課題

  1. さあ、新しいコンポーネントを作ってみましょう!同じプロジェクトを使いますが、いろいろ試してみて、例えば好きな食べ物のようなものを表示してみてください。
    • コンポーネントは通常デフォルトエクスポートされますが、デフォルトエクスポートの代わりに、いくつかの名前付きエクスポートを使ってみてください。やり方がよくわからない場合は、あなたの一番の友達に相談しましょう: export文についてのMDNのドキュメント
