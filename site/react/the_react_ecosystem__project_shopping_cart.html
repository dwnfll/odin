Shopping Cart

イントロダクション

ここまでで、あなたはReact初心者だった頃からずいぶん遠くまで来ました。ルーターやテストフレームワークといったツールをすでに身につけていますが、まだまだ先は長いです。今こそ、これらの概念を、定番のプロジェクトである模擬ショッピングカートで実践するのにぴったりのときです。

課題

  1. 新しいReactプロジェクトを作成してください。
  2. コンポーネントとフォルダの構造について考えてください。アプリケーションをどのようにセットアップできるでしょうか?どのようなコンポーネントや機能が必要でしょうか?これを、簡単にアクセスできて後で参照したり書き足したりできる場所にメモしておき、把握しておくのは良い考えです。
  3. ホームページ、ショップページ、カートページという3つのページを用意する必要があります。すべてのページに表示されるナビゲーションバーを使って、ユーザーがページ間を移動できるようにしてください。
  4. ホームページには、好きなものを何でも追加してかまいません!いくつかの画像や情報だけでもまったく問題ありません。凝ったものである必要はなく、これまで教わった概念を試すためのものです。
  5. ショップページでは、各商品ごとに個別のカード要素を作成してください。ユーザーが購入したい商品の数を手動で入力できる入力フィールドを表示してください。また、微調整のために、その隣に増加・減少ボタンを追加してください。各商品のタイトルと「Add To Cart」ボタンも表示できます。
  6. カートに商品が入っているときは、ナビゲーションバーのカートページへのリンクに、カート内に何個の商品があるかを表示するべきです。これは、ユーザーがカートに商品を追加したり削除したりするたびに、リアルタイムで更新されるべきです。
  7. カートページでは、商品とその数量を表示し、ユーザーがカート内の商品の数量を増減できる(適切であれば削除も含む)ようにする必要があります。チェックアウトや支払いのシステムを実装する必要はありません。
  8. FakeStore APIか、それに類似したものから、ショップの商品を取得してください。
  9. React Testing Libraryを使って、アプリを徹底的にテストするようにしてください。react-routerは外部ライブラリであり、それに取り組んでいる開発者たちがすでにそのライブラリをテストしているはずなので、react-router自体を直接テストしないよう注意してください。
  10. いつものように、見せびらかせるようにアプリケーションにスタイルを付けましょう!すでにたくさんの選択肢が用意されています。

  11. 最後に、いよいよデプロイのときです!使用しているホスティングソリューションによっては、シングルページアプリケーション(SPA)としてルーティングが正しく処理されるように、追加の設定が必要になる場合があります。

    • Netlify: プロジェクトのpublic/ディレクトリに_redirectsファイルを追加する必要があります。以下をコピーして、すべてのルートをindexページにリダイレクトし、残りはreact-routerに処理させてください。これについての詳細は、リダイレクトについてのNetlifyドキュメントで読むことができます。

      /* /index.html 200

    • Vercel: プロジェクトのルートにvercel.jsonファイルを追加し、以下の設定をコピーする必要があります。Netlifyと同様に、これによってすべてのルートがindexページにリダイレクトされ、残りはreact-routerが処理します。詳しい情報は、SPAとViteについてのVercelドキュメントで見つけることができます。

      {
  "rewrites": [
    {
      "source": "/(.*)",
      "destination": "/index.html"
    }
  ]
}

    • Cloudflare Pages: この記事の執筆時点では、NetlifyやVercelとは異なり、追加のステップは必要ありません。デフォルトの挙動により、react-routerがSPAのリダイレクトを正しく処理できるからです。これについてさらに詳しく知りたい場合は、ページの配信についてのCloudflareドキュメントを参照してください。
