Reactとは何ですか?

Reactのウェブサイトによると、Reactは「ウェブとネイティブのインターフェースのためのライブラリ」です。しかし、これをもう少し詳しく見ていきましょう。

一般的に、JavaScriptのライブラリとは、開発を簡単にするために設計された、あらかじめ書かれたコードの集まりです。このコードは、複雑なタスクを達成するために、自分自身のコードベースの中で再利用/再実装できます。

ライブラリとフレームワークは混同すべきではありませんが、これらの用語はしばしば同じ意味で使われます。ライブラリとフレームワークの違いについては、このレッスンの後半で読むことになります。

Reactは、さまざまな複雑さのユーザーインターフェースを構築できるようにする、強力なプリミティブ(組み込みの関数/モジュール)を提供します。このコースを通して、Reactが提供する機能についてすべて学び、かっこいいアプリケーションを構築できるようになります。

なぜReactを扱うのですか?

Reactは、最も強力で広く使われているJavaScriptライブラリの一つです。

フロントエンドフレームワークを取り巻く状況は、ここ数年で大きく変化しているため、「間違った」ものを選んでしまうのではないかと不安になるのも理解できます。 このJavaScriptフレームワークのライフサイクルについての記事は、フロントエンドフレームワークの最近の発展をよく示しています。

フレームワークをより深く掘り下げ始めると、それを好きになっていくはずです。フレームワークは、あなたのコードを簡単にスケーラブルにし、より読みやすくし、(私たちのささやかな見積もりでは)もしかしたら千倍も効率的にしてくれます。

Reactを学ぶ理由をいくつか挙げると:

  • コンポーネントは再利用可能です。
  • その人気と大きなコミュニティのおかげで、よくサポートされています。
  • 主張が弱い(not opinionated)ため、特定のデザインパターンやプロジェクトの構成、ロジックに従うことを強制されません。すべてあなた次第です。
  • 学習曲線が比較的緩やかです。特に、これまでのレッスンですでにJavaScript、HTML、CSSをしっかり理解しているなら、なおさらです。
