Memory Card

イントロダクション

さあ、また新しいプロジェクトです!ここまでの概念をしっかり理解できているか確認していきましょう。このプロジェクトの主な目標は、外部APIからデータを取得して利用しながら、フックを使ってstateを管理・活用することで、これまで学んできた概念を実践することです。

ゲームの仕組み

この受講生の解答例を実際に触ってみて、Memoryゲームがどのように機能するか、自分で確かめてみてください。この例ではアニメのキャラクターが使われていますが、あなたのゲームには好きなものを使ってかまいません。

課題

  1. 新しいReactプロジェクトを作成してください。
  2. 実装したい機能、必要なコンポーネント、アプリケーションの構造、そしてAPIから画像を取得する方法について、時間をかけて考えてください。あなたのアプリケーションには、現在のスコアを数えるスコアボードと、これまでに達成した最高スコアを表示する「Best Score」を含める必要があります。ユーザーがカードをクリックするたびに、カードをランダムな順序で表示する関数が必要です。この関数を、コンポーネントがマウントされたときに必ず呼び出すようにしてください。
  3. また、画像や、場合によっては説明用のテキストを表示する、いくつかのカードも必要です。これらの画像やテキストは、外部APIから取得する必要があります。GiphyからPokemon APIまで、何でも好きなものを使うことができます。
  4. アプリケーションの構造について考え終わったら、フォルダ構造をセットアップし、コンポーネントを作成し始めてください。
  5. 見せびらかせるように、アプリケーションにスタイルを付けましょう!
  6. いつものように、プロジェクトをGitHubにプッシュし、デプロイすることを忘れないでください。
