SQL Zoo

日本語訳

← databases

The best way to learn is by practice, so this project will give you plenty of opportunity to apply your new SQL powers (for good).

イントロダクション

SQL Zooは、実際に既存のテーブルに対してクエリを組み立てて実行できる、数少ないオンラインリソースの一つです。それぞれのチュートリアルでは、テーブルが示され、それに対してクエリを実行することで、特定の質問に答えていくことになります。クエリの中には、特に最初のうちは、かなり短いものもあります。終盤になると、確実により難しくなっていき、本当に頭を悩ませることになるでしょう。

課題

  1. SQL Zooにアクセスし、「Tutorial Section」に掲載されているTutorial 0から9(+/-の印が付いているものも含む)と、それぞれの最後にあるクイズに取り組んでください。最初のチュートリアルは「SELECT basics」という名前です。
    • メインページの右上にある「Engine」のドロップダウンが「MySQL」(デフォルト)になっていることを確認してください。大きな結果は途中で切り捨てられ、すべての行や列が表示されるわけではないため、「答え」が100%正しいようには見えないことがあります。
  2. 先に進む前に、あなたのフィードバックをいただきたいと思います。このSQLコースについてのフィードバックフォームにご記入ください。ユーザー(あなた)からのフィードバックを得ることは、カリキュラムを改善し続け、あなたの体験について知るために重要です。
