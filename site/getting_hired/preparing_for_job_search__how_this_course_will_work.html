How This Course Will Work

This course is a bit different than the others so it's worth getting acquainted with how it will work.

イントロダクション

あなたはこれまで長い間、このウェブ開発というものを理解しようと奮闘し、アプリを構築してきました。そしていよいよ、誰かのために働きながら、学び続けることに対してお金をもらう時が来ました。

あなたには間違いなく仕事を得る能力がありますが、それを見つけるのが簡単なことは滅多にありません。自分が何を望んでいて、何を提供できるかについて、自分自身に正直になる必要がありますし、ここまであなたを導いてきたのと同じ厳格さと構造をもって、採用されるという課題に取り組む必要があります。

これは、他の何ごとにも劣らず一種の確率のゲームであり、特に過去の経験によって自分を「証明」できていない、初めての就業者にとってはそうです。つまり、その道のりでは相応の割合で不採用を経験することになりますが、それは誰もが経験することです。あなたはただ、毎日応募を送り続け、自分を世に出し続けながら、自分をより強い候補者にするために、スキルとポートフォリオを築き続ける必要があるだけです。

このコースは、計画もなくただプロセスに飛び込んでしまうことのいくつかの落とし穴を避ける助けとなるはずの、構造化された道筋を示していきます。まずこのコースを一度最初から最後まで読み通し、それから、プロセスを進めていく中で、それを一歩ずつ使っていってください。幸運を祈ります、頑張ってください!

形式

このコースは、特定のスキルを学んだり特定のプロジェクトを構築したりすることよりも、あなたが実際に世に出ていくことがはるかに重要であるため、他のコースとは少し異なる形で構成されています。取り組むよう求められるプロジェクトもいくつかありますが、ここでの構成のほとんどは、あなたの就職活動のプロセスの骨組みとして存在しています。

それぞれのレッスンでは

  1. トピックを紹介し、あなたの全体的な就職活動の中でのその文脈を提供します。
  2. 読み物を読んだり、動画を見たり、オンラインコースを受講したり、その他あなたを助けてくれるコンテンツに触れたりするよう求められます。
  3. しばしば、特定のタスクを行うよう求められます。例えば、あなたが提出した応募を記録しておく、といったことです。これは純粋に、その過程であなたを助けるためのものです。
  4. 最後に、それぞれのレッスンの終わりに、追加の役立つリソースや、他の潜在的に有用な小ネタを含めます。

もう十分話しました、採用されに行きましょう!
