Create a fully responsive homepage.

イントロダクション

あなたの最後のHTML/CSSプロジェクトとして、ポートフォリオサイトのようなもので見かけるかもしれない、レスポンシブなホームページを作成していきます。あなたの作品を共有したり、仕事に応募したりし始めたいと思う段階になったとき、共有できるよくデザインされたポートフォリオを持っていることは役立ちます。まだそれを作ることはしませんが、まずはこれらのより高度なHTMLとCSSの概念を練習しておきたいところなので、これをそれらを練習する機会だと捉えてください!

以前のプロジェクトであるランディングページや管理ダッシュボードと同様に、あなたには与えられたデザインブリーフに沿って構築するという課題が課されます。私たちは、デスクトップ、タブレット、モバイルという3つの異なるサイズで、完全なデザインを提供します。それぞれのビューポートについて、そのデザインをできるだけ忠実に再現し、320ピクセルから1,920ピクセル幅までの間のどんな画面サイズでも、あなたのレイアウトが見栄え良く見えることを確認してください。

好きなフォントや色を選んで構いませんし、ヘッダーにはストックフォト以外の何かを使っても構いません。主な焦点は、完全なポートフォリオを作ることよりも、指定されたレイアウトとレスポンシブな挙動を達成することにあります。

課題

ステップ1: セットアップと計画

  1. すべてが正しくリンクされていることを確認するためだけに、ダミーコンテンツでHTMLとCSSファイルをセットアップしてください。
  2. デザインファイルのフル解像度版(デスクトップのデザインファイル、タブレットのデザインファイル、モバイルのデザインファイル)をダウンロードし、HTMLドキュメントでどのようにレイアウトする必要があるかについて大まかなイメージをつかんでください。

ステップ2: アセットを集める

  1. デザインファイルで使用している人物写真は、pexels.comからダウンロードしたストックフォトです。もし手元に自分自身の写真がなければ、遠慮なく今のところはプレースホルダーを使ってください。
  2. フォントを選んでください!私たちはデザインでPlayfair DisplayとRobotoを使っており、どちらもGoogle Fontsで利用できます。
  3. デザインには、GitHub、LinkedIn、X(旧Twitter)へのアイコンリンクがあります。もちろん、あなた自身のサイトには好きなリンクを自由に追加して構いません。私たちはそれらのアイコンをhttps://devicon.dev/から入手しました。
  4. その他のアイコン(電話、メール、外部リンク)は、https://materialdesignicons.com/からSVGとしてダウンロードしました。

ステップ3: いくつかのヒント!

  1. ご想像の通り、このプロジェクトでの作業は好きなように整理して構いません。過去のいくつかのレッスンで多くのヒントを提供してきたので、おそらくすでに何もないページから始めることに慣れていることでしょう。
  2. 何をすべきか指示してもらいたい場合: このレッスンの著者は、レイアウトのより大きなセクションから始め、それからページの上から下へと作業していくのが最も心地よいと感じています。言い換えれば、多くの特定のスタイルやコンテンツの詳細を無視しながら、さまざまなセクション(ヘッダー、プロジェクト、連絡先など)を大まかに正しい場所に配置し、それから上から下まで戻って、埋めていき、スタイリングし、すべてをきれいに整えていくということです。
  3. このプロジェクトのレスポンシブ性をいつ、どうやって達成するかは、320ピクセルから1,920ピクセル幅までのビューポートでレイアウトが崩れない限り、問題ではありません。常にモバイル体験から始め、それからメディアクエリを使ってレイアウトをどう拡張するか指示すべきだと言う人もいます。「モバイルファースト」派には確かに良い主張があります(ググってみてください!)が、結局のところ、それが機能する限り、どうやって達成するかは重要ではありません。頑張ってください!
  4. 終わったら、GitHubにプッシュして、GitHub Pagesを使って世界に公開するのを忘れないでください!ここで成し遂げたことを誇りに思うべきです!

ステップ4: フィードバックをお寄せください

  1. 先に進む前に、Advanced HTML and CSSコースについてのフィードバックを送っていただけると嬉しいです。ユーザー(あなた)からのフィードバックを得ることは、カリキュラムを改善し続け、あなたの体験がどんなものだったかを知るために重要です。
