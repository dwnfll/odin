Transforms

日本語訳

← advanced_html_css

Before we get into animations, we need to learn about manipulating elements with CSS transforms.

イントロダクション

transformプロパティは、通常のドキュメントフローに影響を与えることなく、要素の見た目を変更するための強力なツールです。

あなたはおそらく、お気に入りのウェブサイトの多くでこれが実際に使われているのを見たことがあるでしょう!Transformはアニメーション効果によく使われます。あなたが自分自身で洗練されたアニメーションを作りたくなるだろうと確信していますが、まずはtransformがどう機能するかを理解する必要があります。

transformの基本

transformプロパティは、値として1つ以上のCSS transform関数を取り、それらの関数はそれぞれ独自の値、通常は角度や数値を取ります。

ほとんどすべての要素にtransformプロパティを適用できますが、例外は<col>、<colgroup>、そして非置換インライン要素です。「非置換(non-replaced)」とは、コンテンツがHTMLドキュメントの中に含まれている要素(例えば<span>、<b>、<em>)を指し、「置換(replaced)」要素のコンテンツがドキュメントの外に含まれていて、要素自体が外部のコンテンツによって「置換」される(例えば<video>、<iframe>、<img>)のとは対照的です。非置換であるすべての要素を暗記する必要はありませんが、transformプロパティをある要素に適用しようとしてなぜ機能しないのか分からないときのために、この知識を心に留めておいてください。

複数のtransformを連結する

2D transformの理解が深まったところで、それらを連結する方法を学びましょう。複数のtransformを連結するには、それぞれの間にスペースを入れながら、さらに多くのtransform関数を追加していきます。以下のコードを見てみてください:

<div class="red-box"></div>
<div class="blue-box"></div>
.red-box,
.blue-box {
  position: absolute;
  width: 100px;
  height: 100px;
}

.red-box {
  background: red;
  transform: rotate(45deg) translate(200%);
}

.blue-box {
  background: blue;
  transform: translate(200%) rotate(45deg);
}

同じ位置に配置された2つのボックスがあります。両方のボックスにrotateとtranslate関数の値を連結しましたが、異なる順序でです。それぞれのボックスに何が起こるか予想してから、下のCodepenの「Result」リンクをクリックして、あなたの予想が正しかったか確認してください。

See the Pen Chaining | CSS Transform by TheOdinProject (@TheOdinProjectExamples) on CodePen.

もし正しく予想できたなら、おめでとうございます!青いボックスはX軸方向に200%移動し、まっすぐ右に動いてから、その場で45度回転します。赤いボックスは先に45度回転してから、回転した後のX軸方向に200%移動し、右下に動きます。

一般的に、さまざまな結果を得るために複数のtransformを好きな順序で連結できますが、一つ例外があります: perspectiveです。これは、次のperspectiveが関わるセクションへとうまくつながっていきます。

3次元transform

rotate、scale、translateのtransform関数は、2D平面だけに限定されているわけではありません。これらは3D平面でも機能します!しかし、これらの値の一部で3D効果を知覚するためには、perspectiveが必要です。

ここから先は、例がより複雑になっていきます。これらのプロパティを自由にいろいろ試してみて構いませんが、あまり深入りしすぎないよう気をつけてください。

Perspective

これは、z = 0の平面からユーザーまでの距離を設定するためのtransform関数の値です:

.element {
  transform: perspective();
}

基本的に、perspectiveの値を設定することで、z軸上のある特定の距離から見ているかのようにオブジェクトを描画するよう指示しています。

他のtransform関数の値とは異なり、複数のtransform関数の値がある場合、perspectiveは最初に(一番左に)宣言される必要があります。これから見ていくrotate、scale、translateの例で、これが対象の要素にどう影響するかを見ることができます。

これらは、3D空間で要素を移動させるための追加のtransform関数の値です:

Matrix

厳密には3D transform関数ではありませんが、どれほどまれにしか使われないかという理由から、このレッスンの最後に触れておきます。これがそのtransform関数の値です。

.element {
  transform: matrix();
  transform: matrix3d();
}

Matrixは、すべてのtransform関数を一つにまとめる方法です。可読性が低いためめったに使われず、手で書かれることはほぼありません。非常に複雑なtransformを適用する必要がない限り、代わりに他のtransform関数の値を使うべきです。

これらの関数が存在するということと、大まかにどう機能するかを知っておくだけで十分です。しかし、それらを使って構築することに慣れている必要はありません。

transformの利点

transformプロパティが優れている理由を理解するには、CSSトリガーについて知っておく必要があります。これについては、GoogleのWeb FundamentalsのThe Pixel Pipelineセクションで学ぶことができます。

transformを使う主な利点は、それが合成(composition)の間に発生するということです。これにより、他の多くのCSSプロパティと比べて、使用コストが低くなります。それぞれのCSSプロパティでどのトリガーが実行されるかは、このCSSトリガーの一覧表で見ることができます。

transformのもう一つの利点は、デバイスのGPUを介してハードウェアアクセラレーションできることです(GPUがどう機能するかを理解する必要はありませんが、この用語とその意味を知っておくのは良いことです)。この利点は、次のレッスンで学ぶことになるtransitionやアニメーションに関して、より顕著になります。
