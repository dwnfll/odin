Natural Responsiveness

日本語訳

← advanced_html_css

Learn the importance of making your sites naturally responsive.

イントロダクション

レスポンシブなウェブサイトを作るための最初のステップは、自然に柔軟なテクニックを使うことです。後のレッスンでは、画面サイズに基づいてページ上のアイテムを完全に並べ替える方法を学びますが、ほとんどの場合、まずはflexboxやgridのようなツールに頼って、幅広い画面でページが機能するようにする方が望ましいです。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • あなたのサイトを自然にレスポンシブに保つためのいくつかのコツを学びます。

すべてにCSSが必要なわけではない

CSSのないプレーンなHTMLはレスポンシブです。このCSSのないHTMLのみのページを訪れて、ブラウザを携帯電話のサイズまで縮小してみてください。完璧に機能します!Apple Watchでもそのサイトを読むことができるでしょう。

あなたが作るすべてのウェブサイトが、ページ上のプレーンなテキストほどシンプルであるのは現実的ではありませんが、あなたがCSSでそれを変えるまでは、プロジェクトを構築するために使っている要素のほとんどがレスポンシブであるということを心に留めておくことは重要です。このマインドセットでプロジェクトに取り組み、その自然なレスポンシブ性を維持するよう最善を尽くせば、サイトを適切にレスポンシブにするために必要な追加作業がそれほど多くないと気づくかもしれません。

このレッスンの残りは、自然なレスポンシブ性を維持するために使えるコツのリストです。

viewport metaタグ

携帯電話が初めてウェブブラウザを搭載し始めた頃、ほとんどのウェブサイトはそのような小さな画面解像度に最適化されていませんでした。これを回避するために、ほとんどの携帯電話のブラウザは、より大きな画面をシミュレートし、ページのズームアウトされたバージョンを表示していました。しかし、最近ではその挙動はほとんど望まれないため、私たちのウェブサイトを実際の非ズーム状態の画面解像度で見てもらいたいということを指定する必要があります。

このため、取り組むほぼすべてのプロジェクトで、HTMLファイルの<head>にこの断片を追加すべきです。

<meta name="viewport" content="width=device-width, initial-scale=1">

これは、ウェブページの初期の幅を、実際にあなたがそれを見ている画面のサイズに設定し、拡大・縮小しないよう指示します。簡単ですね!

もしEmmetを使ってHTMLボイラープレートを生成させてきたなら、おそらくすでにこのタグを使ってきたはずです。(! + ENTER)

固定の幅と高さを避ける

柔軟性の最大の敵は、要素に対する固定の幅です。もし何かにwidth: 600pxを設定すると、それはその幅より小さくなることは決してできなくなり、それをほとんどの携帯電話の画面に収まるようにするチャンスが台無しになります。同様に、要素に固定の高さをくっつけると、その要素の中身がスペース不足になった場合に問題が発生する可能性があります。

もちろん、どんな状況で何がうまくいくかは文脈によりますが、多くの場合の簡単な修正方法は、widthやheightをmax-widthやmin-heightに置き換えることです(min-widthとmax-heightも有効で、文脈によっては役立つかもしれません)。

以下の例では、固定の幅が私たちのdivを画面からはみ出させてしまっていることに注目してください!これをmax-widthに変えてみて、プレビュー画面に収まるように縮小されるのを見てみてください!「Fork on CodePen」をクリックし、それから「Save」をクリックして、下部にある「Open Live View in a New Window」アイコンに移動して、フルウィンドウサイズで見てみてください。ウィンドウのサイズを変えて、max-widthがどう機能するか試してみてください。max-widthが定義されている場合、要素はその幅を超えることはありませんが、それに収まるには画面が狭すぎる場合は縮小します。

See the Pen max-width | CSS Responsiveness by TheOdinProject (@TheOdinProjectExamples) on CodePen.

以下に示す例は、静的な高さの問題を示しています。フルサイズの画面では、テキストはピンクのボックス内にちゃんと収まりますが、この窮屈な埋め込みでは、はみ出してしまいます!ここで望んでいるのは、divがほとんどの場合は300pxであってほしいが、テキストが窮屈になったときにはみ出しを引き起こす代わりに大きくなってほしい、ということです。この場合、height: 300pxをmin-height: 300pxに変えることで、この問題が修正されます。

高さの指定を完全に避ける

ほとんどの場合、高さの設定は完全に避けるべきです。このルールにはいくつか例外があります(おそらくヘッダーやフッターなど)が、コンテンツの周りのスペースを増やすには、marginとpaddingを使う方を優先すべきです。marginとpaddingを使うことで、中のコンテンツが何をしていようとも、要素を柔軟に保つことができます。

固定の幅が適切な場合

固定の幅が適切な場合もあります。普遍的なルールを作るのは難しいですが、一般的には、幅が小さいほど、それを固定にすることがより許容されやすくなります。例えば、ページ上の32pxのアイコンは、max-widthを使うことから恩恵を受けることはないでしょう。なぜなら、おそらくそれが縮小することを望まないからです。同様に、250pxのサイドバーはおそらく常に250pxである必要があります。何事もそうであるように、選択肢を検討し、最も適切だと思われるものを選ぶ必要があります。

flexとgridを使う

これは、冗談のように聞こえるほど明白な発言です: flexboxは柔軟なレイアウトの作成を可能にするために作られました。flexとgridを使うことは、必ずしも完璧なレスポンシブ性を保証するわけではありませんが、それらは本当に役立つツールです。あなたはすでにここでの関連するプロパティについて学びましたが、flex-wrapやgridのminmax、auto-fillなどのプロパティを使うと、それほど余計な作業をすることなく、驚くほどレスポンシブなレイアウトを作ることができます。
