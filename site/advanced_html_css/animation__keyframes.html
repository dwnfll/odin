More flexible than transitions are Keyframes

イントロダクション

それでは、keyframesを使ったCSSアニメーションを探っていきましょう。これは、あなたがすでに触れたCSS transitionの知識を拡張し、両者の違いを深く掘り下げるものです。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • CSS transitionとCSSアニメーションの違い。
  • アニメーションのサブプロパティを設定する方法。
  • keyframesを使ってアニメーションの順序を組み立てる方法。

アニメーションとtransitionの比較

アニメーションを使うと、要素をあるスタイル構成から別のスタイル構成へとアニメーションさせることができます。これは聞き覚えがありますか?「transitionと基本的に同じなら、アニメーションを学ぶ意味は何なのか?」と思ってもおかしくありませんが、アニメーションはtransitionにはないいくつかの機能を大きく拡張しています。いくつかの違いを挙げると:

  • transitionは、ある状態から別の状態へと要素をアニメーションさせるために設計されました。ループさせることもできますが、そのために設計されたわけではありません。一方でアニメーションは、明示的にループを可能にするという目的をもって設計されました。

  • transitionには、:hoverや:focusのような疑似クラスの使用や、JavaScriptを使ったクラスの追加・削除といった、トリガーが必要です。一方でアニメーションには、そのようなトリガーは必要ありません。要素を配置してCSSを定義すれば、そう指定した場合はアニメーションはすぐに実行され始めます。

  • transitionは、アニメーションを使うほど柔軟ではありません。transitionを定義するとき、それはその要素をポイントAからポイントBへと一直線の旅に送り出しているようなものだと想像してください。確かにtransition-timing-functionは、この変化のタイミングに多少のバリエーションを加えることができますが、アニメーションを使うことで加わる柔軟性の量には及びません。

結局のところ、アニメーションとtransitionにはどちらもそれぞれの使いどころがあるので、上記の違いを考慮することに加えて、あなた自身の最善の判断も使うべきです。例えば、要素がアクティブになったときに不透明度を変える必要があるだけなら、アニメーションはやり過ぎですが、もっと複雑なことを行う必要があるなら、アニメーションが必要なツールを提供してくれます。

アニメーションのプロパティ

私たちがここまで話してきたことを実際に見るために、あるアニメーションを見てみましょう。

See the Pen keyframes 1 longhand by TheOdinProject (@TheOdinProjectExamples) on CodePen.

このアニメーションがすでに実行されていて、繰り返し続けていることに注目してください。例の下部にある@keyframesルールについては後ほど扱うので、今のところは上記の例で使われている実際のアニメーションプロパティに注目してください:

#ball {
  /* ... other CSS properties ... */
  animation-duration: 2s;
  animation-name: change-color;
  animation-iteration-count: infinite;
  animation-direction: alternate;
}

これは設定段階として知られており、#ball要素にアニメーションプロパティを定義していますが、これはアニメーションの定義の前半部分にすぎません。この例では、次のようになっています:

  • animation-durationは2秒です。これは、#ball要素が一つのアニメーションサイクルを完了するのに2秒かかることを意味します。

  • animation-nameを「change-color」と定義しました。これは、次に出てくる@keyframesセクションにとって不可欠です。これは特定のCSSの値ではない、単なるカスタムの名前です。望むなら「pineapples」と呼ぶこともできましたが、私たちの目的には「change-color」がよく合っています。

  • animation-iteration-countをinfiniteに設定しました。これは、このアニメーションが永遠に実行され続けることを意味します。これを1、2、あるいは好きなだけの反復回数に設定することもできます。

  • animation-directionをalternateに設定しました。このプロパティは、一つのサイクルが完了したときにアニメーションの方向を交互に入れ替えるべきか、それとも開始地点にリセットして繰り返すべきかを決めます。ここでは、#ballが元の色に直接「ジャンプ」して戻る代わりに、滑らかに元の色に戻ることを意味します。

Keyframes

さて、@keyframesアットルールを探ることで、私たちのアニメーション定義の後半部分に取り組む時が来ました。

@keyframes change-color {
  from {
    background-color: red;
  }

  to {
    background-color: green;
  }
}

@keyframesアットルールは、先ほど定義した「change-color」という名前を参照します。それから、fromとtoプロパティを使って、#ballのbackground-colorを赤から緑に変化させます。

keyframesは、アニメーションが発生する時間をパーセンテージで示すこと、そしてfromとtoという記述は、実はそれぞれ0%と100%のエイリアスであるということを知っておくことが重要です。上記の例では、animation-durationに従って、from/0%は「0秒の時点で」、to/100%は「2秒の時点で」を意味すると読むことができます。from/toを使うべきか0%/100%を使うべきかについて、厳格なルールはありません。ただ一つのスタイルを選んで、それに一貫性を持たせてください。

@keyframesアットルールはまた、一つのアニメーションサイクルも定義します。ですので、もし先ほどのanimation-iteration-countを2に変更したとすると、ボールはbackground-colorを赤から緑に、それから緑から赤に変化させ、それからアニメーションが停止します。一つの反復を完全なループだと考えるのではなく、始まりから終わりまでの(あるいは方向が入れ替わっているときは終わりから始まりまでの)単一のサイクルだと考えるように気をつけてください。

さて、アニメーションプロパティのショートハンド記法を紹介し、keyframes記法によって加わる柔軟性を少し垣間見てみましょう。以下のライブ例を見てから、その記法を見てみてください。

See the Pen keyframes 2 shorthand by TheOdinProject (@TheOdinProjectExamples) on CodePen. 

#ball {
  /* ... other CSS properties ... */
  background-color: red;
  animation: 2s change-color infinite alternate;
}

@keyframes change-color {
  from {
    background-color: red;
  }

  50% {
    transform: scale(2);
    background-color: blue;
  }

  to {
    background-color: green;
  }
}

ここでは、animation-durationが50%、つまり1秒の時点のための別のkeyframeを追加しました。これは、background-colorが追加の値に変化することに加えて、ボールが2倍の大きさになることも指定したことを意味します。追加のkeyframeは常にパーセンテージで定義されることに注意してください。0%/100%の値だけがfrom/toのエイリアスを使うことができます。

これで、要素のプロパティのアニメーションをコントロールすることに関して@keyframes構文が提供してくれる力を、少し垣間見ることができたと思います。好きなときにkeyframesを追加でき、好きなCSSアニメーション可能なプロパティをコントロールでき、あなたのウェブサイトの要素に本当に創造的な華やかさを加える力を持つことができます。
