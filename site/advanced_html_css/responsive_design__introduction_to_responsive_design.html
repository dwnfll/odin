イントロダクション

「レスポンシブデザイン」は、ウェブ向けに開発する際に非常に重要な概念です。多くの点で、あなたはすでに美しいレスポンシブなウェブサイトを作るための準備ができています。このセクションでは、その隙間を埋めていきます。

用語

「レスポンシブデザイン」とは、どんなデバイスでも動作するものを作るために、ブラウザのサイズの変化に反応(respond)するウェブサイトを作ることを表すために使われる用語です。残念ながら、この言葉は「デザイン(design)」という単語のせいで、少し誤解を招きやすいものになっています。これらのレッスンは、レスポンシブなウェブサイトの実際のデザインにはあまり焦点を当てず、ウェブサイトにレスポンシブ性を実装するために使えるテクニックに焦点を当てていきます。

「デザイン」という単語は、どんな種類のものが見栄え良いかについての決定を下すこと、ユーザー体験を作り上げること、プロジェクトが正確にどう見えるべきかを決めることを指します。これらのレッスンの随所に、そのことについての小さな話がいくらか散りばめられているかもしれませんが、それが主な焦点ではありません。しかし、このフレーズはほぼ普遍的に採用されているため、ここでもそのフレーズを使っていきます。

では、それは何なのか?

2007年に最初のiPhoneがリリースされて以来、あなたのウェブプロジェクトが、通常のデスクトップモニターから小さな携帯電話の画面まで、あらゆるもので正しく機能することが必須になりました。

あなたもおそらく気づいているように、この種のレスポンシブ性は自動的に実現されることはあまりありません。特に、プロジェクトがページ上の単純なテキストよりも複雑になってくるとなおさらです(あなたの最初のHTMLのみのレシピプロジェクトは、画像が切れてしまう以外は、おそらく携帯電話でもちゃんと動作したことでしょう)。ですので、突き詰めれば、「レスポンシブウェブデザイン」とは、どんなサイズの画面でもあなたのサイトが動作するようにするために使える一連のテクニックのことです。

デザインをほとんどの画面でうまく機能するくらい十分に柔軟にする方法もあれば、特定のサイズでページのレイアウトを劇的に変える方法もあります。おそらく、ほとんどのプロジェクトで両方に頼ることになるでしょう。

どの画面サイズをサポートすべきか?

一般的に流通している最も小さな携帯電話は、320pxより小さくなることはめったにないので、それが信頼できる下限の目標として機能するはずです。もしあなたのウェブサイトが幅320pxまで低くても動作するなら、どんな小さなデバイスでも動作するはずです。上限を明確にするのは少し難しいです。最近では、超々ワイドなモニターも珍しくないので、あなたのサイトがとんでもなく幅の広いモニターで見られる可能性も計画に入れておくべきです。これはしばしば、すべてのコンテンツに最大幅を設定し、それをページ上で中央揃えにすることで実現されます。そのようなセットアップにすれば、あなたのコンテンツは超ワイドな解像度でも見栄え良く見えるはずです。
