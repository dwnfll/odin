Accessibility Auditing 日本語訳

Learn how to audit your own sites to check for and correct accessibility issues.

イントロダクション

これで、あなたのウェブサイトを多くのユーザーにとってよりアクセシブルにするために必要な知識を身につけましたが、ここで疑問が生じます: a11y機能が正しく実装されていることをどう確認できるでしょうか?修正すべき間違いや、改善できる可能性のある点はあるでしょうか?このレッスンでは、あなたのa11yスキルをさらに一段上へと押し上げる助けとなるよう、これらの質問に答えていきます。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • ブラウザのDevTools内でアクセシビリティセクションを開きます。
  • サードパーティの監査ツールを使ってウェブページを監査します。

アクセシビリティDevTools

ブラウザのDevToolsを使うことは、ページに適用されているスタイルを確認することからコードのデバッグまで、さまざまなことに非常に役立ちますが、それはあなたもすでにご存知でしょう!ここで、あなたが知らないかもしれないことがあります: DevToolsを使って、さまざまなアクセシビリティ機能を確認することもできるのです。これは、いわば「簡易監査」として非常に役立ちます。コントラスト比を確認したり(前のレッスンで触れたように)、さまざまなアクセシビリティプロパティを見たり、アクセシビリティツリーを見たりすることが、いくつかできる機能として挙げられます。

アクセシビリティ監査

ウェブページのアクセシビリティを監査するためのサードパーティツールはたくさんあり、それぞれに独自の長所と短所があります。ここでは、それらのツールのうち3つだけを紹介します。ウェブページを監査する習慣を身につけることで、見落としていたかもしれない未解決のa11yの問題を突き止められるようになります。これらのツールのいずれかを使うことに決めても、あなたが好む他の監査ツールを使うことに決めても、今のところは、カリキュラムのこの部分で紹介された概念に関連する問題を修正することだけに焦点を当てるべきです。

  • axe DevTools for Chromeは、拡張機能ベースのツールで、重大度レベルごとにランク付けされた問題のリストを返し、手動で確認すべき問題があれば知らせてくれます。

  • Lighthouse for ChromeはデフォルトでChromeのDevToolsで利用可能です(Auditingタブとして表示されている場合もあります)。あるいはコマンドラインから実行することもできます。Lighthouseは、a11yの監査だけでなく、パフォーマンス、ベストプラクティス、検索エンジン最適化(SEO)、該当する場合はプログレッシブウェブアプリ(PWA)についても提供してくれます。問題はカテゴリごとに分かれており、axe DevToolsと同様に、手動で確認すべき問題のリストがある場合があります。

  • WebAIMのWAVEは、監査したいページのURLを入力する、ウェブサイトベースのツールです。ブラウザ拡張機能やAPIのオプションもあります。WAVEは、ページのプレビューにアイコンのオーバーレイを重ねたものを返し、問題はアラート、警告、コントラストエラーというカテゴリに分けられます。残念ながら、ページに配置されるアイコンがレイアウトを崩してしまうことがありますが、発見されたa11yの問題により集中したいのであれば、それは小さな問題かもしれません。

もちろん、あなたのウェブサイトのアクセシビリティを確認する最良の方法の一つは、これらのアクセシビリティ機能に頼っているユーザーからフィードバックを得ることです。これは必ずしも簡単な選択肢ではありませんが、あなたのサイトのアクセシビリティ(あるいはその欠如)によって影響を受けるかもしれない人々の声に耳を傾ける価値はあります。

課題

  1. 以下のリソースを読んでください:
    • アクセシビリティ機能のリファレンスは、Accessibilityタブのセクションから始まり、ChromeのDevTools内のアクセシビリティ機能の簡単な概要を提供してくれます。
    • Chrome 83のアップデートページからの視覚障がいをエミュレートするセクション。
    • Issuesタブを開くセクション。このページでアクセシビリティに関連しない言及はすべて無視して構いません。ここでは、DevToolsでこのタブを開く方法を知ってもらうことだけが目的だからです。それができるようになれば、他に発見された問題に加えて、a11yの問題も見られるようになります。
    • ブラウザによって(roleプロパティの値やa11yプロパティの表示方法など)違いはありますが、MDNのドキュメントの「Features of the Accessibility panel」セクションをチェックしてみてください。よりFirefox向けの内容ではありますが、Chromeユーザーにとっても依然として役立つ有用な情報があります。
