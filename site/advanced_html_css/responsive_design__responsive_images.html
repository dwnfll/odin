Responsive Images

日本語訳

← advanced_html_css

Some tricks relating specifically to making Images responsive.

イントロダクション

レスポンシブなウェブサイトでは、画像に特別な配慮が必要です。このレッスンでは、レスポンシブな画像を扱う際に発生するいくつかの問題と、それらに対処する際に利用できる選択肢を紹介します。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • CSSで画像をリサイズする際に、それらを適切に振る舞わせる方法を学びます。
  • 画面サイズに基づいて異なる画像を提供する方法を学びます。

基本

レスポンシブな画像を扱う際に直面する最も基本的な問題は、アスペクト比、つまり幅と高さの関係です。小さな画面で画像の幅を縮小し、高さを操作しない場合、画像は歪んで表示されてしまいます!

この問題への解決策は非常に簡単で、前のレッスンですでに触れました: 幅と高さの両方を定義しないことです。画像に柔軟な幅を与え、高さをautoに設定すれば、そのアスペクト比は正しく保たれるはずです。

background-size、background-position、object-fit

もし画像を(高さと幅の両方において)縮小させたくない場合はどうすればよいでしょうか?background-sizeとobject-fitは、アスペクト比の扱いについてもう少し柔軟性(ダジャレのつもりです)を提供してくれる2つのプロパティです。

background-positionとbackground-sizeは、背景画像を持つ要素に対して機能するプロパティであり、通常のimgタグに対しては機能しません。後の課題の読み物でいくつかの例と詳細を見ることになりますが、これらのプロパティを扱うことで、背景画像の表示と配置について、かなり多くのコントロールを得ることができます。例えば、background-position: centerは、たとえコンテナが画像全体を収めるには小さすぎる場合でも、画像が常にそのコンテナ内で中央に配置されるようにしてくれます。background-size: coverは、画像が常にそのコンテナを完全に埋め尽くすようにしつつ、できるだけトリミングを少なくするように画像をリサイズします。

object-fitも同じように機能しますが、imgタグ向けのものです。object-fitプロパティを使うと、画像に幅と高さを指定した上で、その画像がどのようにその寸法に自身を収めるべきかを指示することができます。object-fitのデフォルト値はfillで、これは画像をその寸法に合わせて引き伸ばしますが、background-sizeと同様に、画像をcoverやcontainするよう指示することもできます。

さらなるコントロール!

画面サイズによって文字通り異なる画像を使うことも可能です。これにより、さまざまな解像度で画像が正確にどう表示されるかについて、最大限のコントロールが得られます。例えば、object-fitに頼って写真の被写体を枠内に収め続けるだけでなく、小さな画面ではトリミングされたバージョンを表示することもできます。これを実現する方法は2つありますが、最も柔軟なのは<picture>タグを使うことです。これについては課題でさらに詳しく学びます。

課題

  1. まず、background-size、background-position、object-fitのドキュメントをチェックしてみてください。それらのページにあるデモが、使い方を明確にしてくれるはずです。
  2. MDNのResponsive Imagesは、HTMLでレスポンシブな画像を提供することについての導入です。
  3. CSS TricksのGuide to the Responsive Images Syntax in HTMLは、レスポンシブな画像を実際にどう実装するかについて、より深く掘り下げてくれる素晴らしい記事です。
