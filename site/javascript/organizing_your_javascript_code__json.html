JSON

イントロダクション

JSON(JavaScript Object Notation)は、データを構造化するための標準化されたフォーマットです。これは、JavaScriptオブジェクトの構文に大きく基づいています。外部サーバーやAPIを扱う際、JSON形式のデータによく出会うことになります - これは基本的に、ウェブ上でデータを送信するための普遍的なフォーマットです。

幸いなことに、ここで学ぶべきことはあまり多くありません。一部のフォーマットルールは、それを知らないと混乱を招く可能性があるため、これについてのレッスンを含めているだけです。以下のリソースに10〜15分ほど目を通せば、準備万端です。
