Linked Lists

日本語訳

← javascript

Build one of the most fundamental data structures.

イントロダクション

コンピューターサイエンスにおいて、最も基本的で重要なデータ構造の一つが連結リスト(linked list)であり、配列と似たような働きをします。従来の配列に対する連結リストの主な利点は、他の要素を再配置することなく、リストの要素を簡単に挿入したり削除したりできることです。

一部のプログラミング言語では配列のサイズが問題になり、その問題を克服して動的に確保されるデータを扱えるようにする方法の一つが、連結リストを使うことです。

幸いなことにJavaScriptでは、配列は特定のサイズに制限されておらず、適切な組み込みの配列メソッドを使えば、任意のインデックスでの挿入や削除も簡単に行えるため、そうした制限を克服する方法について考える必要はありません。

では、JavaScriptにおいて配列のサイズ、配列への挿入、配列からの削除が制限にならないのであれば、連結リストは本当に必要なのでしょうか?この質問への短い答えは場合による、です。とはいえ、連結リストは動的データ構造の中で最もシンプルなものであり、しっかりとした基礎を与えてくれるため、グラフや二分木のようなより複雑なデータ構造をより簡単に理解できるようになります。

連結リストの構造

連結リストとは、ノードと呼ばれるデータ要素の線形の集合であり、各ノードはポインタによって次のノードを"指し示し"ます。

各ノードは、単一のデータ要素と、リスト内の次のノードへのリンク(ポインタ)を保持します。

先頭ノード(head node)はリストの最初のノードであり、末尾ノード(tail node)はリストの最後のノードです。以下は連結リストの基本的な表現です:

[ NODE(head) ] -> [ NODE ] -> [ NODE(tail) ] -> null

課題

NodeでES6モジュールを実行する

Node v22(2024年10月にLTSになりました)は、これ以上の設定をしなくても、自動的にES6モジュールを検出して実行できるようになりました。ES6モジュールを使っていて、Nodeがその構文を認識できないことによるエラーに遭遇した場合は、Nodeを最新のLTSバージョンに更新してください。

2つのクラスまたはファクトリが必要になります:

  1. LinkedListクラス/ファクトリ。リスト全体を表します。
  2. Nodeクラス/ファクトリ。valueプロパティとnextNodeプロパティを持ち、両方ともデフォルトでnullに設定します。

連結リストのクラス/ファクトリに、以下の関数を実装してください:

  1. append(value)は、valueを含む新しいノードをリストの末尾に追加します。
  2. prepend(value)は、valueを含む新しいノードをリストの先頭に追加します。
  3. size()はリスト内のノードの総数を返します。
  4. head()はリストの最初のノードの値を返す必要があります。リストが空の場合はundefinedを返す必要があります。
  5. tail()はリストの最後のノードの値を返す必要があります。リストが空の場合はundefinedを返す必要があります。
  6. at(index)は指定されたインデックスのノードの値を返す必要があります。指定されたインデックスにノードが存在しない場合は、undefinedを返す必要があります。
  7. pop()はリストの先頭ノードを削除し、その値を返す必要があります。空のリストに対して使われた場合は、単にundefinedを返す必要があります。
  8. contains(value)は、渡された値がリスト内に存在する場合はtrueを返し、そうでない場合はfalseを返します。
  9. findIndex(value)は、指定された値を含むノードのインデックスを返します。その値がリスト内に見つからない場合は、-1を返す必要があります。指定されたvalueと一致する値を持つノードが複数ある場合は、一致する値を持つ最初のノードのインデックスを返す必要があります。
  10. toString()は、あなたのLinkedListオブジェクトを文字列として表現し、コンソールに出力してプレビューできるようにします。リストが空の場合は、空の文字列を返す必要があります。フォーマットは次の通りです: ( value ) -> ( value ) -> ( value ) -> null。

追加課題

  1. insertAt(index, ...values)は、指定されたindexに、与えられた値を持つ新しいノードを挿入する必要があります。例えば:

    // list that's already set up
console.log(list.toString());
//=> "( 1 ) -> ( 2 ) -> ( 3 ) -> null"

list.insertAt(1, 10, 11)
console.log(list.toString());
//=> "( 1 ) -> ( 10 ) -> ( 11 ) -> ( 2 ) -> ( 3 ) -> null"

    このメソッドが範囲外のインデックス(0未満、またはリストのサイズより大きい)で呼び出された場合は、RangeErrorをスローしてください。

  2. removeAt(index)は、指定されたindexのノードを削除します。指定されたインデックスが範囲外(0未満、またはリストのサイズ以上)の場合は、RangeErrorをスローしてください。

追加課題のヒント: ノードを挿入または削除するときは、それが既存のノードにどう影響するかを考えてください。一部のノードは、nextNodeのリンクを更新する必要があります。

試してみよう

作成した連結リストを実際に試してみましょう!

  1. main.jsファイルを作成し、あなたのLinkedListクラスまたはファクトリをインポートするようにしてください。ここでリストをテストします。

  2. LinkedListのインスタンスを作成し、ノードを追加してください:

    // example uses class syntax - adjust as necessary
const list = new LinkedList();

list.append("dog");
list.append("cat");
list.append("parrot");
list.append("hamster");
list.append("snake");
list.append("turtle");

  3. ファイルの末尾にconsole.log(list.toString());を追加して実行してください。

  4. すべてが正しく動作していれば、出力は以下のようになるはずです:

    ( dog ) -> ( cat ) -> ( parrot ) -> ( hamster ) -> ( snake ) -> ( turtle ) -> null

    好きであれば、テストのために別の値を使ってみてください。
