Form Validation with JavaScript 日本語訳

This lesson will cover the Constraint Validation API

イントロダクション

フォームはほとんどのウェブサイトにとって重要な部分です。ほとんどすべての主要なサイトには、サインアップフォーム、お問い合わせフォーム、検索フォームなどがあります!幸運なことに、HTML5とJavaScriptには便利な組み込みのメソッドがいくつかあります。Intermediate HTML and CSSコースのForm Validationsのレッスンで、すでにHTMLでのバリデーションとCSSでのバリデーションのスタイリングについて学びました。

このレッスンでは、Constraint Validation APIを扱います。これは、JavaScriptを使ってフロントエンドでフォームを検証する方法です。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • HTMLフォームにおけるバリデーションの重要性。
  • Constraint Validation API。
  • JavaScriptのみのバリデーション。

課題

  1. Constraint Validation APIを含め、フォームを検証するためにJavaScriptをどう使えるかを扱った、このフォームバリデーションについてのチュートリアルに従ってください。

  2. Constraint Validationのドキュメントにも目を通しておくと有益です。

もう少し練習

  1. Email、Country、Postal Code、Password、Password Confirmationのフィールドを集めるブラウザフォームを構築してください。フィールドが適切に入力されているかどうかをユーザーに知らせるために、ライブなインラインバリデーションを使うべきです。つまり、フォーム送信時だけでなく、入力しながら検証するということです。フィールドが無効な場合、それは赤くハイライトされ、ユーザーを導くためのエラーメッセージを表示すべきです。

    フォームは実際にどこかに送信される必要はありませんが、ユーザーが何らかの有効なエラーや未入力の必須フィールドがある状態でフォームを送信しようとした場合、カスタムのエラーメッセージを表示すべきです。このレッスンのために、<form>要素にnovalidate属性を必ず付けてください。これにより、すべてのバリデーションをJavaScriptファイルで行えるようになります。さまざまな<input>のtypeを引き続き使うことはできますが、その有効性をチェックして報告するにはJavaScriptを使う必要があります。すべてが問題なく、フォームが「送信」されたら、ユーザーにハイタッチしてあげてください。

  2. 空のHTMLドキュメントをセットアップしてください。

  3. さまざまなフォーム要素とそれに付随するバリデーターをどうセットアップするか考えてみてください。どんなオブジェクトや関数が必要になるでしょうか?数分間考える時間を取ることで、1時間のコーディングを無駄にせずに済むかもしれません。あなたにできる最善のことは、コンピューターに触れる前に、解決策全体をホワイトボードに書き出してみることです。
  4. フォーム要素を書いてください。
  5. ユーザーがフォームを進めていくにつれてバリデーションをチェックするJavaScriptコードを追加してください。ユーザーがフォームフィールドから離れたとき、そのフィールドを自動的に検証すべきです。
  6. 考えられるすべてのケースをテストしてください。

  7. :user-validと:user-invalid疑似クラスを使って、バリデーションをCSSでスタイリングするのを忘れないでください!

  8. あなたのLibraryプロジェクトに戻り、そのフォームにカスタムバリデーションを追加してください!ユーザーが空のフォームフィールドでフォームを送信しようとしたとき、カスタムのエラーメッセージを表示してください(例えば「著者名は入力必須です!」など)。新しい機能に取り組むために、FoundationsのRevisiting Rock Paper Scissorsで学んだgitのブランチワークフローを使うのを忘れないでください。
