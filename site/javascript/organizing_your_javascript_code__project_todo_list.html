Todo List

イントロダクション

この時点で、あなたはすでに示してきたさまざまなテクニックをかなり練習してきました。しかし、あなたにたくさんの情報を投げかけてきたので、先に進む前に少し立ち止まって、これらのテクニックを結びつける、もう一つの素晴らしいプロジェクトに取り組む時間を取りましょう。あなたが新しく身につけたスキルのほとんど(もしすべてでなければ)を披露する機会になるはずです!

Todoリスト

Todoリストは初心者向けのウェブ開発チュートリアルの定番であり、実装は基本的なものにできます。しかし、改善の余地や追加できる機能はたくさんあります。

コードに飛び込む前に、少し時間を取って、プロジェクトをどう整理したいか考えてみてください。

課題

  1. あなたの「todo」は動的に作成したいオブジェクトになるので、それらを生成するにはファクトリーかコンストラクタ/クラスのどちらかを使うことになります。
  2. あなたのtodoアイテムがどんな種類のプロパティを持つべきか、ブレインストーミングしてみてください。最低限、title、description、dueDate、priorityを持つべきです。notesや、checklistさえも含めたいと思うかもしれません。
  3. あなたのtodoリストはprojects、つまり別々のtodosのリストを持つべきです。ユーザーが最初にアプリを開いたとき、彼らのすべてのtodoが入る、何らかの「デフォルト」プロジェクトがあるべきです。ユーザーは新しいプロジェクトを作成でき、自分のtodoをどのプロジェクトに入れるか選べるべきです。
  4. アプリケーションロジック(つまり、新しいtodoの作成、todoを完了に設定すること、todoの優先度を変更することなど)をDOM関連のものから分離すべきなので、それらすべてを別々のモジュールに保ってください。
  5. ユーザーインターフェースの見た目はあなた次第ですが、次のことができるべきです:
    1. すべてのプロジェクトを表示する。
    2. それぞれのプロジェクト内のすべてのtodoを表示する(おそらくタイトルと期日だけ…もしかしたら優先度によって色を変えるのもいいかもしれません)。
    3. 単一のtodoを展開して、その詳細を確認・編集する。
    4. todoを削除する。
  6. インスピレーションのために、次の素晴らしいtodoアプリをチェックしてみてください。(スクリーンショットを見たり、紹介動画を見たりしてみてください)
    1. Todoist
    2. Things
    3. any.do
  7. おそらくすでにwebpackを使っているので、npmから外部ライブラリを追加するのは朝飯前です!コードで次の便利なライブラリを使うことを検討したくなるかもしれません:
    1. date-fnsは、日付や時間をフォーマット・操作するための便利な関数をたくさん与えてくれます。

  8. まだ、実際にデータをどこかに保存するテクニックを学んでいないので、ユーザーがページをリフレッシュすると、彼らのすべてのtodoが消えてしまいます!Web Storage APIを使って、このtodoアプリに何らかの永続性を追加すべきです。

    localStorageを使うと、ユーザーのコンピューターにデータを保存できます。ここでの欠点は、そのデータが作成されたコンピューター上でしかアクセスできないということです。それでも、かなり便利です!新しいプロジェクト(またはtodo)が作成されるたびにプロジェクト(とtodo)をlocalStorageに保存する関数と、アプリが最初に読み込まれたときにlocalStorageの中にそのデータを探す別の関数をセットアップしてください。さらに、つまずかないようにするための、いくつかの簡単なヒントをここに示します: - localStorageから取得したいデータが存在しない場合でも、あなたのアプリがクラッシュしないことを確認してください! - DevToolsを使って、localStorageに保存したデータを検査できます!これを行うには、DevToolsのApplicationタブを開き、Storageの下にあるLocal Storageタブをクリックしてください。アプリでlocalStorageのデータを追加、更新、削除するたびに、それらの変更はDevToolsに反映されます。 - localStorageはデータの送受信・保存にJSONを使い、データを取得するときも、それはJSON形式になります。関数はJSONに保存できないということを心に留めておいてください。ですので、それらを取得した後、オブジェクトのプロパティにどうメソッドを戻すかを考える必要があります。頑張ってください!
