JavaScriptコースの終わりに!

JavaScriptコースを修了したことは、大きなマイルストーンです!おめでとうございます!プロトタイプ、クロージャ、Promise、イベントループなど、JavaScriptの主要な概念の多くを学んできました。少し立ち止まって、自分がどれだけ遠くまで来たかを振り返ってみてください。

この時点で、あなたはすべて素のJavaScriptだけを使って、素晴らしく動的なフロントエンドを作れるようになっています。しかし、フロントエンドの学びはまだ終わりではありません。この先のコースでは、アクセシビリティ、レスポンシブデザイン、そしてインターフェースを構築するためのライブラリであるReactについて学んでいきます。あなたはすでに、背後にあるデータの変化に応じて手動でDOMを更新することの大変さを経験してきましたが、まさにその部分をReactが簡単にしてくれます。
