How this course will work

イントロダクション

JavaScript!好きでも嫌いでも、ウェブの仕事をしている限り、いずれはそれに向き合わなければなりません。このコースでは、JavaScript言語そのものをさらに深く掘り下げ、プロトタイプ継承、モジュール化、バンドリング、非同期コード、JavaScriptのテストといったトピックを含む、JavaScriptがフロントエンドでどう使われるかについての多くの方法を探っていきます。

Reactのようなツールを使ってより複雑なフロントエンドを作ることに飛び込む前に、より素のままの文脈でこれらの基礎を実践的に経験しておくことが重要です。そのようなツールは、しばしば魔法のように見えたり、直感に反するように見えたりする、非常に特有のやり方を持っていますが、JavaScriptとフロントエンド開発の良い基礎を持ってそれらに取り組めば、それらが実際に裏側で何をしているのかをずっとよく理解できるようになるでしょう。

Rubyの人たちへ

このコースは、JavaScriptパスよりもRubyパスの方で少し後になって登場します。あなたはこれらの概念のいくつかにすでに触れたことがあるという恩恵を受けられますが、何かがRubyの何かと見た目が同じ、あるいは同じ名前を持っているからといって、まったく同じように動作するとは限らないということに注意してください。それさえ意識しておけば、きっとうまくやれるはずです!

旅路

これらのレッスンの進め方は、ここまであなたがやってきたこととかなり似たものになるので、その調子で続けてください。あなたは前のコースで学んだことを忘れてしまっているでしょう。このコースで学ぶことも、進めていくうちに忘れてしまうでしょうし、後のコースでもまた忘れてしまうでしょう。学んだことをすべて暗記する必要はないということを、自分自身に思い出させてください。

私たちは多くのことをカバーしていくので、あなたの脳が何度か溶けてしまうかもしれませんが、心配いりません、それはただのかすり傷です!学びの旅は確かに大変ですが、しっかり休んで、傷を癒やして、前進し続けてください!

話はもう十分です - さあ、学びましょう!
