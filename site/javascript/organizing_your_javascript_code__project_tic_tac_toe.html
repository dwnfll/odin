Tic Tac Toe

イントロダクション

ブラウザでプレイできるTic Tac Toeゲームを作っていきます!

課題

  1. HTML、CSS、JavaScriptファイルでプロジェクトをセットアップし、Gitリポジトリもすべてセットアップしてください。
  2. ゲームボードは、Gameboardオブジェクトの中の配列として保存することになるので、そこから始めましょう!プレイヤーも同様にオブジェクトとして保存されることになり、そしておそらく、ゲーム自体の流れをコントロールするオブジェクトも欲しくなるでしょう。
    1. ここでのあなたの主な目標は、グローバルなコードをできるだけ少なくすることです。できるだけ多くのものをファクトリーの中に押し込んでみてください。もし何かの単一のインスタンスだけが必要な場合(例えばgameboardやdisplayControllerなど)、追加のインスタンスを作成するために再利用されることのないよう、ファクトリーをIIFE(モジュールパターン)でラップしてください。
    2. このプロジェクトでは、それぞれのロジックがどこに置かれるべきかを慎重に考えてください。それぞれの小さな機能は、game、player、gameboardオブジェクトのいずれかに収まるはずです。それらを「論理的な」場所に置くよう気を配ってください。ここで少し時間をかけてブレインストーミングすることで、後々の作業がずっと楽になります!
    3. もし困っているなら、Building a house from the inside outは、このプロジェクトにどう取り組むか、そしてコードをどう整理・構造化するかについての、非常に応用の利く例を示してくれる素晴らしい記事です。
  3. まずはコンソールで動作するゲームを作ることに集中してください。ゲームが終了したときをチェックするロジックを必ず含めてください!3つ並んだすべての勝利パターンと引き分けをチェックすべきです。ゲームが動作するまでは、DOMやHTML/CSSについて考えるのは避けるようにしてください。この時点では、ユーザー入力を受け取ることについても心配しなくて構いません。自分で関数を呼び出し、引数を渡すことでゲームをプレイし、すべてが意図通りに動作しているか確認できます。
  4. コンソールで動作するゲームができたら、表示/DOMのロジックを扱うオブジェクトを作成してください。ゲームボード配列の内容をウェブページに描画する関数を書いてください(今のところ、何が起きているか確認するためだけに、ゲームボード配列を"X"と"O"で埋めておくだけでも構いません)。
  5. 適切なDOM要素とやり取りすることで、プレイヤーがボードの特定のマスにマークを追加できるようにする関数を書いてください(例えば、プレイヤーがボードのマスをクリックしてマーカーを置けるようにするなど)。すでに埋まっているマスにプレイヤーがプレイできないようにするロジックを忘れないでください!
  6. プレイヤーが自分の名前を入力できるようにインターフェースを整え、ゲームを開始/リスタートするボタンを含め、ゲーム終了時に結果を表示する表示要素を追加してください!
