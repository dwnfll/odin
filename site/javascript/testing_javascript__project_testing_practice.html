Testing Practice

イントロダクション

練習しましょう!このテストというもの自体は、それほど難しくはありませんが、かなり新しいものではあります。それに慣れる唯一の方法は、それをすることに時間を費やすことです。

課題

以下のためにテストを書き、それからテストを通してください!JestにはESMに対する組み込みの安定したサポートがないため、JestのESM/CJS変換のためにBabelをセットアップする必要があります。

  1. 文字列を受け取り、最初の文字を大文字にして返すcapitalize関数。
  2. 文字列を受け取り、それを反転させて返すreverseString関数。
  3. 基本的な演算のための関数、add、subtract、divide、multiplyを含むcalculatorオブジェクト。これらの関数はそれぞれ2つの数値を受け取り、正しい計算結果を返すべきです。
  4. 文字列とシフトの量を受け取り、それぞれの文字を「シフト」させて返すcaesarCipher関数。シーザー暗号がどう機能するかについてさらに読んでみてください。
  5. zからaへの折り返しをテストするのを忘れないでください。例えば、caesarCipher('xyz', 3)は'abc'を返すべきです。
  6. 大文字・小文字の保持をテストするのを忘れないでください。シフトされた文字の大文字・小文字は、元の文字の大文字・小文字に従うべきです。例えば、caesarCipher('HeLLo', 3)は'KhOOr'を返すべきです。
  7. 句読点をテストするのを忘れないでください。句読点、スペース、その他のアルファベット以外の文字は変更されないままであるべきです。例えば、caesarCipher('Hello, World!', 3)は'Khoor, Zruog!'を返すべきです。
  8. これについては、最終的な関数をいくつかの小さな関数に分割したいと思うかもしれません。テストの一つの考え方は、書いたすべての関数を明示的にテストする必要はないというものです…パブリックなものだけです。ですので、この場合、最終的なcaesarCipher関数のためのテストだけが必要です。それが期待通りに機能すれば、より小さなヘルパー関数もそれぞれ意図した通りのことをしていると確信できます。

  9. 数値の配列を受け取り、average、min、max、lengthというプロパティを持つオブジェクトを返すanalyzeArray関数。

    const object = analyzeArray([1,8,3,4,2,6]);

// object should equal:
{
  average: 4,
  min: 1,
  max: 8,
  length: 6
}
