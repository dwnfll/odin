Common Data Structures and Algorithms 日本語訳

Learn why we use different data structures to handle our data and some classic algorithms for searching through them to help solve problems

イントロダクション

データ構造の基本的な考え方は、あなたの特定のアプリケーションのニーズに合った方法でデータを保存することです。特定の種類のデータを一つの巨大な配列に保存したくなるかもしれませんが、もしかなりの数と深さのアイテムがあれば、特定の値を見つけるのはかなり時間がかかってしまうでしょう。ですので、他の選択肢を探す必要があります。

アプリケーションによっては、あなたを助けてくれる、他の基本的なデータ構造がひとまとまりあります。それらの間の違いは、通常、構造に最初にデータを入れるのにどれだけ時間がかかるか、要素を追加・検索するのにどれだけ時間がかかるか、そして構造がメモリ内でどれだけ大きいかの間のトレードオフに関係しています。

データ構造の詳細は、よりコンピューターサイエンス志向のコースのために取っておきますが、この導入は、単純な配列やハッシュ、セットではうまく対応できない特定の問題を特定し解決できるように、再びあなたの道具箱を少し広げてくれるはずです。新しい構造や戦略は、特に、特定の値のために大量のデータを検索しようとしているときや、何手も先の戦略を計画しているときに、特に関連性が高くなります。

あなたはすでに、他のいくつかのレッスンを通してアルゴリズムについて簡単な紹介を受けており、前回のプロジェクトでは自分自身のマージソートアルゴリズムを書くことさえしました。ソートアルゴリズムはかなり一般的だと気づくでしょう。アルゴリズムのもう一つの主要な分野は検索であり、そこではミリ秒が重要です。膨大な量のデータを検索しているとき、あなたの検索アルゴリズムの品質は非常に重要です。特定の要素を探してデータツリーを辿ることは、データ集約型のアプリケーションでよく見られる、関連する問題です。

あなたにとって幸運なことに、これらの複雑なアルゴリズムの問題は、過去に何度も解決されてきました。それらがどう解決されているかを理解することで、他の(似たような)問題に自分で応用できる、素晴らしいツールが手に入ります。アルゴリズムとは実のところ、問題を体系的に解決する方法に過ぎません。この短い導入では、自分でコーディングしているときに出会うかもしれない、いくつかのアルゴリズム、幅優先探索と深さ優先探索に焦点を当てていきます。
