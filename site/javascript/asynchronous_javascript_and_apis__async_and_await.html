Async and Await

イントロダクション

非同期コードは、多くのことが起きていると追いにくくなることがあります。asyncとawaitは、非同期コードをより同期的なコードのように読めるようにするのに役立つ、2つのキーワードです。これは、非同期コードの利点を保ちながら、コードをより綺麗に見せてくれます。

例えば、以下の2つのコードブロックは、まったく同じことを行います。どちらもサーバーから情報を取得し、それを処理し、Promiseを返します。

function getPersonsInfo(name) {
  return server.getPeople().then(people => {
    return people.find(person => { return person.name === name });
  });
}
async function getPersonsInfo(name) {
  const people = await server.getPeople();
  const person = people.find(person => { return person.name === name });
  return person;
}

2つ目の例は、あなたが書き慣れている種類の関数にずっと似ています。しかし、関数宣言の前にあるasyncキーワードに気づきましたか?server.getPeople()の前にあるawaitキーワードはどうでしょうか?

これらの関数を自分で実行してみたい場合は、以下の、サーバーを表すコードブロックを関数定義の前に貼り付けてください。この「サーバー」がどう機能するかは重要ではなく、単なる抽象化です。ここでの目標は、両方の関数がまったく同じように振る舞い、Promiseを返すことを見てもらうことです。

const server = {
  people: [
    {
      name: "Odin",
      age: 20,
    },
    {
      name: "Thor",
      age: 35,
    },
    {
      name: "Freyja",
      age: 29,
    },
  ],

  getPeople() {
    return new Promise((resolve, reject) => {
      // Simulating a delayed network call to the server
      setTimeout(() => {
        resolve(this.people);
      }, 2000);
    });
  },
};

asyncキーワード

asyncキーワードは、あなたが非同期関数を宣言していることをJavaScriptエンジンに知らせるものです。これは、どんな関数の中でもawaitを使うために必要です。関数がasyncで宣言されると、それは自動的にPromiseを返します。async関数の中でreturnすることは、Promiseをresolveすることと同じです。同様に、エラーを投げることはPromiseをrejectします。

理解しておくべき重要なことは、async関数は単にpromiseのためのシンタックスシュガーに過ぎないということです。

asyncキーワードは、関数を作成できるどんな方法でも使うことができます。言い換えると: 通常の関数を使えるどこでもasync関数を使うのは有効です。以下に、直感的でないかもしれないいくつかの例を示します。もし理解できなければ、課題を終えたときに戻って見てみてください。

const yourAsyncFunction = async () => {
  // do something asynchronously and return a promise
  return result;
}
anArray.forEach(async item => {
  // do something asynchronously for each item in 'anArray'
  // one could also use .map here to return an array of promises to use with 'Promise.all()'
});
server.getPeople().then(async people => {
  people.forEach(person => {
    // do something asynchronously for each person
  });
});

awaitキーワード

awaitは次のことを行います: それは、関数を続ける前に非同期のアクションが終わるのを待つよう、JavaScriptに伝えます。これは「終わるまで一時停止する」キーワードのようなものです。awaitキーワードは、通常.then()を使う関数から値を取得するために使われます。非同期関数の後に.then()を呼び出す代わりに、awaitを使って結果を変数に割り当てることになります。それから、同期コードでするのと同じように、その結果をコードで使うことができます。

エラーハンドリング

async関数のエラーを処理するのは非常に簡単です。Promiseにはrejectされたpromiseを処理するための.catch()メソッドがあり、async関数は単にpromiseを返すだけなので、その関数を呼び出し、末尾に.catch()メソッドを追加することができます。

asyncFunctionCall().catch(err => {
  console.error(err)
});

しかし、別の方法もあります: あの強力なtry...catch文です!async関数の中で直接エラーを処理したい場合、async/await構文でtry...catchを使うことができます。もしtryブロックの中でJavaScriptがエラーを投げたら、代わりにcatchブロックのコードが実行されます(これは同期コードにも使うことができます)。

async function getPersonsInfo(name) {
  try {
    const people = await server.getPeople();
    const person = people.find(person => { return person.name === name });
    return person;
  } catch (error) {
    // Handle the error any way you'd like
  }
}

これを行うと乱雑に見えるかもしれませんが、関数呼び出しの後に.catch()を追加することなくエラーを処理する、非常に簡単な方法です。エラーをどう処理するかはあなた次第であり、どちらの方法を使うべきかは、あなたのコードがどう書かれたかによって決まるべきです。何が必要かは、時間をかけて感覚がつかめてくるでしょう。課題も、async/awaitの処理方法を理解するのに役立ちます。

練習

Giphy APIの練習プロジェクトを覚えていますか?(もし覚えていなければ、戻ってAPIのレッスンを完了させるべきです)。Promiseベースのコードをasync/await互換のコードに変換していきます。これが、私たちが出発点とするコードのおさらいです:

<script>
  const img = document.querySelector('img');
  fetch('https://api.giphy.com/v1/gifs/translate?api_key=YOUR_KEY_HERE&s=cats')
    .then(function(response) {
      return response.json();
    })
    .then(function(response) {
      img.src = response.data.images.original.url;
    })
    .catch(function (error) {
      console.error(error);
    });
</script>

awaitはモジュールではないスクリプトのトップレベルでは機能しないため、GiphyへのAPI呼び出しをラップするasync関数を作成する必要があります。

<script>
  const img = document.querySelector('img');

  async function getCats() {
    fetch('https://api.giphy.com/v1/gifs/translate?api_key=YOUR_KEY_HERE&s=cats')
      .then(function(response) {
        return response.json();
      })
      .then(function(response) {
        img.src = response.data.images.original.url;
      })
      .catch(function(error) {
        console.error(error);
      });
  }
</script>

これで非同期の関数ができたので、promiseを使うことからawaitを使うことへとリファクタリングを始めることができます:

<script>
  const img = document.querySelector('img');

  async function getCats() {
    const response = await fetch('https://api.giphy.com/v1/gifs/translate?api_key=YOUR_KEY_HERE&s=cats');
    response.json().then(function(response) {
      img.src = response.data.images.original.url;
    }).catch(function(error) {
      console.error(error);
    });
  }
</script>

responseは依然として、最初に.then()ブロックに渡していたものと同じオブジェクトなので、.json()メソッドを使う必要があります。これは今度はpromiseを返します。.json()がpromiseを返すため、awaitを使ってそのレスポンスを変数に割り当てることができます。

<script>
  const img = document.querySelector('img');

  async function getCats() {
    const response = await fetch('https://api.giphy.com/v1/gifs/translate?api_key=YOUR_KEY_HERE&s=cats');
    const catData = await response.json();
    img.src = catData.data.images.original.url;
  }
</script>

エラーハンドリングについては、.catch()メソッドを連結する代わりに、try...catch文が必要になります。通常のコードをtryブロックでラップし、それからエラーハンドリングの部分にcatchブロックを使います。

<script>
  const img = document.querySelector('img');

  async function getCats() {
    try {
      const response = await fetch('https://api.giphy.com/v1/gifs/translate?api_key=YOUR_KEY_HERE&s=cats');
      const catData = await response.json();
      img.src = catData.data.images.original.url;
    } catch (error) {
      console.error(error);
    }
  }
</script>

この関数を使うには、私たちのコードの中でgetCats()と呼び出すだけです。

<script>
  const img = document.querySelector('img');

  async function getCats() {
    try {
      const response = await fetch('https://api.giphy.com/v1/gifs/translate?api_key=YOUR_KEY_HERE&s=cats');
      const catData = await response.json();
      img.src = catData.data.images.original.url;
    } catch (error) {
      console.error(error);
    }
  }
  getCats();
</script>

このコードは、前のレッスンのコードとまったく同じように振る舞います。リファクタリングした後、少し見た目が違うだけです。async/awaitは、非同期のJavaScriptコードを整理する上で非常に便利なツールです。async/awaitは単に、異なる方法で書かれたpromiseに過ぎないということを覚えておくことが重要です。以下の課題に取り組んで、async/awaitの理解をさらに深めてください。
