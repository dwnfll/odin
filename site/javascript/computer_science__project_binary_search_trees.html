Binary Search Trees

日本語訳

← javascript

In this project you'll get your hands dirty with one of the most common computer science problems, searching binary trees.

イントロダクション

あなたはすでに二分探索木について学んでいます。これは、データ項目の集まりを、ノードでいっぱいの木構造に変換したもので、それぞれの左のノードは右のノードよりも"低い"値を持ちます。木は"ルートノード"から始まり、子を持たないノードは"葉ノード"と呼ばれます。あなたはまた、幅優先や深さ優先といった、木の走査アルゴリズムについても学んでいます。

では、バランスの取れた二分探索木(BST)を見ていきましょう。BSTを使うと、データ項目の検索・挿入・削除を高速に行うことができます。このバランスの取れたBSTを構築する記事を読んでください。また、バランスの取れたBSTを構築する動画もあります。最後のリソースはJavaScriptを使っていませんが、自分なりの疑似コードを組み立てられる程度には理解できるはずです。

課題

この課題では、バランスの取れたBSTを構築します。重複した値は使わないでください。処理がより複雑になり、バランスを取るのがはるかに難しい木になってしまうからです。そのため、必ず重複した値を取り除くか、挿入前に既存の値かどうかを確認するようにしてください。

  1. Nodeクラス/ファクトリを作成してください。保存するデータのための属性に加えて、左右の子のための属性も持つ必要があります。

  2. 初期化時に配列を受け取るTreeクラス/ファクトリを作成してください。Treeクラスはroot属性を持つ必要があり、これには次に書くbuildTree()の戻り値を使います。

  3. 数値の配列(例: [1, 7, 4, 23, 8, 9, 4, 3, 5, 7, 9, 67, 6345, 324])を受け取り、それを適切に配置されたNodeオブジェクトでいっぱいのバランスの取れた二分木に変換する、buildTree(array)関数を書いてください(ソートして重複を取り除くのを忘れないように!)。buildTree()関数は、レベル0のルートノードを返す必要があります。この関数は(クラス構文のプライバシー機能を使うか、ファクトリの戻り値オブジェクトに含めないことで)プライベートにしてもかまいません。あとは、それを呼び出してrootノードの値を初期化するだけです。

    木を視覚的に表現する

    二分探索木を視覚化したい場合は、木を構造化されたフォーマットでconsole.logするprettyPrint()関数を用意しました。この関数は、nodeパラメータの値として、あなたの木のルートを受け取ることを想定しています:

    const prettyPrint = (node, prefix = '', isLeft = true) => {
  if (node === null || node === undefined) {
    return;
  }

  prettyPrint(node.right, `${prefix}${isLeft ? '│   ' : '    '}`, false);
  console.log(`${prefix}${isLeft ? '└── ' : '┌── '}${node.data}`);
  prettyPrint(node.left, `${prefix}${isLeft ? '    ' : '│   '}`, true);
}

  1. 値を受け取り、指定された値が木の中にあればtrueを返す、includes(value)関数を書いてください。値が木の中にない場合は、falseを返す必要があります。

  2. 値を受け取り、その値を持つ新しいノードを木に挿入する、insert(value)関数を書いてください。"二分探索"の性質を保つように挿入することを忘れないでください: 各ノードについて、その左側にあるすべてのノードはより小さい値を持ち、右側にあるすべてのノードはより大きい値を持つ必要があります。すでに木の中に存在する値でこの関数が呼び出された場合、この関数は何もしないようにしてください。追加のリソースが必要な場合は、二分探索木への挿入についてのGeeks for Geeksの記事を確認してください。

    元の入力配列を使うのは避ける

    木を構築するために使った元の入力配列を使って、これらのメソッドを実装したくなるかもしれませんが、これらの操作の効率性のためには、それを避けることが重要です。Big O Cheatsheetを振り返ってみると、二分探索木はO(log n)の時間で挿入・削除ができることがわかります。これは、同じ操作を配列で行う場合と比べて、パフォーマンスが大きく向上していることを意味します。この効率性を得るためには、これらのメソッドの実装が、木を走査してノードとそのつながりを操作するようにする必要があります。

  3. 値を受け取り、それを木から削除する、deleteItem(value)関数を書いてください。対象のノードがいくつの子を持つかに応じて、複数のケースに対処する必要があります。指定された値が木の中に存在しない場合、この関数は何もしないようにしてください。追加のリソースが必要な場合は、二分探索木での削除についてのGeeks for Geeksの記事を確認してください。

  4. パラメータとしてコールバック関数を受け取る、levelOrderForEach(callback)関数を書いてください。levelOrderForEach()は、幅優先のレベル順で木を走査し、走査しながら各値に対してコールバックを呼び出す必要があります。この際、Array.prototype.forEach()が配列に対して動作するのと同じように、(ノードではなく)各値を引数として渡します。levelOrderForEach()は、反復処理または再帰処理のどちらを使っても実装できます(両方を試してみてください!)。コールバック関数が渡されなかった場合は、コールバックが必要であることを伝えるエラーをスローしてください。

    キューを使う

    まだ走査していないすべての子ノードを把握し、新しいノードをリストに追加していくために、キューとして機能する配列を使うとよいでしょう。視覚的なイメージが必要な場合は、mycodeschoolによるレベル順走査についての動画を見てください。

  5. 同じくコールバックをパラメータとして受け取る、inOrderForEach(callback)、preOrderForEach(callback)、postOrderForEach(callback)関数を書いてください。これらの関数はそれぞれ、対応する深さ優先の順序で木を走査し、各値を渡されたコールバックに渡す必要があります。levelOrderForEach()と同様に、これらの関数も、引数としてコールバックが渡されなかった場合はエラーをスローする必要があります。それぞれの走査がどのように機能するかについてのリソースが必要な場合は、mycodeschoolによる二分木の走査: 行きがけ順・通りがけ順・帰りがけ順についての動画を見てください。

  6. 指定された値を含むノードの高さを返す、height(value)関数を書いてください。高さとは、そのノードから葉ノードまでの最長経路にある辺の数として定義されます。値が木の中に見つからない場合は、undefinedを返す必要があります。

  7. 指定された値を含むノードの深さを返す、depth(value)関数を書いてください。深さとは、そのノードからルートノードまでの経路にある辺の数として定義されます。値が木の中に見つからない場合は、undefinedを返す必要があります。

  8. 木がバランスしているかどうかを確認する、isBalanced()関数を書いてください。二分木は、木の中のすべてのノードについて、その左右の部分木の高さの差が1以下であり、かつ左右の部分木もどちらもバランスしている場合に、バランスしていると見なされます。

    バランスの確認における落とし穴

    よくある間違いは、ルートの左右の子の高さの差だけを確認してしまうことです。それだけでは不十分です。すべてのノードについて、バランスの条件を確認する必要があります。

  9. バランスの崩れた木を再びバランスさせる、rebalance()関数を書いてください。走査の手法を使って、buildTree()関数に新しい配列を渡すとよいでしょう。

すべてをまとめる

以下を行う、動作確認用のスクリプトを書いてください:

  1. 各要素が100未満の値を持つ、ランダムな数値の配列から二分探索木を作成してください。必要であれば、呼び出すたびにランダムな数値の配列を返す関数を作ってもかまいません。
  2. isBalanced()を呼び出して、木がバランスしていることを確認してください。
  3. レベル順、行きがけ順、帰りがけ順、通りがけ順で、すべての要素を出力してください。
  4. 100より大きい値を持つ数値をいくつか追加して、木のバランスを崩してください。
  5. isBalanced()を呼び出して、木のバランスが崩れていることを確認してください。
  6. rebalance()を呼び出して、木のバランスを取ってください。
  7. isBalanced()を呼び出して、木がバランスしていることを確認してください。
  8. レベル順、行きがけ順、帰りがけ順、通りがけ順で、すべての要素を出力してください。
