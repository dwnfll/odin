Classes

イントロダクション

JavaScriptには、JavaやRubyのような他のオブジェクト指向言語と同じ意味でのクラスはありません。しかし、ES6では、classキーワードを使うオブジェクト作成のための構文が導入されました。これは基本的に、コンストラクタのレッスンで学んだオブジェクトコンストラクタとプロトタイプにほとんど似た、新しい構文です。

歴史的に、特にES6がリリースされた当時、class構文がまさにJavaのような言語のクラスのように見えるという理由で、ちょっとした論争がありました。JavaScriptのclass構文はシンタックスシュガーのように見えますが、オブジェクトコンストラクタやプロトタイプとは異なる、いくつかの独自の性質を持っています。とはいえ、構文が異なっていても、根底にある仕組みは変わっていません(古典的な継承が行われているわけではありません)。しかし、この構文がこれらのオブジェクトで実際に何が起きているのかについてそれほど明示的ではないため、しばしば人々を混乱させます。

かなりの時間が経ち、今ではclass構文は多くのコードベースに存在しています。ここで学ぶべき新しい仕組みはそれほど多くなく、主にほとんど馴染みのある概念のための新しい構文だけです。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • オブジェクトコンストラクタとクラスの違いを説明します。
  • getterとsetterが何かを説明します。
  • 基本的なクラス構文を説明します。
  • クラスで継承を使います。
  • プライベートなクラスのフィールドとメソッドを実装する方法を説明します。
  • staticなプロパティとメソッドが何かを説明します。

課題

  1. getterとsetterについて読んでください(「accessor descriptors」のセクションについては、以前扱っていないので心配しなくて構いません)。この記事ではまだクラスを示していませんが、クラスも(Object.definePropertyを使わずに)同じ構文でgetterとsetterを使うことができます。
  2. クラス構文の概要については、JavaScript.infoのクラス構文の入門を読んでください。
  3. MDNのクラスについてのドキュメントは、いつも通り、もう少し深く掘り下げるための素晴らしいリソースです。個々の構文機能はたくさんありますが、これらは時間をかけて探っていくことができます。いつも通り、ここで今すぐドキュメントを読んだだけで何かを暗記する必要はありません。少し見ておくとよい機能には、次のようなものがあります:
    • クラスを拡張する(例えば、Personクラスを拡張するPlayerクラスを持ち、Person.prototypeをプロトタイプチェーンに追加するようなこと)。
    • プライベートプロパティ。これにより、ファクトリー関数のプライベート変数のように、クラスの外からアクセスできないプロパティやメソッドを持つことができます。
    • staticなプロパティとメソッド。これらは、クラスのインスタンスにではなく、クラス自体にアクセスされるプロパティやメソッド(パブリックまたはプライベート)です。これは、一部の文字列メソッドが文字列自体のインスタンスにアクセスされる(例えばsomeString.slice(0, 5))のに対し、一部のメソッドはStringコンストラクタに直接呼び出される(例えばString.fromCharCode(79, 100, 105, 110))のと似ています。

練習

あなたのLibraryプロジェクトに戻り、単なるコンストラクタの代わりにclassを使うようにリファクタリングしてください。新しい機能に取り組むために、Revisiting Rock Paper Scissorsで学んだgitのブランチワークフローを使うのを忘れないでください。このように作業することに慣れておくべきです!
