関数

以下の例の関数を通して、パラメータと引数について説明しましょう:

function favoriteAnimal(animal) {
    return animal + " is my favorite animal!"
}

const message = favoriteAnimal('Goat')
console.log(message)

JavaScriptでは、パラメータとは関数宣言のかっこ()の間に列挙される項目のことです。関数の引数とは、私たちがその関数に渡すことに決めた実際の値のことです。

上記の例では、関数の定義は最初の行に書かれています:function favoriteAnimal(animal)。パラメータanimalは、かっこの中にあります。animalをpet、x、blahなどに置き換えることも同じくらい簡単にできます。しかしこの場合、パラメータにanimalという名前を付けることで、コードを読む人に多少の文脈が与えられ、animalが最終的に何を含むことになるのかを推測する必要がなくなります。

favoriteAnimal関数宣言のかっこの中にanimalを入れることで、私たちはfavoriteAnimal関数に何らかの値を送ることをJavaScriptに伝えています。つまり、animalは将来のある値のための単なるプレースホルダーにすぎないということです。では、どんな値を送っているのでしょうか?

5行目のfavoriteAnimal('Goat')は、私たちがfavoriteAnimal関数を呼び出し、その関数呼び出しの中に値'Goat'を渡している箇所です。ここでは'Goat'が私たちの引数です。私たちはfavoriteAnimal関数に「'Goat'をfavoriteAnimal関数に送り、animalというプレースホルダーがあるところではどこでも'Goat'を使ってください」と伝えているのです。パラメータを使うことで得られる柔軟性のおかげで、どんな動物でも自分のお気に入りとして宣言できます。

以下は、パラメータが関数にどう渡され、値がそこからどう返されるかを視覚的に理解するのに役立つ図です。

私たちはfavoriteAnimal('Goat')の結果をmessage変数に保存し、後でmessageをlog()の引数として渡していますが、関数呼び出しを別の関数呼び出しの引数として渡すことも可能であることに注意してください。

function favoriteAnimal(animal) {
    return animal + " is my favorite animal!"
}

console.log(favoriteAnimal('Goat'))

上記の例では、log()の引数としてfavoriteAnimal('Goat')を渡しています。そうすると、favoriteAnimal('Goat')関数呼び出しの戻り値(文字列"Goat is my favorite animal!")が、別の変数に先に保存することなく、log()の引数として使用されます。

関数呼び出しを引数として渡すことは今後わりとよくあるので、この可能性を心に留めておいてください。もしfavoriteAnimal('Goat')を単体で呼び出し、それをconsole.logの引数として渡してその戻り値を出力させなかった場合、それでもその文字列は返されます……しかし、どこにも行き着きません。コンソールには何も表示されず、その文字列が変数に保存されることもありません。

自由にコードを自分でいろいろ試して、'Goat'をあなたの好きな動物に置き換えてみてください。引数を好きなように変えられることに気づきましたか?関数宣言と関数の本体の中のanimalも変えてみてください。そうするとどうなりますか?

  4. 次に、JavaScriptの関数についてもう少し文脈をつかむためにfunction expressionsの記事を読み、アロー関数への入門としてarrow functionsについての記事も読んでください。アロー関数は便利ですが必須ではないので、まだあまり気にしすぎなくて構いません。ここに含めているのは、この先進んでいく中で出会う可能性が高いためであり、それが出てきたときに何を見ているのか少なくともある程度分かっている方がよいからです。

いくつか関数を書いてみましょう!これらを、骨組みだけのHTMLファイルのscriptタグの中に書いてください。セットアップの仕方を忘れてしまった場合は、JavaScriptコードを実行する方法についての私たちの説明を見返してください。

今のところは、それぞれの関数を書いて、console.logで出力をテストするだけにしてください。

  1. 1つの数値を受け取り、その数値+7を返すadd7という関数を書いてください。
    • add7(10)は17を返すべきです。
  2. 2つの数値を受け取り、それらの積を返すmultiplyという関数を書いてください。
    • multiply(3, 2)は6を返すべきです。
  3. 文字列を受け取り、最初の文字だけを大文字にしたその文字列を返すcapitalizeという関数を書いてください。小文字、大文字、あるいはその両方が混ざった文字列を受け取れるようにしてください。
    • capitalize("abcd")は"Abcd"を返すべきです。
    • capitalize("ABCD")は"Abcd"を返すべきです。
    • capitalize("aBcD")は"Abcd"を返すべきです。
  4. 文字列を受け取り、その文字列の一番最後の文字を返すlastLetterという関数を書いてください:
    • lastLetter("abcd")は"d"を返すべきです。
