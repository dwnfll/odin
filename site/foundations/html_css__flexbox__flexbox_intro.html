Let's get started with Flexbox

イントロダクション

これから学んでいくように、ウェブページ上で要素を動かす方法はたくさんあります。長年にわたって新しい方法が開発され、古いものは廃れていきました。Flexboxは最初からCSSで使えたわけではありません---その登場は革命的なものでした。

多くの教材は、これが技術として比較的新しいという理由でカリキュラムの終盤に配置しています。しかし現時点では、多くの開発者にとって要素を配置するデフォルトの方法になっています。Flexboxはあなたのツールボックスの中で最もよく使うツールの一つになるので、先に学んでしまいましょう。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • flexboxを使って要素を配置する方法を学びます。
  • フレックスコンテナとフレックスアイテムについて学びます。
  • 単に要素を積み重ねたり中央揃えしたりするだけにとどまらない、役立つコンポーネントやレイアウトの作り方を学びます。

始める前に

Flexboxのレイアウトは少し複雑になることがあります。前のレッスンでは、ブラウザの開発者ツールを使って物事を検証しデバッグする方法を学びました。これらのツールは、これから続くレッスンで非常に重要になります。何かが期待通りに動作しない場合は、開発者ツールで検証することが毎回最初のステップになるはずです。

Flexboxは、これまで扱ってきた他の概念より必ずしも難しいわけではありませんが、動く部分が確かにもう少し多くあります。これらの最初のレッスンで学んでいることを実際に活用できるようになるには、最後までたどり着いてすべてを組み合わせられるようになるまで、少し難しく感じるでしょう。進めていく中で、自分のためにもすべてのコード例をいろいろ試してみてください。

このセクションの終わりの課題に取り組む際、ほぼ間違いなくこれらのレッスン(あるいは私たちが紹介するいくつかのリソース)を振り返って参照する必要が出てくるでしょう。しかし、時間をかけて私たちが提供するすべてのコード例を試しておけば、その時が来たときにどこを見ればよいかがよりよく分かるようになります。

フレックスしてみよう!

Flexboxは、アイテムを行や列に配置する方法です。これらのアイテムは、あなたが定義できるいくつかのルールに基づいて、フレックス(つまり伸び縮み)します。始めるにあたって、まずデモを見てみましょう。

コメント

コメントは、ブラウザがある行をコードとして解釈するのを防ぐもので、特定のタグの間に囲まれています。CSSでは/*を開始コメントタグ、*/を終了コメントタグとして使用し、HTMLとJavaScriptにはそれぞれ独自の構文があります。コメントアウトされたコードの行は、コードを囲んでいるコメントタグを削除することで「再度有効化」できます。

これで3つのdivがすべて水平に並んでいるはずです。「1x」「.5x」「.25x」ボタンで結果のフレームのサイズを変更すると、divが「フレックス」する様子も見られます。それらは利用可能な領域を埋め、それぞれが等しい幅を持つようになります。

HTMLの.flex-containerの中に別のdivを追加すると、それは他のものと並んで表示され、すべてが利用可能な領域に収まるようにフレックスします。

フレックスコンテナとフレックスアイテム

これまで見てきたように、flexboxは単一のCSSプロパティではなく、物事を必要な場所に配置するために使える、プロパティ一式のツールボックスです。これらのプロパティの中にはフレックスコンテナに属するものもあれば、フレックスアイテムに属するものもあります。これは重要な概念です。

フレックスコンテナとは、display: flexが設定されている任意の要素のことです。フレックスアイテムとは、フレックスコンテナの直下に存在する任意の要素のことです。

少しややこしいのですが、どんな要素もフレックスコンテナかつフレックスアイテムの両方になることができます。言い換えると、フレックスアイテムにdisplay: flexを設定し、flexboxを使ってその子要素を配置することもできるということです。
