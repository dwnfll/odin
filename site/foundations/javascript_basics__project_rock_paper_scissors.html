Rock Paper Scissors

イントロダクション

このプロジェクトでは、じゃんけん(Rock Paper Scissors)ゲームを作成します。このゲームは完全にコンソール内でプレイされます。

GUIはまだなし

以下の受講生の解答の一部には、ボタン、テキスト、その他の要素が含まれています。これらの要素は、グラフィカルユーザーインターフェース(GUI)と呼ばれるものの一部です。GUIは後のレッスンで作成します。それまでの間、コードをGitHubにコミットするのを忘れないでください。

問題解決のアプローチ

これはゼロから構築する最初のJavaScriptプロジェクトなので、Problem Solvingのレッスンの賢明な言葉を思い出しておくことが重要です。このプロジェクトの各ステップで、以下のことを必ず行ってください

  1. 解決策を計画するか、疑似コードを書く。
  2. コードを書く。
  3. コードをテストして、うまく動くことを確認する。

早めに、こまめにコミットするのを忘れないでください!記憶を新たにするために、commit messagesのレッスンを確認してみてください。

ステップ1: プロジェクト構造をセットアップする

  1. プロジェクト用の新しいGitリポジトリを作成してください。
  2. scriptタグを含む空のHTMLドキュメントを作成してください。
  3. JavaScriptが正しくリンクされているか確認してください:
    • JavaScriptでconsole.log("Hello World")と書いてください。
    • ウェブページを開いたときに、ブラウザのコンソールに「Hello World」が出力されるか確認してください。

このscriptタグ内で外部JavaScriptファイルをリンクするのがベストプラクティスです。外部JavaScriptファイルを使うことで、HTMLファイルをきれいで整理された状態に保てます。

HTMLファイルに追加のコードを書く必要はありません。このゲームは完全にコンソールを通してプレイされます。

ステップ2: コンピューターの選択を取得するロジックを書く

あなたのゲームはコンピューターを相手にプレイされます。「rock」「paper」「scissors」のいずれかをランダムに返す関数を書きます。

  1. getComputerChoiceという名前の新しい関数を作成してください。
  2. getComputerChoiceが「rock」「paper」「scissors」のいずれかの文字列値をランダムにreturnするようにコードを書いてください。
    • ヒント: Math.randomメソッドは、0以上1未満のランダムな数値を返します。これを使って、複数の選択肢のうちの一つを条件付きで返す方法を考えてみてください。
    • 注: この問題には配列が必要だと考える学習者もいるかもしれませんが、そうではありません。配列に馴染みがなくても心配いりません---カリキュラムの後半で扱います。
  3. 次のステップに進む前に、console.logまたはブラウザの開発者ツールを使って、関数が期待通りのものを返すことをテストしてください。

ステップ3: 人間の選択を取得するロジックを書く

あなたのゲームは人間のプレイヤーによってプレイされます。ユーザーの選択を受け取り、それを返す関数を書きます。

  1. getHumanChoiceという名前の新しい関数を作成してください。
  2. ユーザーが入力した内容に応じて、getHumanChoiceが有効な選択肢のいずれかを返すようにコードを書いてください。
    • ヒント: ユーザーの入力を得るためにpromptメソッドを使用してください。
    • ユーザーが無効な入力をした場合の再入力の処理は、後で教える内容が必要になるため、対応する必要はありません。今のところは、ユーザーが常に有効な選択肢を入力すると仮定してください。
  3. console.logを使って、関数が何を返すかをテストしてください。

ステップ4: プレイヤーのスコア変数を宣言する

あなたのゲームはプレイヤーのスコアを記録します。プレイヤーのスコアを記録するための変数を書きます。

  1. グローバルスコープにhumanScoreとcomputerScoreという名前の2つの新しい変数を作成してください。
  2. それらの変数を0という値で初期化してください。

ステップ5: 1ラウンドをプレイするロジックを書く

あなたのゲームはラウンドごとにプレイされます。人間とコンピューターのプレイヤーの選択を引数として受け取り、1ラウンドをプレイし、ラウンドの勝者のスコアを増やし、勝者発表を出力する関数を書きます。

  1. playRoundという名前の新しい関数を作成してください。
  2. playRoundに2つのパラメータを定義してください:humanChoiceとcomputerChoice。この2つのパラメータを使って、人間とコンピューターの選択を引数として受け取ります。
  3. プレイヤーが「rock」「ROCK」「RocK」など、さまざまなバリエーションを入力できるように、関数のhumanChoiceパラメータを大文字・小文字を区別しないようにしてください。
  4. playRound関数のコードを書いて、「You lose! Paper beats Rock」のような、ラウンドの勝者を表す文字列値をconsole.logで出力してください。
  5. ラウンドの勝者に基づいて、humanScoreまたはcomputerScore変数を増やしてください。

コード例:

function playRound(humanChoice, computerChoice) {
  // your code here!
}

const humanSelection = getHumanChoice();
const computerSelection = getComputerChoice();

playRound(humanSelection, computerSelection);

ステップ6: ゲーム全体をプレイするロジックを書く

あなたのゲームは5ラウンドプレイします。playRoundを呼び出して5ラウンドをプレイし、スコアを記録し、最後に勝者を発表するplayGameという名前の関数を書きます。

  1. playGameという名前の新しい関数を作成してください。
  2. playRound関数とスコア変数を移動し、新しいplayGame関数の中で宣言されるようにしてください。
  3. playRoundを5回呼び出して、5ラウンドをプレイしてください。
    • ヒント: 関数呼び出しを変数に代入すると、その関数の戻り値が変数に代入されます。その後変数にアクセスしても、代入された値が得られるだけで、関数が再度呼び出されるわけではありません。各ラウンドで新しい選択を得るには、選択の関数を再度呼び出す必要があります。
    • 必要であれば、以前の関数を作り直したり、ヘルパー関数をさらに作成したりしてください。特に、戻り値をより役立つものに変更したいと思うかもしれません。
    • すでにループについて知っているなら、それを使っても構いません。知らなくても心配いりません!ループは次のレッスンで扱います。
