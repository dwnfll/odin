オブジェクト

オブジェクトはJavaScript言語の非常に重要な一部であり、ほとんどの場合、単純な、あるいは中級レベルのタスクであれば、それらを気にしなくても達成できますが、あなたが取り組むことになる実際のプロジェクトはどれもオブジェクトを特徴とすることになります。JavaScriptにおけるオブジェクトの使い方は比較的すぐに深くなり得るため、今のところは基本だけを扱います。詳しい掘り下げは後で行います。

  2. MDNの「JavaScript object basics」を読んで一緒に進めてください。「Introducing constructors」セクションは、カリキュラムの後半で扱うより高度なトピックなので飛ばしてください。

オブジェクトとプリミティブの違い

カリキュラムの前半で、プリミティブ型について学びました。そして今、オブジェクト型も見てきました。これにはオブジェクト({key: value})、配列、関数などが含まれますが、それらに限られるわけではありません。この2つの主な違いは、プリミティブは単一のもの(文字列、数値など)しか含めないという点です。オブジェクト型は、データの集まりやより複雑な実体を保存するために使用されます。

形式的な違いに加えて、それぞれのデータ型をどう使うかに影響する技術的な違いもいくつかあります。プリミティブ変数を定義すると、それに与えられた情報のコピーを含むことになります:

let data = 42;
// dataCopy will store a copy of what data contains, so a copy of 42
let dataCopy = data;

// which means that making changes to dataCopy won't affect data
dataCopy = 43;

console.log(data); // 42
console.log(dataCopy); // 43

一方、オブジェクト変数を定義すると、それに与えられたオブジェクトへの参照を含むことになります:

// obj contains a reference to the object we defined on the right side
const obj = { data: 42 };
// objCopy will contain a reference to the object referenced by obj
const objCopy = obj;

// making changes to objCopy will make changes to the object that it refers to
objCopy.data = 43;

console.log(obj); // { data: 43 }
console.log(objCopy); // { data: 43 }

この振る舞いはあなたにとって初めてのものではありません。前回のプロジェクトでは、参照を使ってEtch-A-Sketchグリッドのセルに変更を加えました。このコードの断片を例に取ってみましょう:

const element = document.querySelector("#container");
element.style.backgroundColor = "red";

私たちは宣言した変数(element)を変更(mutate)していますが、その変更はDOM内の対応するノードに影響を与えます。なぜこれが起きるのでしょうか?私たちのコードにあるノードは、私たちのDOMが使用しているのと同じノードへの参照です。もしelementが参照ではなく、代わりにノード自体のコピーだったら(プリミティブ型がそうであるように)、それを変更しても何の効果もなかったでしょう。なぜなら、変更はコピーにしか影響せず、元のものには影響しないからです。

この振る舞いは、関数に引数を渡す際にも考慮すべきことです。以下の関数を例に取ってみましょう:

function increaseCounterObject(objectCounter) {
  objectCounter.counter += 1;
}

function increaseCounterPrimitive(primitiveCounter) {
  primitiveCounter += 1;
}

const object = { counter: 0 };
let primitive = 0;

increaseCounterObject(object);
increaseCounterPrimitive(primitive);

少し時間を取って、関数呼び出しを行った後、objectとprimitiveにそれぞれ何が起きるか予想してみてください。

オブジェクトのカウンターは1増え、プリミティブのカウンターは変わらないと答えたなら、それは正解です。パラメータobjectCounterは、私たちが渡したobject変数と同じオブジェクトへの参照を含んでいるのに対し、primitiveCounterはプリミティブな値のコピーしか含んでいないことを思い出してください。

オブジェクト型の変数を再代入する

複数の変数から参照されているオブジェクトを変更すると、それらの変数はすべて同じオブジェクトを参照しているため、その変更はすべての変数を通して見えるようになります。しかし、それらの変数の一つを新しいオブジェクトに再代入しても、他の変数が再代入されるわけではありません。例えば:

let animal = { species: "dog" };
let dog = animal;

// reassigning animal variable with a completely new object
animal = { species: "cat" };

console.log(animal); // { species: "cat" }
console.log(dog); // { species: "dog" }
