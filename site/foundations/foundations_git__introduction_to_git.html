A high level overview of what Git is and why it's so useful

イントロダクション

Gitは、あなたのファイルやディレクトリのための、まさに壮大な保存ボタンのようなものです。正式には、Gitはバージョン管理システムです。

テキストエディタでの保存は、ドキュメント内のすべての単語を1つのファイルとして記録します。複製を作らない限り(これは作成や管理を忘れがちです)、essay.docのようなファイルの記録は一つしか持てません:

essay-draft1.doc、essay-draft2.doc、essay-final.doc

しかし、Gitでの保存は、ファイルやフォルダの差分を記録し、それぞれの保存の履歴記録を保持します。この機能はゲームチェンジャーです。個人の開発者として、Gitはプロジェクトがどのように成長していくかを振り返ったり、過去のファイルの状態を簡単に確認したり復元したりすることを可能にしてくれます。ネットワークに接続すれば、Gitを使ってプロジェクトをGitHubや、Bitbucket、Beanstalk、GitLabといった他の選択肢にプッシュし、他の開発者と共有・協力できるようになります。

なお、私たちのカリキュラムでサポートしているのはGitHubのみであり、他の選択肢のトラブルシューティングは手伝いません。

Gitがあなたのローカルマシン上で動作する一方、GitHubはあなたのすべてのコーディングプロジェクトのための、ウェブ上のリモートストレージ施設です。つまり、Gitを学ぶことで、GitHub上で自分のポートフォリオを披露できるようになるということです!これは本当に重要なことです。なぜなら、ほとんどすべてのソフトウェア開発企業が、Gitを使えることを現代のウェブ開発者にとって不可欠なスキルとみなしているからです。GitHubのポートフォリオを持つことは、将来の雇用主候補にあなたが何をできるかの証拠を提供してくれます。

このレッスンでは、Gitの歴史、それが何であるか、そして何に役立つのかを簡単に見ていきます。

次のレッスンでは、Gitを使う際の基本的なワークフローを見ていきます。これにより理解が深まり、Gitがなぜそれほど便利なのかが分かるようになるはずです。

最後に、今後のプロジェクトのテンプレートとなる、Gitを使ったプロジェクトをセットアップします。

それでは、Gitとは何か、そしてなぜそれほど強力なのかを学んでいきましょう!
