HTMLとCSS

HTMLとCSSは、ウェブ上で何かを見るときに目にするすべてを作り出すために連携する、2つの言語です。HTMLは、ウェブページが作られる元となる生のデータです。テキスト、リンク、カード、リスト、ボタンはすべてHTMLで作られます。CSSは、それらの飾り気のない要素にスタイルを加えるものです。HTMLはウェブページに情報を配置し、CSSはその情報を配置し、色を付け、フォントを変え、見た目を良くしてくれます!

世の中の多くの優れたリソースが、HTMLとCSSをプログラミング言語と呼び続けていますが、厳密に言えば、それは正確な表現ではありません。なぜなら、それらは情報を提示することにしか関わっておらず、何らかのロジックをプログラムするために使われるものではないからです。次のセクションで学ぶJavaScriptは、ウェブページに何かをさせるために使われるため、プログラミング言語です。とはいえ、HTMLとCSSだけでもかなり多くのことができ、あなたはその両方を確実に必要とすることになります。以降のレッスンは、カリキュラムを進めてJavaScriptの内容にたどり着いたときに成功するために必要なツールを、あなたに提供することに重点を置いています!
