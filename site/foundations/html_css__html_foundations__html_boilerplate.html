HTML Boilerplate

日本語訳

Create your first HTML file.

イントロダクション

すべてのHTMLドキュメントは、何か役立つことをする前に整えておく必要がある、同じ基本構造、つまりボイラープレートを持っています。このレッスンでは、このボイラープレートのさまざまな部分を見ていき、それらがどのように組み合わさっているかを確認します。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • HTMLドキュメントの基本的なボイラープレートの書き方。
  • ブラウザでHTMLドキュメントを開く方法。

HTMLファイルを作成する

HTMLのボイラープレートを示すために、まず作業対象となるHTMLファイルが必要です。

コンピューター上に新しいフォルダを作成し、html-boilerplateという名前を付けてください。そのフォルダの中に新しいファイルを作成し、index.htmlという名前を付けてください。

あなたはおそらく、docファイル、pdfファイル、画像ファイルなど、すでに多くの種類のファイルに慣れ親しんでいることでしょう。

コンピューターにHTMLファイルを作成したいことを伝えるには、index.htmlファイルを作成したときのように、ファイル名の末尾に.html拡張子を付ける必要があります。

私たちがHTMLファイルにindexという名前を付けたことは、注目に値します。ウェブサイトのホームページとなるHTMLファイルには、常にindex.htmlという名前を付けるべきです。これは、ユーザーがあなたのウェブサイトにアクセスしたとき、ウェブサーバーがデフォルトでindex.htmlページを探すためです---それがないと、大きな問題を引き起こします。

DOCTYPE

すべてのHTMLページは、doctype宣言から始まります。doctypeの目的は、ドキュメントをレンダリングする際にどのバージョンのHTMLを使うべきかをブラウザに伝えることです。最新版のHTMLはHTML5であり、そのバージョンのdoctypeは<!DOCTYPE html>です。

より古いバージョンのHTMLのdoctypeは、もう少し複雑でした。例えば、これはHTML4のdoctype宣言です:

<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01 Transitional//EN" "http://www.w3.org/TR/html4/loose.dtd">

しかし、私たちが古いバージョンのHTMLを使いたくなることはおそらくないので、常に<!DOCTYPE html>を使用します。

先ほど作成したindex.htmlファイルをテキストエディタで開き、最初の行に<!DOCTYPE html>を追加してください。

HTML要素

doctypeを宣言した後、<html>要素を用意する必要があります。これはドキュメントのルート要素として知られているもので、ドキュメント内の他のすべての要素がその子孫になるということを意味します。

これは、後でJavaScriptを使ったHTMLの操作について学ぶときに、より重要になります。今のところは、<html>要素がすべてのHTMLドキュメントに含まれているべきだということだけ知っておいてください。

index.htmlファイルに戻って、開始タグと終了タグを入力することで<html>要素を追加しましょう。次のようにです:

<!DOCTYPE html>
<html lang="en">
</html>

ここでlangという単語に気づきましたか?これは、与えられたHTMLタグ(この場合は<html>)に関連付けられたHTML属性を表しています。これらの属性は、HTML要素についての追加情報を提供します。(HTML属性については次のレッスンで詳しく扱います。)

lang属性とは何か?

langは、その要素内のテキストコンテンツの言語を指定します。この属性は、主にウェブページのアクセシビリティを向上させるために使用されます。これにより、スクリーンリーダーなどの支援技術が言語に応じて適応し、正しい発音を呼び出すことができるようになります。

head要素

<head>要素は、私たちのウェブページについての重要なメタ情報や、ウェブページがブラウザで正しくレンダリングされるために必要なものを配置する場所です。 <head>の中では、ウェブページ上にコンテンツを表示するような要素を使うべきではありません。

index.htmlファイルに戻って、<meta>要素とtitleを含む<head>要素を追加しましょう。<head>要素は<html>要素の中に置かれ、常に開始<html>タグの直下の最初の要素であるべきです:

<!DOCTYPE html>

<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>My First Webpage</title>
  </head>
</html>

meta要素

<head>要素内には、常にウェブページの文字コードを指定する<meta>タグを含めておくべきです: <meta charset="UTF-8">。

エンコーディングを設定することは非常に重要です。なぜなら、それによってウェブページがブラウザ上でさまざまな言語の特殊記号や文字を正しく表示できるようになるからです。

title要素

HTMLドキュメントのheadに常に含めるべきもう一つの要素は、<title>要素です:

<title>My First Webpage</title>

<title>要素は、ウェブページに人間が読める形のタイトルを付けるために使われ、それはウェブページのブラウザタブに表示されます。例えば、現在のブラウザタブの名前を見ると、「HTML Boilerplate | The Odin Project」と表示されているはずです。これが現在の.htmlファイルの<title>です。

もし<title>要素を含めなかった場合、ウェブページのタイトルはデフォルトでファイル名になります。私たちの場合それはindex.htmlとなり、ユーザーにとってあまり意味のあるものではありません。これでは、ユーザーが多くのブラウザタブを開いている場合、私たちのウェブページを見つけるのが非常に難しくなってしまいます。

HTMLドキュメントのheadの中に配置できる要素は、他にもたくさんあります。しかし、今のところはここで扱った2つの要素について知っておくことだけが重要です。headに入る他の要素については、カリキュラムの残りの部分を通して紹介していきます。

body要素

HTMLのボイラープレートを完成させるために必要な最後の要素は、<body>要素です。ここには、ユーザーに表示されるすべてのコンテンツ---テキスト、画像、リスト、リンクなど---が入ります。

ボイラープレートを完成させるために、index.htmlファイルに<body>要素を追加してください。<body>要素も<html>要素の中に置かれ、常に<head>要素の下に来ます。次のようにです:

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>My First Webpage</title>
  </head>

  <body>
  </body>
</html>

ブラウザでHTMLファイルを表示する

この時点でindex.htmlファイル内のHTMLボイラープレートは完成していますが、これをブラウザで表示するにはどうすればよいのでしょうか?いくつかの異なる方法があります:

  • テキストエディタからHTMLファイルをブラウザのアドレスバーにドラッグ&ドロップできます。
  • Ctrl + O(macOSではCmd + O)を押してブラウザから直接ファイルを開き、HTMLファイルまで移動できます。
  • ファイルシステム内でHTMLファイルを見つけて、それをダブルクリックできます。これにより、システムが使用しているデフォルトのブラウザでファイルが開かれます。
  • ターミナルを使ってブラウザでファイルを開くこともできます:
    • Ubuntu: ファイルを含むディレクトリに移動し、google-chrome index.htmlと入力します。
    • macOS: ファイルを含むディレクトリに移動し、open ./index.htmlと入力します。
    • WSL: ファイルを含むディレクトリに移動し、explorer.exe index.htmlと入力します。これにより、システムのデフォルトブラウザでファイルが開かれます。なお、ファイル名だけを使用する必要があります。パス(例:./index.htmlや絶対パス)を使用すると、代わりにWindowsのファイルエクスプローラーが開いてしまいます。

Google Chromeを使用する

ブラウザ間のあらゆる違いに対応するためにレッスンの説明を分岐させることを避けるため、このコースの残りの部分では、Google Chromeを主要なブラウザとして使用します。ブラウザへの言及はすべて、特にGoogle Chromeを指すものとします。今後のすべてのテストにはGoogle Chromeを使用することを強くお勧めします。

上記の方法のいずれかを使って、私たちが取り組んできたindex.htmlファイルを開いてみてください。画面が空白であることに気づくでしょう。これは、bodyの中に表示するものが何もないためです。

index.htmlファイルに戻って、bodyに見出し(これについては後で詳しく扱います)を追加し、ファイルを保存しましょう:

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>My First Webpage</title>
  </head>

  <body>
    <h1>Hello World!</h1>
  </body>
</html>

さて、ブラウザでページを更新すると、変更が反映されているのが分かり、「Hello World!」という見出しが表示されるはずです。

VSCodeのショートカット

VSCodeには、ボイラープレートを一度にすべて生成するために使える組み込みのショートカットがあります。このショートカットは、.html拡張子のファイル、またはすでにHTML言語が選択されているテキストファイルを編集しているときにのみ機能することに注意してください。ショートカットを起動するには、index.htmlファイルの中身をすべて削除し、最初の行に!だけを入力してください。これにより、いくつかの選択肢が表示されます。Enterキーを押して最初のものを選ぶと、ほら、ボイラープレートがすべて自動で入力されているはずです。

このショートカットによって生成されたボイラープレートには、まだ触れていない行が含まれていることに気づくかもしれません:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

これは、さまざまな画面サイズに関わる高度なトピックであるレスポンシブデザインについて、カリキュラムのずっと後で扱うまでは知る必要のないものです。今のところは、その行はそのままにしておいて構いません。
