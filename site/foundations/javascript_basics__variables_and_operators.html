Variables and Operators 日本語訳

In this lesson we learn about variables and operators.

イントロダクション

前のセクションでは、HTMLを使ってウェブページを構造化し、CSSを使ってスタイルを付ける方法を学びました。次のステップは、ウェブページをインタラクティブにすることです。まさにこれこそがJavaScriptの目的です。

このセクションでは、JavaScriptの基礎と、それを使ってウェブページとユーザーの間のさまざまなやり取りをどう操作できるかに焦点を当てます。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • HTMLファイルを使ってJavaScriptコードを実行すること。
  • letとconstで変数を宣言すること。
  • 数値の演算を行うこと。
  • 文字列の演算を行うこと。
  • 論理演算子と算術演算子を使用すること。

JavaScriptコードを実行する方法

Foundationsコースの大部分で書くJavaScriptはすべて、ブラウザを通して実行されます。Foundationsの後のレッスンやNode.jsパスでは、ブラウザ環境の外でJavaScriptを実行する方法を紹介します。つまり、それが私たちが作成したファイルから来ているものであっても、ブラウザにコードを実行させるということです。

これらのレッスン以外では、今のところ、特に指定がない限り、常にブラウザでJavaScriptを実行することをデフォルトにしてください。そうしないと、予期しないエラーに遭遇する可能性があります。

始めるための最も簡単な方法は、JavaScriptコードを含むHTMLファイルを作成することです。VS Codeのスニペット! + TABを使って、コンピューター上のどこかのファイルに基本的なHTMLの骨組みを作成してください。<script>タグを必ず含めてください:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
<body>

  <script>
    // Your JavaScript goes here!
    console.log("Hello, World!")
  </script>

</body>
</html>

このファイルを保存してウェブブラウザで開き、それからブラウザのコンソールを開いてください:

  1. 空白のウェブページを右クリックしてください。
  2. 「検証」または「Inspect Element」をクリックして開発者ツールを開いてください。
  3. 「Console」タブを見つけて選択してください。そこにconsole.log文の出力が表示されるはずです。

ライブプレビュー

コードを編集した際に変更を見るために手動でページを更新する代わりに、Visual Studio CodeのLive Preview拡張機能を使えば、ファイルを保存したときに自動的にブラウザが更新されるようになります。テキストを編集して、何か別のことを表示させてみてください!

console.log()は、ブラウザの開発者コンソールに何かを出力するためのコマンドです。これを使って、以下の記事や演習の結果をコンソールに出力できます。このレッスンと今後のレッスンにあるすべての例について、一緒にコードを書いてみることをお勧めします。

ウェブページにJavaScriptを含めるもう一つの方法は、外部スクリプトを通すことです。これは、ウェブサイトに外部CSSファイルをリンクするのと非常によく似ています。

<script src="javascript.js"></script>

JavaScriptファイルには、スタイルシートの.cssと同様に、.jsという拡張子が付きます。外部JavaScriptファイルは、より複雑なスクリプトのために使用されます。

私たちはファイルにjavascript.jsという名前を付けましたが、my-script.jsやi-love-the-odin-project.jsのような、どんな名前を選んでもよかったのです。

変数

変数はあらゆるプログラムの構成要素です。変数は、コード内のデータのための「保管容器」だと考えることができます。

letキーワードを使って変数を宣言できます。実際に試してみましょう!(ダジャレのつもりはありません。)

let firstName = "John";
let lastName = "Doe";

console.log(firstName);
console.log(lastName);

console.logは何を出力するでしょうか?試してみてください!

変数を再代入することもできます:

let age = 11;
console.log(age); // outputs 11 to the console

age = 54;

console.log(age); // what will be output now?

4行目にletがないことに注目してください---変数はすでに前の行で宣言されており、ここでは単に再代入しているだけなので、letは必要ありません!

再代入もいいものですが、それが起きてほしくない場合はどうでしょうか?例えば、決して再代入する必要のない定数piがあるかもしれません。これはconstキーワードを使うことで実現できます。

const pi = 3.14;
pi = 10;

console.log(pi); // What will be output?

直感的には3.14が出力されると思うかもしれません。試してみてください!

エラーが発生します。console.logにすら到達しません!なぜ私たちがコード内でエラーを望むのか、疑問に思うかもしれません。実のところ、エラーは、私たちのコードの何が間違っていて、問題が正確にどこにあるのかを教えてくれる、非常に役立つものです。エラーがなければ、私たちのコードは望み通りに動作しないままですが、何が間違っているのかを見つけようとするのは非常に大変な作業になってしまいます!

つまり、まとめると、変数を宣言する方法は2つあります:

  • letは、再代入できます。
  • constは再代入できず、試みるとエラーが発生します。

3つ目の方法、varもあります。これはJavaScriptで変数を宣言する元々の方法でした。varは、この方法で代入された変数が再代入できるという点でletに似ていますが、言語がletとconstを導入した際に解消された、他の癖があります。今ではほとんど使われていません。しかし、どこかの時点でvarを使用しているコードに出会うことがあるかもしれないので、それが存在することを知っておくのは有用です。

数値

数値はプログラミングのロジックの構成要素です!実際、多少の基本的な計算を伴わない、役に立つプログラミングタスクを考えるのは難しいので、数値がどう機能するかを知ることは明らかに非常に重要です。幸いなことに、JavaScriptでは、数値の振る舞い方はかなり馴染み深いものです。

例えば、JavaScriptは標準的な数学の演算の順序に従います(PEMDASやBODMASのような頭字語でよく覚えられています)。つまり:

  1. 括弧(Parentheses/Brackets)が最初に評価されます。
  2. 次にべき乗(Exponentiation)が右から左に行われます。
  3. 次に乗算(Multiplication)と除算(Division)が左から右に行われます。
  4. 最後に加算(Addition)と減算(Subtraction)が左から右に行われます。

例えば、数式(3 + 2) - 76 * (1 + 1)は完全に有効なJavaScriptであり、この式をconsole.logに入れると、まさに期待通りに評価されます。

課題

HTMLファイルのscriptタグにコードを追加して、以下の演習に取り組んでみましょう:

  1. 2つの数値を足し合わせましょう!スクリプトの中でconsole.log(23 + 97)と入力してください。これを実行すると120が出力されるはずです。
  2. 同じことを、6つの異なる数値を足し合わせて行ってください。
  3. 次に、以下の式の値を出力してください:(4 + 6 + 9) / 77。コンソールにはおよそ0.24675が出力されるはずです。
  4. いくつか変数を使ってみましょう!
  5. scriptタグにこの文を追加してください:let a = 10。
  6. その下にconsole.log(a)を追加してください。これを実行すると、ブラウザのコンソールには10が出力されるはずです。
  7. その後、aに別の数値を再代入してください。その後もう一度aを出力すると、更新された値が表示されるはずです(前の出力は、aが再代入される前のものなので、古い値10のままのはずです)。
  8. 次に、スクリプトの一番下にlet b = 7 * aを追加してください。
  9. bが何であるかを出力してください。7に、あなたがaに再代入した値を掛けた結果が出力されるはずです。
  10. 次の手順を試してみてください:
  11. 値57を持つconst変数maxを宣言してください。
  12. 別のconst変数actualを宣言し、max - 13を代入してください。
  13. さらに別のconst変数percentageを宣言し、actual / maxを代入してください。
  14. percentageを出力すると、コンソールに0.7719のような値が表示されるはずです。
  15. 数分間、scriptタグの中でさまざまなことをいろいろ試してみてください。いずれ、実際にこれらのものをウェブページ上に表示させる方法を学びますが、このロジックはすべて変わりません。先に進む前に、これに十分慣れておいてください。
