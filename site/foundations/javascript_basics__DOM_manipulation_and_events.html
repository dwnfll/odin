イントロダクション

JavaScriptの最もユニークで便利な能力の一つが、DOMを操作する能力です。しかし、DOMとは何であり、どうやってそれを変更していくのでしょうか?早速始めましょう……

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • ウェブページとの関係においてDOMとは何かを説明する。
  • 「ノード」と「要素」の違いを説明する。
  • 「セレクタ」を使ってノードを対象にする方法を説明する。
  • DOMノードを見つけ、追加し、削除し、変更するための基本的なメソッドを説明する。
  • 「NodeList」と「ノードの配列」の違いを説明する。
  • 「バブリング」とは何か、どのように機能するかを説明する。

ドキュメントオブジェクトモデル

DOM(ドキュメントオブジェクトモデル)とは、ウェブページのコンテンツを木構造で表現したもの、つまり、HTMLドキュメント内でどのように配置されているかに応じてさまざまな関係を持つ「ノード」の木です。ノードには多くの種類がありますが、そのほとんどは一般的には使われません。このレッスンでは、DOMの操作に主に使われる「要素」ノードに焦点を当てます。

<div id="container">
  <div class="display"></div>
  <div class="controls"></div>
</div>

上記の例では、<div class="display"></div>は<div id="container"></div>の「子」であり、<div class="controls"></div>の「兄弟」です。家系図のようなものだと考えてください。<div id="container"></div>が親であり、その子が次のレベルにいて、それぞれが自分自身の「枝」にいます。

セレクタでノードを対象にする

DOMを扱う際は、「セレクタ」を使って作業したいノードを対象にします。CSSスタイルのセレクタと関係性プロパティを組み合わせて、目的のノードを対象にできます。まずはCSSスタイルのセレクタから始めましょう。上記の例では、<div class="display"></div>を参照するために以下のセレクタを使用できます:

  • div.display
  • .display
  • #container > .display
  • div#container > div.display

ノードが持つ特別なプロパティを使って、リレーショナルセレクタ(つまりfirstElementChildやlastElementChildなど)を使用することもできます。

// selects the #container div (don't worry about the syntax, we'll get there)
const container = document.querySelector("#container");

// selects the first child of #container => .display
const display = container.firstElementChild;
console.log(display);  // <div class="display"></div>
// selects the .controls div
const controls = document.querySelector(".controls");

// selects the prior sibling => .display
const display = controls.previousElementSibling;
console.log(display); // <div class="display"></div>

つまり、周囲のノードとの関係性に基づいて、特定のノードを特定しているのです。

JavaScriptのオブジェクト

変数の後にドット(.)記法が続いているのはなぜだろうと疑問に思っているかもしれません。例えば、container.firstElementChildのようにです。

これは、JavaScriptでオブジェクトにアクセスする方法です。JavaScriptにおけるオブジェクトとは、プロパティを保持するデータ型です。プロパティとは「キー:値」のペアです。例えば、私たちのcontainerは多くのプロパティを含んでおり、firstElementChildキーにアクセスすることで、その最初の子要素にアクセスし、値を取得できます。この場合、その値はdisplayクラスを持つ<div>要素です。

今のところ、JavaScriptのオブジェクトについて知っておく必要があるのはこれだけです。詳しくはObjects Basicsのレッスンをお楽しみに!

DOMメソッド

あなたのHTMLコードがウェブブラウザによってパースされると、上記で述べた通りDOMに変換されます。主な違いの一つは、これらのノードが、多くのプロパティやメソッドが付随したJavaScriptオブジェクトであるということです。これらのプロパティやメソッドが、JavaScriptを使ってウェブページを操作するために私たちが使用する主要なツールです。

クエリセレクタ

  • element.querySelector(selector) - selectorに最初に一致するものへの参照を返します。
  • element.querySelectorAll(selectors) - selectorsに一致するすべてのものへの参照を含む「NodeList」を返します。

パフォーマンスに関する考慮事項

他にも、潜在的な(わずかな)パフォーマンス上の利点をもたらす、より具体的なクエリがいくつかありますが、今はそれらについて扱いません。

querySelectorAllを使用する場合、戻り値は配列ではないことを覚えておくのが重要です。配列のように見え、いくらか配列のように振る舞いますが、実際には「NodeList」です。大きな違いは、いくつかの配列メソッドがNodeListには存在しないことです。問題が発生した場合の一つの解決策は、NodeListを配列に変換することです。これはArray.from()またはスプレッド演算子を使って行えます。

要素の作成

  • document.createElement(tagName, [options]) - タグタイプtagNameの新しい要素を作成します。この場合の[options]は、関数にいくつかの任意のパラメータを追加できることを意味します。この時点では、これらについて気にしなくて構いません。
const div = document.createElement("div");

この関数は、新しい要素をDOMに配置する「わけではありません」---メモリ内にそれを作成するだけです。これは、ページに配置する前に、その要素を(スタイル、クラス、id、テキストなどを追加して)操作できるようにするためです。以下のいずれかのメソッドを使って、要素をDOMに配置できます。

要素の追加

  • parentNode.appendChild(childNode) - childNodeをparentNodeの最後の子として追加します。
  • parentNode.insertBefore(newNode, referenceNode) - newNodeをparentNodeの中のreferenceNodeの前に挿入します。

要素の削除

  • parentNode.removeChild(child) - DOM上のparentNodeからchildを削除し、childへの参照を返します。

要素の変更

要素への参照を持っている場合、その参照を使ってその要素自身のプロパティを変更できます。これにより、属性の追加・削除・変更、クラスの変更、インラインスタイル情報の追加など、多くの便利な変更を行うことができます。

// creates a new div referenced in the variable 'div'
const div = document.createElement("div");

インラインスタイルの追加

// sets the indicated style rule to the element in the div variable
div.style.color = "blue";

// set the entire inline style
div.setAttribute("style", "color: blue; background: white;");

background-colorのようなケバブケースのCSSプロパティにJSでアクセスする場合、ドット記法ではcamelCaseを使うか、あるいはブラケット記法を使う必要があります。ブラケット記法を使う場合は、camelCaseとkebab-caseのどちらも使用できますが、プロパティ名は文字列でなければなりません。

// dot notation with kebab case: doesn't work as it attempts to subtract color from div.style.background
// equivalent to: div.style.background - color
div.style.background-color;

// dot notation with camelCase: works, accesses the div's background-color style
div.style.backgroundColor;

// bracket notation with kebab-case: also works
div.style["background-color"];

// bracket notation with camelCase: also works
div.style["backgroundColor"];

属性の編集

// if id exists, update it to 'theDiv', else create an id with value "theDiv"
div.setAttribute("id", "theDiv");

// returns value of specified attribute, in this case "theDiv"
div.getAttribute("id");

// removes specified attribute
div.removeAttribute("id");

利用可能な属性についての詳細は、MDNのHTML Attributesのセクションを参照してください。

クラスを扱う

// adds class "new" to your new div
div.classList.add("new");

// removes "new" class from div
div.classList.remove("new");

// if div doesn't have class "active" then add it, or if it does, then remove it
div.classList.toggle("active");

インラインCSSを追加・削除するよりも、CSSスタイルをトグルする方が一般的(かつよりクリーン)であることがよくあります。

テキストコンテンツの追加

// creates a text node containing "Hello World!" and inserts it in div
div.textContent = "Hello World!";

HTMLコンテンツの追加

// renders the HTML inside div
div.innerHTML = "<span>Hello World!</span>";

innerHTMLのセキュリティリスク

テキストを追加する際は、innerHTMLよりもtextContentを使う方が好ましいです。潜在的なセキュリティリスクを避けるため、innerHTMLは控えめに使うべきだからです。 innerHTMLを使うことの危険性を理解するために、最も一般的なクロスサイトスクリプティング攻撃を防ぐことについての動画を見てみてください。

少し時間を取って、これまで扱ってきたことを復習し、先に進む前にこれらのことを練習する機会を持ちましょう。ウェブページにDOM要素を作成して追加する、以下の例を見てみてください。

<!-- your HTML file: -->
<body>
  <h1>THE TITLE OF YOUR WEBPAGE</h1>
  <div id="container"></div>
</body>
// your JavaScript file
const container = document.querySelector("#container");

const content = document.createElement("div");
content.classList.add("content");
content.textContent = "This is the glorious text-content!";

container.appendChild(content);

JavaScriptファイルでは、まず私たちのHTMLにすでに存在するcontainerdivへの参照を取得します。それから新しいdivを作成し、contentという変数に保存します。contentdivにクラスといくつかのテキストを追加し、最後にそのdivをcontainerに追加します。JavaScriptコードが実行された後、私たちのDOMツリーは次のようになります:

<!-- The DOM -->
<body>
  <h1>THE TITLE OF YOUR WEBPAGE</h1>
  <div id="container">
    <div class="content">This is the glorious text-content!</div>
  </div>
</body>

JavaScriptはあなたのHTMLを変更する「のではなく」、DOMを変更するということを心に留めておいてください---あなたのHTMLファイルは同じままですが、JavaScriptはブラウザがレンダリングするものを変更します。

JavaScriptのタイミング

あなたのJavaScriptは、ほとんどの場合、JSファイルが実行されるとき、あるいはHTML内でscriptタグに出くわしたときに実行されます。JavaScriptをファイルの先頭に含めている場合、ノードがDOMに作成される「前に」JSコードが実行されてしまうため、これらのDOM操作メソッドの多くは機能しません。これを修正する最も簡単な方法は、HTMLファイルの下部にJavaScriptを含めることで、DOMノードがパースされ作成された後に実行されるようにすることです。

あるいは、HTMLドキュメントの<head>内でJavaScriptファイルをリンクすることもできます。JSファイルへのパスを含むsrc属性を持つ<script>タグを使用し、HTMLがパースされた「後で」ファイルを読み込むためにdeferキーワードを含めます。次のようにです:

<head>
  <script src="js-file.js" defer></script>
</head>

scriptタグのdefer属性について詳しく知ってみましょう。

演習

上記の例を自分のコンピューター上のファイルにコピーしてください。動くようにするには、残りのHTMLの骨組みを用意し、JavaScriptファイルをリンクするか、ページ上のscriptタグにJavaScriptを入れる必要があります。先に進む前に、すべてが動作していることを確認してください!

JavaScriptと上記で示したDOMメソッドのみを使って、以下の要素をcontainerに追加してください:

  1. 「Hey I'm red!」と表示される赤いテキストの<p>。
  2. 「I'm a blue h3!」と表示される青いテキストの<h3>。
  3. 黒いborderとピンクの背景色を持ち、中に以下の要素が入った<div>:
    • 「I'm in a div」と表示される別の<h1>。
    • 「ME TOO!」と表示される<p>。
    • これについてのヒント:createElementで<div>を作成した後、containerに追加する前に、その中に<h1>と<p>を追加してください。

イベント

JavaScriptでDOMを操作するコツをつかんだところで、次のステップは、それを動的に、あるいは必要に応じて起こす方法を学ぶことです!イベントは、あなたのページでその魔法を起こす方法です。イベントとは、マウスクリックやキー押下のような、ウェブページ上で発生する動作のことです。JavaScriptを使うことで、私たちのウェブページにこれらのイベントを監視させ、反応させることができます。

これを行うための主な方法は3つあります:

  • HTML要素に直接、関数属性を指定できます。
  • JavaScriptの中で、DOMノードにonclickやonmousedownのようなon<eventType>という形式のプロパティを設定できます。
  • JavaScriptの中で、DOMノードにイベントリスナーを取り付けることができます。

イベントリスナーは間違いなく望ましい方法ですが、他の方法も定期的に使われているのを見ることになるので、3つすべてを扱います。

クリックするとすべて「Hello World」とアラートを表示する3つのボタンを作成します。自分のHTMLファイルを使うか、CodePenのようなものを使って、すべて試してみてください。

方法1

<button onclick="alert('Hello World')">Click Me</button>

この解決策は理想的とは言えません。私たちのHTMLをJavaScriptで散らかしてしまっているからです。また、1つのDOM要素に設定できる「onclick」プロパティは1つだけなので、この方法ではクリックイベントに応じて複数の別々の関数を実行することはできません。

方法2

<!-- the HTML file -->
<button id="btn">Click Me</button>
// the JavaScript file
const btn = document.querySelector("#btn");
btn.onclick = () => alert("Hello World");

アロー関数の構文の復習

アロー構文() =>を復習する必要がある場合は、このアロー関数についての記事を確認してください。

これは少し良くなりました。JSをHTMLから取り出してJSファイルに移しましたが、それでもDOM要素は「onclick」プロパティを1つしか持てないという問題が残っています。

方法3

<!-- the HTML file -->
<button id="btn">Click Me Too</button>
// the JavaScript file
const btn = document.querySelector("#btn");
btn.addEventListener("click", () => {
  alert("Hello World");
});

これで、関心の分離が保たれ、必要であれば複数のイベントリスナーも許可されます。方法3は、セットアップが少し複雑にはなりますが、はるかに柔軟で強力です。

これら3つの方法はすべて、次のように名前付き関数と一緒に使用できることに注意してください:

<!-- the HTML file -->
<!-- METHOD 1 -->
<button onclick="alertFunction()">CLICK ME BABY</button>
// the JavaScript file
// METHOD 1
function alertFunction() {
  alert("YAY! YOU DID IT!");
}
<!-- the HTML file -->
<!-- METHODS 2 & 3 -->
<button id="btn">CLICK ME BABY</button>
// the JavaScript file
// METHODS 2 & 3
function alertFunction() {
  alert("YAY! YOU DID IT!");
}
const btn = document.querySelector("#btn");

// METHOD 2
btn.onclick = alertFunction;

// METHOD 3
btn.addEventListener("click", alertFunction);

名前付き関数を使うことで、コードをかなりきれいにでき、複数の場所で行いたい処理であれば本当に良い考えです。

これら3つの方法すべてにおいて、呼び出している関数にパラメータを渡すことで、イベントについてのより多くの情報にアクセスできます。自分のマシンで試してみてください:

btn.addEventListener("click", function (e) {
  console.log(e);
});

コールバックを理解する

alertFunctionやfunction (e) {...}をaddEventListenerの引数として渡すとき、これをcallback(コールバック)と呼びます。コールバックとは、単に別の関数に引数として渡される関数のことです。

そのコールバック関数のeパラメータには、イベント自体を参照するオブジェクトが含まれています。そのオブジェクトの中では、どのマウスボタンやキーが押されたか、あるいはイベントのtarget(クリックされたDOMノード)についての情報など、多くの便利なプロパティやメソッド(オブジェクトの中に存在する関数)にアクセスできます。eという名前や、それがどこから来ているかについて、魔法のようなことは何もありません。JavaScriptがそのパラメータをイベントだと分かるのは、イベントリスナーのコールバックが定義上Eventオブジェクトを受け取るからです。コールバックが実行されると、イベントハンドラが自身のイベントへの参照を渡します。イベントオブジェクトについてはMDNのイベント入門でさらに詳しく読むことができます。

これを試してみましょう:

btn.addEventListener("click", function (e) {
  console.log(e.target);
});

そして次にこれを:

btn.addEventListener("click", function (e) {
  e.target.style.background = "blue";
});

なかなかクールでしょう?

ノードのグループにリスナーを取り付ける

多くの要素に似たようなイベントリスナーをたくさん取り付ける場合、これはかなりの量のコードのように思えるかもしれません。それをより効率的に行う方法がいくつかあります。上記で、querySelectorAll('selector')を使って、特定のセレクタに一致するすべての項目のNodeListを取得できることを学びました。それぞれにリスナーを追加するには、リスト全体を反復処理する必要があります。次のようにです:

<div id="container">
  <button id="one">Click Me</button>
  <button id="two">Click Me</button>
  <button id="three">Click Me</button>
</div>
// buttons is a node list. It looks and acts much like an array.
const buttons = document.querySelectorAll("button");

// we use the .forEach method to iterate through each button
buttons.forEach((button) => {
  // and for each one we add a 'click' listener
  button.addEventListener("click", () => {
    alert(button.id);
  });
});

これはDOM操作とイベント処理に関しては氷山の一角にすぎませんが、いくつかの演習を始めるには十分です。ここまでの例では、もっぱら「click」イベントを使ってきましたが、他にもたくさんのイベントが利用できます。

役立つイベントには以下のようなものがあります:

  • click
  • dblclick
  • keydown
  • keyup

各イベントの説明付きのより完全なリストは、W3SchoolsのJavaScript Event Referenceページにあります。
