Block and Inline

日本語訳

← foundations

Learn about two common CSS display modes.

イントロダクション

前のレッスンでは、異なるdisplayタイプはそれぞれ独自のボックスモデルを持っていること、そしてbox-sizingプロパティを変更することでボックスの計算方法を変更できることを学びました。CSSにはblockとinlineという2種類のボックスタイプがあり、これらが要素の振る舞いと相互作用を決定します。displayプロパティは、HTML要素がウェブページ上にどのように表示されるかを制御します。このレッスンでは、そのさまざまなオプションについてさらに詳しく見ていきます。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • 「通常のフロー(Normal flow)」について学びます。
  • block要素とinline要素の違いを学びます。

  • divとspanとは何かを学びます。

ブロックとインライン

これまでに学んできた要素のほとんどは、ブロック要素です。言い換えると、それらのデフォルトのスタイルはdisplay: blockです。デフォルトでは、ブロック要素はページ上で互いに積み重なるように表示され、新しい要素はそれぞれ新しい行から始まります。

しかし、インライン要素は新しい行から始まりません。それらは、隣に配置されている要素と同じ行の中に表示されます。インライン要素の分かりやすい例は、リンク、つまり<a>タグです。これをテキストの段落の途中に置くと、リンクはその段落の一部であるかのように振る舞います。さらに、paddingとmarginはインライン要素上では異なる振る舞いをします。一般的に、インライン要素に余分なpaddingやmarginを付けようとするのは避けるべきです。

中間的な存在、inline-block

inline-block要素はインライン要素のように振る舞いますが、ブロックスタイルのpaddingとmarginを持ちます。display: inline-blockは知っておくと便利なツールですが、実際には、多数のボックスを並べようとする場合、おそらくもっと頻繁にflexboxに手を伸ばすことになるでしょう。flexboxについては次のレッスンで詳しく扱います。

divとspan

ウェブページを構築する際、すべてのコンテンツが特定のセマンティックタグを持っているわけではありません。時には、スタイルや配置ができるコンテナだけが必要なこともあります!そこで登場するのがdivとspanです。

divは汎用のブロックレベルコンテナです。デフォルトでは、その親の幅いっぱいに広がり、新しい行から始まる、長方形のセクションのように振る舞います。通常、divはカード、セクション、サイドバー、ナビゲーションバーのグループ化など、ページコンポーネント内の関連する要素をグループ化するために使用します。

この場合、コンテンツをdivで囲み、classやidを付けることで、CSSのレイアウトやスタイリングのための便利なフックを作ることができます!

See the Pen block-inline-lesson-div-example by TheOdinProject (@TheOdinProjectExamples) on CodePen.

spanは汎用のインラインコンテナです。テキストの行の中に収まり、そのコンテンツと同じだけのスペースしか占有しません。divとは異なり、新しい行から始まることはありません。文章の一部だけをスタイリングしたり対象にしたりしたいときにspanを使用します。例えば、単一の単語を強調表示したり、フレーズにツールチップを付けたりしたい場合、それをspanで囲み、classやidを追加することで、CSSがそれを見つけて操作できるようになります。

See the Pen block-inline-lesson-span-example by TheOdinProject (@TheOdinProjectExamples) on CodePen.

divもspanも、セマンティックタグのようにコンテンツに意味を加えるものではありません。それらは、柔軟な「構成要素」を提供するために存在しているからです。重要な違いは、レイアウトの中でどう振る舞うかです。divはブロックレベル要素としてフローに参加し、spanはインライン要素として振る舞います。それさえ理解すれば、どちらを使うかを選ぶのは簡単です!より大きなコンテンツのブロックをグループ化して配置する場合はdivを、行の中の小さな部分をスタイリングしたりスクリプトで操作したりする場合はspanを使用できます。

課題

  1. 「通常のフロー(Normal flow)」という概念は、ボックスモデルのリソースの中で暗に示されてはいますが、それほど明確には説明されていません。要素がデフォルトでどのように自分自身を配置するかを確実に理解するために、MDNの「Normal Flow」を読んでみてください。
  2. W3schoolsの「HTML Block and Inline Elements」には、すべてのデフォルトのブロック要素とインライン要素についての説明と一覧があります。
  3. Digital Oceanのチュートリアル「Inline vs Inline-block Display in CSS」には、inlineとinline-blockの違いを明確にしてくれる、いくつかの優れた例があります。
