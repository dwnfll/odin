Use CSS selectors to pick elements to style.

イントロダクション

前のレッスンでは、ウェブページの構造を決めるHTMLの書き方を学びました。次のステップは、その構造に何らかのスタイルを加えて見栄えを良くすることです。まさにこれこそがCSSの目的です。これから数レッスンでは、初めて学ぶ人にも、復習が必要な人にも、誰もが最初から知っておくべきだと私たちが考える、基礎的なCSSの概念に焦点を当てていきます。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • CSSを使ってHTMLにスタイルを追加すること。
  • class属性とid属性の使い方。
  • さまざまなCSSセレクタがどのように機能するか。

HTMLにCSSを追加する

CSSルールの書き方を学ぶ前に、まずはindex.htmlにCSSファイルをリンクしておき、このレッスンを通してすべての例を実際に試せるようにしましょう。

HTMLにCSSを追加する方法は3つあります:

  • 外部CSS
  • 内部CSS
  • インラインCSS

今のところは外部CSSに焦点を当てます。これが最もよく使うことになる方法だからです。残りの2つの方法は、このレッスンの後半で扱います。

外部CSS

外部CSSは、あなたが最もよく出会うことになる方法であり、CSS用に別のファイルを作成し、それをHTMLの中でリンクすることを伴います。

<!-- index.html -->

<head>
  <link rel="stylesheet" href="styles.css">
</head>

まず、HTMLファイルの開始<head>タグと終了<head>タグの中に、ボイド要素である<link>要素を追加します。href属性はCSSファイルの場所であり、この例ではHTMLファイルの場所から見た相対パスですが、他のどこかでホストされているスタイルシートへのURLのようなものでも構いません。上記の例では、両方のファイルが同じディレクトリにあることを前提としています。rel属性は必須であり、HTMLファイルとリンクされたファイルの間の関係を指定します。

次に、index.htmlファイルと同じディレクトリに、空のstyles.cssファイルを作成します。次のセクションから、このファイルにCSSルールを追加し始めます。

CSSファイル名

styles.cssは、ここでファイル名として採用したものにすぎません。ファイルタイプが.cssである限り、好きな名前を付けることができます。「style」や「styles」は、単に最もよく使われているというだけです。

この方法のメリットのいくつかは以下の通りです:

  1. HTMLとCSSが分離された状態を保てるため、HTMLファイルが小さくなり、見た目もすっきりします。
  2. CSSを編集する必要があるのは1か所だけで済みます。これは、似たようなスタイルを共有する多くのページを持つウェブサイトにとって特に便利です。

CSSルールの書き方を学ぶ助けとして、まず(いつものボイラープレートを含む)index.htmlファイルと、同じディレクトリにstyles.cssファイルを作成し、上記で説明した通りに両方のファイルをリンクさせましょう。

基本構文

最も基本的なレベルでは、CSSはさまざまなルールで構成されています。各ルールは、セレクタ(これについては後ほど詳しく説明します)と、セミコロンで区切られた宣言のリストで構成されており、それぞれの宣言はプロパティと値のペアで構成されています。

セマンティックHTML

<div>は基本的なHTML要素の一つです。これは空のコンテナです。一般的に、プロジェクトのコンテンツには<h1>や<p>のような他のタグを使うのが最善ですが、CSSについてさらに学んでいくと、必要なのが他の要素のためのただのコンテナである場合が多くあることに気づくでしょう。私たちの演習の多くは、シンプルさのために単純な<div>を使用しています。後のレッスンでは、さまざまなHTML要素をいつ使うのが適切かについて、さらに深く掘り下げます。

セレクタ

セレクタとは、CSSルールが適用されるHTML要素のことを指し、各ルールについて実際に「選択」されているものです。以下のサブセクションはすべての利用可能なセレクタを網羅しているわけではありませんが、断然最もよく使われるものであり、あなたが最初に使いこなせるようになっておくべきものです。

それぞれの例を進めながら、HTMLとCSSの両方をそれぞれのファイルに追加して結果を確認し、いろいろ試してみてください。

ユニバーサルセレクタ

ユニバーサルセレクタは(ドキュメント全体にあるような)あらゆるタイプの要素を選択します。「ユニバーサル(万能)」という名前の由来もそこにあり、その構文は単純なアスタリスクです。以下の例では、すべての要素にcolor: purple;スタイルが適用されます。

* {
    color: purple;
}

タイプセレクタ

タイプセレクタ(または要素セレクタ)は、指定された要素タイプのすべての要素を選択します。構文は単にその要素の名前です:

<!-- index.html -->

<div>Hello, World!</div>
<div>Hello again!</div>
<p>Hi...</p>
<div>Okay, bye.</div>
/* styles.css */

div {
  color: white;
}

ここでは、3つの<div>要素すべてが選択されますが、<p>要素は選択されません。

クラスセレクタ

クラスセレクタは、指定されたクラスを持つすべての要素を選択します。クラスとは、HTML要素に付ける単なる属性です。HTMLタグにクラスを追加し、CSSでそれを選択する方法は次の通りです:

<!-- index.html -->

<div class="alert-text">Please agree to our terms of service.</div>
/* styles.css */

.alert-text {
  color: red;
}

クラスセレクタの構文に注目してください。ピリオドの直後に、大文字小文字を区別するclass属性の値が続きます。クラスは特定の要素に固有である必要はないため、同じクラスをいくつでも好きなだけ多くの要素に使用できます。

先頭が数字のクラス

クラス名が数字から始まる場合、クラスセレクタは機能しません。例えば、要素に4lert-textというクラス名を付けた場合、セレクタとして.4lert-textを使っても一致しません。

class属性でできるもう一つのことは、class="alert-text severe-alert"のように、1つの要素にスペース区切りのリストとして複数のクラスを追加することです。このように空白がクラス名の区切りとして使われるため、複数の単語からなる名前にスペースを使ってはならず、代わりにハイフンを使うべきです。

IDセレクタ

IDセレクタはクラスセレクタと似ています。指定されたIDを持つ要素を選択します。IDも、HTML要素に付けるもう一つの属性です。クラスとIDの大きな違いは、1つの要素は1つのIDしか持てないということです。同じページ内でIDを繰り返すことはできず、空白を含めるべきではありません:

<!-- index.html -->

<div id="title">My Awesome 90's Page</div>
/* styles.css */

#title {
  background-color: red;
}

IDの場合、ピリオドの代わりにハッシュ記号を使い、その直後に大文字小文字を区別するid属性の値が続きます。よくある落とし穴は、必ずしも必要でなく、クラスで十分な場合でもid属性を使いすぎてしまうことです。詳細度を活用したり、現在のページ内のセクションにリンクをリダイレクトさせたりする場合など、IDを使うのが理にかなっている、あるいは必要なケースもありますが、IDの使用は控えめに(できれば使わないように)すべきです。

先頭が数字のID

クラスセレクタと同様に、IDセレクタも数字から始めることはできません。例えば、要素に7itleというIDを付けた場合、セレクタ#7itleは機能しません---これは有効なCSSセレクタではないためです。

グルーピングセレクタ

スタイル宣言の一部を共有する2つの要素グループがある場合はどうすればよいでしょうか?

.read {
  color: white;
  background-color: black;
  /* several unique declarations */
}

.unread {
  color: white;
  background-color: black;
  /* several unique declarations */
}

.readセレクタと.unreadセレクタは、どちらもcolor: white;とbackground-color: black;という宣言を共有していますが、それ以外にはそれぞれ独自の宣言をいくつか持っています。この繰り返しを減らすために、これら2つのセレクタをカンマ区切りのリストとしてグループ化できます:

.read,
.unread {
  color: white;
  background-color: black;
}

.read {
  /* several unique declarations */
}

.unread {
  /* several unique declarations */
}

上記の両方の例(グループ化ありとなし)は同じ結果になりますが、2つ目の例は宣言の繰り返しを減らし、両方のクラスのcolorやbackground-colorを一度に編集しやすくしてくれます。

セレクタのチェイン

セレクタを使うもう一つの方法は、区切りなしのリストとしてチェイン(連結)することです。次のようなHTMLがあるとしましょう:

<div>
  <div class="subsection header">Latest Posts</div>
  <p class="subsection preview">This is where a preview for a post might go.</p>
</div>

何らかの独自のスタイルを持つ、subsectionクラスを持つ2つの要素があります。しかし、headerを2番目のクラスとしても持つ要素にだけ、別のルールを適用したい場合はどうすればよいでしょうか?その場合、CSSで両方のクラスセレクタを次のようにチェインさせることができます:

.subsection.header {
  color: red;
}

.subsection.headerが行うのは、subsectionとheaderの両方のクラスを持つ要素を選択することです。.subsectionと.headerのクラスセレクタの間にスペースがないことに注目してください。この構文は、基本的にどのようなセレクタの組み合わせをチェインする場合にも機能しますが、複数のタイプセレクタをチェインする場合は例外です。

これは、以下のようにクラスとIDをチェインするためにも使用できます:

<div>
  <div class="subsection header">Latest Posts</div>
  <p class="subsection" id="preview">
    This is where a preview for a post might go.
  </p>
</div>

上記の2つの要素を、以下のようにして組み合わせることができます:

.subsection.header {
  color: red;
}

.subsection#preview {
  color: blue;
}

一般的に、1つの要素は同時に2つの異なるタイプになることはできないため、複数のタイプセレクタをチェインすることはできません。例えば、divとpのような2つのタイプセレクタをチェインすると、divpというセレクタになってしまいますが、これは存在しない文字通りの<divp>要素を探そうとしてしまうため、機能しません。

子孫結合子

結合子(コンビネータ)を使うと、グループ化やチェインとは異なる形で複数のセレクタを組み合わせることができます。セレクタ間の関係を示すことができるからです。結合子には全部で4種類ありますが、今のところは子孫結合子だけを紹介します。これはCSSではセレクタ間の1つのスペースで表されます。子孫結合子は、直前のセレクタに一致する祖先(親、祖父母など)を持つ場合に限り、最後のセレクタに一致する要素を選択します。

つまり、.ancestor .childのようなセレクタは、ancestorクラスを持つ祖先がある場合に、childクラスを持つ要素を選択します。別の考え方をすると、childは、そのネストがどれだけ深くても、ancestorの中にネストされている場合にのみ選択されるということです。以下の例をざっと見て、与えられたCSSルールに基づいてどの要素が選択されるか分かるか試してみてください:

<!-- index.html -->

<div class="ancestor">
  <div class="contents">
    <div class="contents"></div>
  </div>
</div>

<div class="contents"></div>
/* styles.css */

.ancestor .contents {
  /* some declarations */
}

上記の例では、contentsクラスを持つ最初の2つの要素(4行目と5行目)が選択されますが、最後の要素(9行目)は選択されません。あなたの予想は合っていましたか?

1つのルールに追加できる結合子の数には、実際のところ制限がありません。したがって.one .two .three .fourも完全に有効です。これは単に、threeクラスを持つ祖先があり、さらにその祖先自身がtwoクラスを持つ祖先を持つ、といった具合の場合に、fourクラスを持つ要素を選択するというだけのことです。しかし、このレベルのネストを必要とする要素を選択しようとするのは、一般的には避けたいところです。かなり分かりにくく長くなりがちですし、詳細度に関して問題を引き起こすこともあるからです。

最初に押さえておくべきプロパティ

常に使うことになる、あるいは少なくとも使うことの方が多いCSSプロパティがいくつかあります。これから、そうしたプロパティのいくつかを紹介しますが、これは決して完全なリストではありません。以下のプロパティを学べば、始めるのに十分です。すべてのプロパティにはデフォルトの初期値があり、あなたもブラウザも別の値を設定していない場合はその値が使われることに注意してください(各CSSプロパティのMDNドキュメントに詳細が記載されています)。

colorとbackground-color

colorプロパティは要素のテキストの色を設定し、background-colorは、まあ、要素の背景色を設定します。これでもう終わりでしょうか?

ほぼそうですが、まだあります。これらのプロパティはどちらも、いくつかの種類の値のうちの一つを受け付けます。よくあるのはキーワードで、redのような実際の色名や、transparentキーワードなどです。また、HEX、RGB、HSLの値も受け付けます。これらは、Photoshopのようなプログラムや、プロフィールの色をカスタマイズできるサイトを使ったことがあれば、馴染みがあるかもしれません。

p {
  /* hex example: */
  color: #1100ff;
}

p {
  /* rgb example: */
  color: rgb(100, 0, 127);
}

p {
  /* hsl example: */
  color: hsl(15, 82%, 56%);
}

アルファ値を追加することでこれらの色の不透明度をどう調整できるかを知るために、CSS Legal Color Valuesをざっと見てみてください。

タイポグラフィの基本とtext-align

font-familyは、要素がどのフォントを使うかを決める、単一の値、あるいはカンマ区切りの値のリストです。各フォントは2つのカテゴリのいずれかに分類されます。"Times New Roman"のような「フォントファミリー名」(単語間に空白があるため引用符を使用します)か、serifのような「ジェネリックファミリー名」(ジェネリックファミリー名には引用符を使いません)です。

ブラウザがリストの最初のフォントを見つけられない、あるいはサポートしていない場合、次のフォント、さらにその次のフォントというように、サポートされている有効なフォントが見つかるまで使用していきます。そのため、このプロパティには、最も使いたいフォントから始めて、フォールバックとしてジェネリックフォントファミリーで終わる値のリストを含めるのがベストプラクティスです。例:font-family: "Times New Roman", serif;

font-sizeは、プロパティ名が示す通り、フォントのサイズを設定します。このプロパティに値を指定する際、その値に空白を含めてはいけません。例えばfont-size: 22pxでは、「22」と「px」の間にスペースがありません。

font-weightは、フォントが指定されたウェイトをサポートしていることを前提に、テキストの太さに影響します。この値はキーワード、例えばfont-weight: bold、あるいは1から1000までの数値、例えばfont-weight: 700(boldと同等)にできます。通常、数値は100刻みで900までですが、これはフォントによって異なります。

text-alignは、要素内でテキストを水平方向に揃えます。このプロパティの値には、ワープロソフトで見かけたことがあるかもしれない一般的なキーワードを使用できます。例:text-align: center。

画像のheightとwidth

heightとwidthを調整できる要素は画像だけではありませんが、今回は特に画像に焦点を当てたいと思います。

デフォルトでは、<img>要素のheightとwidthの値は、実際の画像ファイルのheightとwidthと同じになります。画像の縦横比を崩さずにサイズを調整したい場合は、heightまたはwidthプロパティのどちらかを特定の値に設定し、もう一方のプロパティをautoに設定します。例えば:

img {
  height: auto;
  width: 500px;
}

例えば、ある画像の元のサイズがheight 500px、width 1000pxだった場合、上記のCSSを使用するとheightは250pxになります。

これらのプロパティは、HTML内のheight属性とwidth属性と連携して機能します。画像ファイルの元の値からサイズを調整するつもりがない場合でも、画像要素にはこれらのプロパティとHTML属性の両方を含めるのが最善です。これらの値が含まれていないと、画像がページの他のコンテンツより読み込みに時間がかかる場合、最初はページ上のスペースをまったく占有しませんが、読み込みが完了した瞬間に他のページコンテンツが突然大きくずれてしまいます。heightとwidthを明示的に指定しておくことで、これを防げます。画像が読み込まれるまでの間、ページ上にスペースが「予約」され、空白として表示されるからです。

HTMLにCSSを追加するその他の方法

基本的な構文を学んだところで、(このレッスンの前半で学んだ外部の方法に加えて)HTMLにCSSを追加するさらに2つの方法があります。

内部CSS

内部CSS(または埋め込みCSS)は、完全に別のファイルを作成する代わりに、HTMLファイル自体の中にCSSを追加することを伴います。内部の方法では、すべてのルールを開始タグと終了タグの<style>タグのペアの中に置き、それをHTMLファイルの開始<head>タグと終了<head>タグの中に置きます。スタイルが<head>タグの中に直接置かれるため、外部の方法で必要だった<link>要素はもう必要ありません。

これらの違いを除けば、構文は外部の方法とまったく同じです(セレクタ、波括弧、宣言)。

<head>
  <style>
    div {
      color: white;
      background-color: black;
    }

    p {
      color: red;
    }
  </style>
</head>
<body>
  ...
</body>

この方法は、ウェブサイトの単一のページに独自のスタイルを追加するのに役立ちますが、外部の方法のようにものごとを分離した状態には保てず、ルールや宣言の数によっては、HTMLファイルがかなり大きくなってしまうことがあります。

インラインCSS

インラインCSSを使うと、HTML要素に直接スタイルを追加できますが、この方法はあまりお勧めできません:

<body>
  <div style="color: white; background-color: black;">...</div>
</body>

まず注目すべきは、スタイルが開始<div>タグ自体に直接追加されているため、ここでは実際にはセレクタを一切使用していないということです。次に、style属性があり、引用符のペアの中にある値が宣言となります。

単一の要素に固有のスタイルを追加する必要がある場合、この方法は問題なく機能します。しかし一般的には、いくつかの理由から、これはHTMLにCSSを追加する方法としてあまりお勧めできません:

  • 1つの要素に大量の宣言を追加し始めると、あっという間にかなり乱雑になり、HTMLファイルが不必要に肥大化してしまいます。
  • 多くの要素に同じスタイルを持たせたい場合、それぞれの要素に同じスタイルをコピー&ペーストしなければならず、不必要な繰り返しとさらなる肥大化を招きます。
  • インラインCSSは他の2つの方法を上書きしてしまうため、予期しない結果を招くことがあります。(ここでは深く掘り下げませんが、これは実は逆手に取って活用することもできます。)
