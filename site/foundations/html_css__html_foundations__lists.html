Create lists in HTML

イントロダクション

IMDBのトップ250映画であれ、FBIの指名手配リストであれ、リストはウェブのいたるところにあり、あなたも自分のウェブページでいずれ必要になるでしょう。

幸いなことに、HTMLにはいくつかの異なる種類のリストが用意されています。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • 順序なしリストの作り方。
  • 順序ありリストの作り方。

順序なしリスト

どんな順番で買っても構わない買い物リストのように、項目の順序が関係ないリストが欲しい場合は、順序なしリストを使うことができます。

順序なしリストは<ul>要素を使って作成され、リスト内の各項目はリスト項目要素<li>を使って作成されます。

順序なしリストの各リスト項目は、行頭記号(ビュレット)から始まります:

See the Pen HTML-unordered-list by TheOdinProject (@TheOdinProjectExamples) on CodePen.

順序ありリスト

レシピの手順や、お気に入りのテレビ番組トップ10のように、順序が重要なリストを作成したい場合は、代わりに順序ありリストを使うことができます。

順序ありリストは<ol>要素を使って作成されます。その中の各項目も、同じくリスト項目要素<li>を使って作成されます。ただし、順序ありリストの各リスト項目は、代わりに数字から始まります:

See the Pen HTML-ordered-list by TheOdinProject (@TheOdinProjectExamples) on CodePen.

課題

リストを使う練習をするために、新しいHTMLドキュメントを作成し、以下のリストを作ってみましょう:

  1. お気に入りの食べ物の順序なし買い物リスト
  2. 今日やるべきことの順序ありToDoリスト
  3. いつか訪れてみたい場所の順序なしリスト
  4. あなたの歴代お気に入りビデオゲームまたは映画トップ5の順序ありリスト
