イントロダクション

このプロジェクトでは、あなたのDOM操作スキルを発揮できる、かなり洒落たおもちゃを作ります。スケッチパッドとEtch-A-Sketch(エッチ・ア・スケッチ)の中間のようなものの、ブラウザ版を構築します。

このプロジェクトは簡単ではないはずです。適切なJavaScriptメソッドや使うべきCSSを見つけるために、頻繁にGoogle検索をする必要があるでしょう---実はそれこそがポイントなのです!あなたはすでに学んだツールを使ってこれを構築できます。必要だと感じた場合、まだ扱っていないことを学ぶためのリソースはネット上にたくさんあります。基本的なステップは案内しますが、実際にそれらを実装するのはあなた次第です。

完全に行き詰まってしまったら、私たちのDiscordサーバーに立ち寄って助けを求めてください。誰かが正しい方向を示してくれるでしょう。

課題

早めに、こまめにコミットするのを忘れないでくださいを参照できます!

  1. プロジェクトのGitHubリポジトリをセットアップするについての私たちの説明に従ってください。
  2. 16x16の正方形divのグリッドを持つウェブページを作成してください。
    • JavaScriptを使ってdivを作成してください。HTMLファイルにコピー&ペーストして手作業で作成しようとしないでください!
    • グリッドの正方形は「container」div の中に入れるのが最善です。このdivはHTMLファイルに書くことができます。
    • Flexboxを使って、divが(各行に1つずつ並ぶのではなく)グリッドとして表示されるようにしてください。名前とは裏腹に、CSS Gridを調べたり使ったりしたくなっても我慢してください。それはfoundationsパスの後の、後のレッスンで教えます。このプロジェクトは、特にFlexboxを練習するための機会です!
    • borderとmarginには注意してください。正方形のサイズを変えてしまうことがあります!
    • 「あれ、なんでグリッドが作られないの???」
      • CSSスタイルシートをリンクしましたか?
      • ブラウザの開発者ツールを開いてください。
      • JavaScriptコンソールにエラーがないか確認してください。
      • 「elements」パネルを確認して、要素が実際に表示されているのに何らかの理由で隠れていないか確認してください。
      • JavaScriptにconsole.log文を手当たり次第に追加して、実際に読み込まれているか確認してください。
  3. マウスがグリッドのdivの上を通過したときに色が変わる「ホバー」効果を設定し、ペンのようにグリッドを通る(ピクセル化された)軌跡を残すようにしてください。
    • ヒント: 「ホバー」とは、マウスがdivに入ったときに発生し、マウスがそこから離れたときに終わるものです。出発点として、これらのどちらかのイベントに対してイベントリスナーを設定できます。
    • divの色を変える方法は複数あります。例えば:
      • divに新しいクラスを追加する。
      • JavaScriptを使ってdivの背景色を変更する。
  4. 画面上部に、新しいグリッドの1辺あたりの正方形の数をユーザーに尋ねるポップアップを表示するボタンを追加してください。入力されたら、既存のグリッドは削除され、新しいスケッチパッドが得られるように、新しいグリッドが以前と同じ合計スペースの中に(例:幅960px)生成されるべきです。
    • ヒント: ユーザー入力の上限を最大100に設定してください。正方形の数が多いほど、より多くのコンピューターリソースが使われることになり、私たちが防ぎたい遅延、フリーズ、クラッシュを引き起こす可能性があります。
    • promptを確認してみてください。
    • 64と入力すると、使用されるピクセルの合計量を変えることなく、まったく新しい64x64のグリッドがポップアップするはずです。
  5. プロジェクトをGitHubにプッシュしましょう!

追加課題

一連の変更を導入することで、マウスと相互作用したときの正方形の振る舞いを変化させましょう。

  1. グリッド全体で正方形が同じ色になるのではなく、相互作用のたびに正方形のRGB値をランダム化してください。
  2. さらに、相互作用のたびに正方形が10%ずつ暗くなっていく、段階的な暗化効果を実装してください。目標は、わずか10回の相互作用で完全に黒(あるいは完全に色が付いた状態)の正方形を実現することです。
    • ヒント: opacity CSSプロパティがここで役立ちます。その使い方を学ぶには、opacity CSSプロパティについてのMDNドキュメントの記事を確認してください。

これらの課題のどちらか一方、あるいは両方に取り組むかは、あなた次第です。
