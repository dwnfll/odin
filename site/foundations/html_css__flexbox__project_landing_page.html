Landing Page

日本語訳

← foundations

Build a complete landing page from a given web design.

イントロダクション

このプロジェクトでは、私たちが提供するデザインをもとに、ウェブページ全体を作成します。ここまでついてきていれば、これを達成するために必要なスキルは身についているはずですが、簡単ではないかもしれません!

私たちが提供するデザインは、完成したウェブサイトの画像であり、以下の課題セクションにはフォントや色についての詳細も記載しています。

何かを調べるためにGoogleを使ったり、前のレッスンに戻ったりすることを恐れないでください。現実の世界では、プロの開発者も、何年もやってきたことについて常にGoogleを使っています。この時点で、すべてを暗記していることは期待されていないので、心配しないでください。さらに、私たちのレッスンでまだ出会っていないかもしれない、いくつかの小さな詳細もあります。これは意図的なものです。これらの詳細は些細なものであり、簡単に検索できます(例:Google検索でcss rounded corners)。

プロジェクトをできる限りデザインに近づけてください。ただし、ピクセル単位で完璧にすることは気にしなくて構いません。さまざまなセクション間の正確なマージンを調べるために定規を取り出したりピクセル数を数えたりする必要はありません。この課題のポイントは、ゼロから何かを作成し、さまざまな要素を他の要素との相対的な位置関係において、だいたい正しい位置に配置することです。デザインでは実際にはmargin: 48pxになっているところをmargin: 24pxにしてしまっても問題ありません。

最後に、このデザインに自分自身のコンテンツを自由に入れ替えて構いません。画像には意味のないダミーコンテンツが含まれていますが、架空のビジネスを考え出してこのページを自分らしくカスタマイズしたいのであれば、ぜひそうしてください!プレースホルダーには実際の画像を挿入し、色やフォントも少し自由にいじってみてください。

ウェブ上の画像についての注意

ウェブ上で見つけたどんな画像でも、それを使用する法的権利があるとは限りません。無料で見つけられる画像はたくさんありますが、使用する画像が実際に自分が使用してよいものであることを確認し、プロジェクトの中で画像の制作者にクレジットを表記するようにしてください。クレジットを表記する簡単な方法は、リポジトリのREADMEファイルに制作者の名前と連絡先情報を記載することです。

ウェブ上で自由に使用できる画像を見つけるのに適した場所には、Pexels、Pixabay、Unsplashなどがあります。

プロジェクトのGitHubリポジトリをセットアップする

Recipesプロジェクトで行ったのと同じように、このプロジェクトの作業を始める前にgitリポジトリをセットアップしてください。GitとGitHubは、今後あなたのポートフォリオとして機能することになるので、すべてをそこに保管しておく必要があります!セットアップ方法を思い出す必要があれば、Recipesプロジェクトを振り返ってみてください。

課題

早めに、こまめにコミットするのを忘れないでくださいできます!

  1. 完全なデザイン画像をダウンロードして、これから作成するものを見てみましょう。フォント、色、サイズの一部は以下の通りです(お好みで自分自身のものを使っても構いません):
    • フォント: Roboto(まだ持っていない場合は、このフォントをダウンロードしてインストールする必要があります)
    • 暗い背景色(ヘッダー、ヒーローセクション、フッター): #1F2937
    • ロゴのテキスト:
      • フォントサイズ: 24px
      • 色: #F9FAF8
    • ヒーローセクションのメインテキスト(「This website is awesome」):
      • フォントサイズ: 48px
      • 色: #F9FAF8
      • ウェイト: 900
    • ヒーローセクションのサブテキスト(「This website has some subtext...」)とヘッダーのリンク:
      • フォントサイズ: 18px
      • 色: #E5E7EB
    • ボタンと「Call to action」の背景色: #3882F6
    • Informationの見出し:
      • フォントサイズ: 36px
      • 色: #1F2937
      • ウェイト: 900
    • 引用:
      • 背景色: #E5E7EB
      • フォントサイズ: 36px
      • 色: #1F2937
      • ウェイト: 300
      • フォントスタイル: italic
  2. このようなプロジェクトに取り組む方法はたくさんあり、白紙のHTMLドキュメントを見て何から始めればいいか分からなくなると、圧倒されてしまうことがあります。私たちからの提案は、一度に1つのセクションずつ取り組むことです。作成しているウェブサイトには4つの主なセクション(とフッター)があるので、1つを選び、次に進む前にかなり良い形に仕上げてください。上から始めるのは常に堅実な計画です。
  3. 取り組んでいるセクションについては、スタイルを適用し始める前に、まずすべてのコンテンツをページに載せることから始めてください。つまり、HTMLを行い、それからCSSを行うということです。スタイリングを始めると、おそらくHTMLに戻る必要が出てきますが、最初から行ったり来たりすると、より時間がかかり、よりもどかしさを感じる原因になりかねません。(注:スタイルシートを複数使う必要はありません。このプロジェクトでは、1つのCSSファイルだけで十分です。)
  4. このページの要素の多くは、flexboxの演習で見たものと非常によく似ています……復習が必要であれば、遠慮なくそれらに戻ってください。
  5. このプロジェクトをレスポンシブにする必要はありません。つまり、さまざまな画面サイズ、ズームレベル、モバイルデバイスに合わせてデザインを調整する必要はないということです。今のところは、通常のコンピューター画面で見栄えが良くなることだけに集中してください。さまざまな画面サイズへの対応方法は、後で学びます。
  6. 完成したら、GitHubにプッシュするのを忘れないでください!

ウェブ上でプロジェクトを表示する

ウェブサイトを他の人と共有するには、GitHub Pagesを使ってデプロイする必要があります。このプロセスの完全な手順は、Recipesプロジェクトのレッスンにあります。
