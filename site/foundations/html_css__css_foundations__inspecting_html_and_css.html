Inspecting HTML and CSS

日本語訳

← foundations

Use your browser to inspect and debug your HTML and CSS.

イントロダクション

HTMLとCSSを検証し、デバッグできることは、フロントエンド開発にとって極めて重要です。このレッスンでは、Chrome Dev Toolsについて見ていきます。これにより、要素やCSSルールについての詳細な情報を確認できるだけでなく、コード内の問題を見つけて修正する助けにもなります。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • 要素インスペクターにアクセスする方法が分かるようになる。
  • 特定の要素を選択して検証する方法が分かるようになる。
  • インスペクターでHTMLとCSSを試す方法が分かるようになる。

インスペクター

インスペクターを開くには、ウェブページ上の任意の要素を右クリックして「検証」をクリックするか、F12を押します。実際に今すぐそれを行って、このページで使われているHTMLとCSSを見てみましょう。

今目にしているたくさんのツールに圧倒されないでください!このレッスンでは、ElementsパネルとStylesパネルに焦点を当てます。

要素を検証する

Elementsパネルでは、ページ全体のHTML構造を確認できます。このパネル内の任意の要素をクリックすることで、その特定の要素を選択できます。あるいは、左上の「element select」アイコン(下の画像に表示)をクリックしてから、ページ上の任意の要素にカーソルを合わせることもできます。

要素を選択すると、Stylesタブには現在適用されているすべてのスタイルと、上書きされているスタイル(テキストに取り消し線が引かれて示されます)が表示されます。例えば、TOPのホームページにある「Your Career in Web Development Starts Here」という見出しの「Your」をインスペクターでクリックすると、右側に、以下のように現在その要素に影響を与えているすべてのスタイルが表示されます(var()という構文についてはこの時点では関係ないので気にしないでください):

インスペクターでスタイルを試す

Stylesパネルでは、ブラウザ内で直接スタイルを編集することもできます。任意の個々のセレクタの中をクリックして新しいルールを追加したり、既存の属性や値をクリックして変更したりできます。そうすると、ウェブページはリアルタイムでその変更を反映します。これはテキストエディタ内のソースコードには影響しませんが、ページを何度も再読み込みすることなく、さまざまな属性や値をすばやく試すのに非常に役立ちます。
