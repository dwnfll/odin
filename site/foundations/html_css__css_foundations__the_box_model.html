イントロダクション

HTMLとCSSの基本構文を理解したところで、いよいよ本格的に取り組んでいきます。CSSで習得すべき最も重要なスキルは、配置(ポジショニング)とレイアウトです。フォントや色を変更することも重要なスキルですが、ウェブページ上で物事を思い通りの場所に正確に配置できることは、さらに重要です。結局のところ、すべての要素がただ次々と積み重なっているだけのウェブページなど、いくつ見つけられるでしょうか?

ウェブページ上で要素を配置する方法を学ぶことは、いくつかの重要な概念さえ理解すれば、それほど難しくありません。残念ながら、多くの学習者はJavaScriptにたどり着くためにHTMLとCSSの学習を急ぎすぎて、こうした基本的な概念を見落としてしまいます。これはもどかしさと苦痛(そして面白いgif)につながります。なぜなら、要素を必要な場所にきちんと配置できなければ、世の中のあらゆるJavaScriptのスキルも無意味になってしまうからです。それでは、そのことを念頭に置いて始めましょう。

ボックスモデル

CSSで成功するために理解しておくべき最初の重要な概念は、ボックスモデルです。複雑なものではありませんが、今これを読み飛ばしてしまうと、後々大きなもどかしさを招くことになります。

ウェブページ上のあらゆるものは長方形のボックスです。これらのボックスは、その中に他のボックスを持つことができ、また互いに並んで配置されることもできます。次のようにページ上のすべての要素にoutlineを適用することで、これがどのように機能するかをおおまかに把握できます:

* {
    outline: 2px solid red;
}

「Elements」タブ内の「Styles」パネルの右上にある+ボタンをクリックすることで、ブラウザのインスペクターを使って、このウェブページに上記のCSSを追加してみることもできます。ボックスの中にボックス!

まあ、上の画像には円のようなものもあるかもしれません……しかし、レイアウトに関して言えば、それらは円ではなく長方形のボックスのように組み合わさります。結局のところ、ウェブページをレイアウトし、そのすべての要素を配置するということは、これらのボックスをどのようにネストし、積み重ねていくかを決めることなのです。

ここで唯一本当にややこしいのは、padding、border、marginを使って、これらのボックスのサイズやボックス間のスペースを操作する方法がたくさんあるということです。課題の記事ではこの概念についてさらに詳しく扱いますが、簡単にまとめると:

  • paddingは、ボックスのborder(境界線)とボックスのコンテンツとの間のスペースを広げます。
  • borderは、marginとpaddingの間に(たとえ1〜2ピクセルであっても)スペースを追加します。
  • marginは、ボックスのborderと隣接するボックスのborderとの間のスペースを広げます。
