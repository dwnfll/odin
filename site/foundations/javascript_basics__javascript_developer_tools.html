JavaScript Developer Tools 日本語訳

Covers using the dev tools from the perspective of a JS developer

イントロダクション

ブラウザ内の開発者ツールの使い方を知っていることは、どんなウェブ開発者にとっても重要なスキルです。開発者ツールは、JavaScriptコードを実行したり、ページを更新することなくHTMLやCSSのスタイルを編集したり、パフォーマンスデータを確認したりするのに役立ちます。また、多くの時間も節約してくれます。始めるのはこれ以上ないほど簡単です。デバッグやHTML・CSSの作業のためにすでに使い慣れているはずなので、JavaScriptを書く際にそれらがどう役立つかを見ていきましょう。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • 開発者ツールでウェブサイトの画面サイズを変更する。
  • DOMを表示・変更する。
  • JavaScriptをデバッグする。
  • ブレークポイントを使用する。
  • Elementsタブ内でHTMLを表示・編集する。
  • Resourcesパネルを表示して、ウェブサイトで実行されているスクリプトを確認する。
  • クラスにCSS疑似状態を追加する。
  • CSSプロパティをアルファベット順に表示する。
  • Chrome DevToolsで任意の要素のボックスモデルを表示・編集する。
  • 印刷モードでページを表示する。
  • CSSクラスを有効化・無効化する。
  • デバイスモードでメディアクエリをシミュレートする。

DevToolsを開く

Chrome DevToolsメニューを開く方法は3つあります:

  1. Chromeメニュー > その他のツール > デベロッパー ツールから
  2. ウェブページ上の任意の場所を右クリックし、検証を選択する
  3. キーボードショートカットF12、またはCtrl + Shift + C(Mac: Opt + Cmd + C)を使用する
