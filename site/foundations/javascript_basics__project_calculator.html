Calculator

イントロダクション

やりましたね!ここまでで、JavaScriptの基礎について本当にしっかりとした理解ができているはずです。もちろん学ぶべきことはまだたくさんありますが、この時点でかなりのものを作れるようになっているはずです。最後のプロジェクトでは、これまでに学んだすべてを組み合わせます。JavaScript、HTML、CSSを使って、画面上の電卓を作ります。

いつものことですが、このプロジェクトにはあなたにとって簡単ではない要素がいくつかありますが、ここまでコースについてきていれば、それを完成させるために必要なものは間違いなくすべて揃っています。取れるさまざまなステップを案内していきますが、繰り返しになりますが、実際にそれらをどう実装するかはあなた次第です!

eval()とnew Function()についての警告

プロジェクトを始める前に、一言警告を伝えておく必要があります。JavaScriptで複雑な数式を評価する方法を調べていると、おそらく魅力的なeval()関数に出くわすでしょう。しかし、この関数は非常に危険なものになり得て、MDNはなぜevalを絶対に使うべきではないかについて、うまく文書化してくれています!このプロジェクトの一環として、式を評価するための独自の関数を構築する必要があります。同様に、式の計算方法を調べていると、文字列を評価するnew Function()を返すことを提案する解決策に出くわすことがあります。eval()と同様に、これも安全でないデータを評価することの潜在的な落とし穴のため、使用すべきではありません。それに、すべての作業をやってくれる解決策には、どんな面白みがあるでしょうか?では、始めましょう!

課題

早めに、こまめにコミットするのを忘れないでください!ここでCommit Messagesのレッスンを参照できます!

以下はいくつかのユースケース(プロジェクトについての期待事項)です:

  1. あなたの電卓には、一般的に電卓で見られるすべての基本的な算術演算子のための関数が含まれることになります。まずは以下の項目の関数を作成し、ブラウザのコンソールでテストすることから始めてください: - add(足し算) - subtract(引き算) - multiply(掛け算) - divide(割り算)
  2. 電卓の演算は、数値、演算子、そして別の数値で構成されます。例えば、3 + 5のようにです。演算の各部分に対応する3つの変数を作成してください。これらの変数は、後でディスプレイを更新するために使用します。
  3. 演算子と2つの数値を受け取り、それらの数値に対して上記の関数のいずれかを呼び出す、新しいoperate関数を作成してください。
  4. 各数字と演算子(=を含む)のボタンを持つ、基本的なHTML電卓を作成してください。 - まだそれらを機能させることは気にしなくて構いません。 - 電卓用のディスプレイもあるべきです。正しく見えるように、ダミーの数字で埋めてみてください。 - 「clear」ボタンを追加してください。
  5. 電卓の数字ボタンがクリックされたときに、あなたの数値変数の一つを更新する関数を作成してください。電卓のディスプレイも、その数値変数の値を反映するように更新されるべきです。
  6. 電卓を機能させましょう!ユーザーが入力した1番目と2番目の数値を保存し、ユーザーが=ボタンを押したときに、数値の間で選択された演算子に従ってそれらに対してoperate()を行う必要があります。 - ディスプレイに値を反映させるコードはすでにあるはずなので、operateが呼び出されたら、演算の結果でディスプレイを更新してください。 - これはプロジェクトの中で最も難しい部分です。すべての値をどう保存し、それらを使ってoperate関数をどう呼び出すかを考え出す必要があります。ロジックを考え出すのに時間がかかっても、気に病まないでください。

  7. 注意点:以下のバグがコードに現れたら、注意して修正してください: - あなたの電卓は、一度に1組の数値ペアより多くを評価すべきではありません。例えば、あなたの電卓は次のように機能すべきです:

    1. 数値(12)を入力する。
    2. 演算子(+)を入力する。
    3. 2番目の数値(7)を入力する。
    4. 2番目の演算子(-)を入力する。この時点で、最初の数値のペア(12 + 7)を評価し、結果(19)を表示すべきです。
    5. 別の数値(1)を入力する。
    6. 別の演算子、あるいはイコール記号(=)を入力する。この時点で、前の結果(19)を最初の数値として、演算子(-)、そして新しい数値(1)を使って、新しい式19 - 1を計算すべきです。ディスプレイには結果(18)が表示されるはずです。
    • これが実際にどう動くかを見るために、遠慮なく、たった今説明した式12 + 7 - 1 =をこのオンライン電卓に入力してみてください。
    • 長い小数の答えは、ディスプレイからはみ出さないように丸めるべきです。
    • すべての数値や演算子を入力する前に=を押すと、問題を引き起こす可能性があります!
    • 「clear」を押すと、既存のデータがすべて消去されるべきです。「clear」を押した後、ユーザーが本当にまっさらな状態から始められることを確認してください。
    • ユーザーが0で割ろうとした場合、皮肉の効いたエラーメッセージを表示してください……そして電卓をクラッシュさせないでください!
    • あなたの電卓が、ユーザーによって2つの数値と1つの演算子が与えられたときにのみ演算を実行するようにしてください。例:数値(2)を入力し、続けて演算子ボタン(+)を入力します。演算子ボタン(+)を2回連続して押します。あなたの電卓はこれを(2 + 2)として評価すべきではなく、結果(4)を表示すべきではありません。演算子ボタンが連続して押された場合、電卓は何の評価も実行すべきではなく、次の演算に使用するために最後に入力された演算子だけを取るべきです。
    • 結果が表示されているとき、新しい数字を押すと、既存の結果に数字を追加するのではなく、結果をクリアして新しい計算を始めるべきです。あなたの電卓でこれが当てはまるか確認してください!
