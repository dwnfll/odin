Installing Node.js

日本語訳

← foundations

Install Node.js to run JavaScript outside of your browser

イントロダクション

Node.js(あるいは単に「Node」)は、ウェブブラウザの外でJavaScriptを実行できるようにするJavaScriptランタイム環境です。これから先のレッスンのいくつかの演習でこれが必要になります。始めるにあたって、あなたのシステムにNodeをインストールする前に必要ないくつかのツールがあります。

nvm(Node Version Manager)を使ってそれをインストールします。nvmを使うと、Nodeのバージョンを変更したりアップグレードしたりするのが簡単になるからです。JavaScript環境で使われるさまざまなライブラリやツールをインストールするために、後で使うことになるnpmという別のツールもあります。この2つは混同しやすいので、注意深く読んでください!

Nodeもnvmを使えば非常に簡単にインストールできるので、これはすぐに終わるはずです :)

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • nvm(Node Version Manager)、Node、npmをインストールし設定します。
  • Node REPLを実行します。

課題

nvmをインストールする

  1. まず、Nodeのインストールを簡単にインストール・管理できるよう、nvmをインストールする必要があります。使用しているOSに応じた適切なガイドに従ってください:
    • Linux
    • macOS

Nodeをインストールする

nvmがインストールできたので、これを使ってNodeをインストールできます。

  1. ターミナルで以下を実行してください:

    nvm install --lts

    これにより、「長期サポート(LTS)」の最新の安定版のNodeがインストールされ、ターミナルには大量の出力が表示されます。すべてがうまくいけば、出力の行のどこかに、次のようなものが表示されるはずです(Xの部分は実際の数字に置き換わります):

    Downloading and installing Node vXX.xx.x...

    そうでない場合は、ターミナルを閉じて再度開き、もう一度nvm install --ltsを実行してください。

  2. nodeコマンドを実行する際にどのバージョンのNodeを使うかをnvmに伝える必要があります。簡単です。以下のコマンドを実行するだけです:

    nvm use --lts

    これで、コンピューターにインストールされている最新のLTSバージョンのNodeを使うようnvmに伝えました。今後のレッスンでインストールすることになるパッケージとの非互換性を避けるために、NodeのLTSバージョンを使用することが必須です。

    これでnode -vを実行すると、vXX.xx.xのようなもの(Xの部分は実際の数字に置き換わります)が表示されるはずです。

    Nodeをインストールすると、npmも一緒にインストールされます。npm -vを実行すると、上記と同様にXX.xx.xのようなものが表示されるはずです。

    これらのメッセージが表示されれば、Nodeとnpmのインストールに成功しています!

  3. 最後に、新しくリリースされた依存パッケージのインストールを遅らせる、npm v11.10.0で導入された設定を実装します。ターミナルで以下のコマンドを実行してください:

    npm config set min-release-age=3

    この設定により、npmはリリースから3日未満の依存パッケージをインストールしなくなります。これは、侵害されている可能性のある新しくリリースされたパッケージに関する問題を避け、サプライチェーン攻撃から私たちを守るのに役立ちます。

Node REPLを使う

便利なことに、Nodeは、前のレッスンで使用したブラウザのコンソールと同様に、ターミナルの中で直接JavaScriptコードを実行・編集できるインタラクティブなコンソールであるREPLを提供しています。これは、毎回ブラウザを開くことなく、ブラウザに関係のない小さなコードの断片をすばやくデバッグしたりテストしたりするのに非常に役立ちます。

Nodeのコンソールを実行するには、ターミナルを開いてnodeを単体で実行し、REPLを開いてください。REPLを終了するには.exitと入力してください。
