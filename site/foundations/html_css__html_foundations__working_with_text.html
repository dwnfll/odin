Working with Text

日本語訳

← foundations

Learn how to properly work with text in HTML

イントロダクション

ウェブ上のコンテンツのほとんどはテキストベースであるため、HTMLのテキスト要素をかなり頻繁に扱う必要が出てくるでしょう。

このレッスンでは、あなたが最もよく使うことになりそうなテキストベースの要素について学びます。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • 段落の作り方。
  • 見出しの作り方。
  • 太字のテキストの作り方。
  • 斜体のテキストの作り方。
  • ネストされた要素同士の関係。
  • HTMLコメントの作り方。

見出し

見出しは、他のHTMLテキスト要素とは異なります。見出しであることを示すために、他のテキストよりも大きく太字で表示されます。

見出しには、<h1>から<h6>まで6つの異なるレベルがあります。見出しタグ内の数字は、その見出しのレベルを表します。最も大きく最も重要な見出しはh1であり、h6は最も低いレベルの、最も小さな見出しです。

見出しは段落とほぼ同じように定義されます。例えば、h1見出しを作成するには、見出しのテキストを<h1>タグで囲みます。

See the Pen HTML-headings-example by TheOdinProject (@TheOdinProjectExamples) on CodePen.

正しいレベルの見出しを使用することは重要です。レベルはコンテンツに階層構造を与えるからです。h1見出しは常にページ全体の見出しとして使用されるべきであり、より低いレベルの見出しは、ページのより小さなセクション内のコンテンツの見出しとして使用されるべきです。

strong要素

<strong>要素はテキストを太字にします。また、意味的にテキストを重要なものとしてマークします。これは、視覚障害のあるユーザーがあなたのウェブサイトを利用する際に頼りにする、スクリーンリーダーのようなツールに影響を与えます。一部のスクリーンリーダーでは、strong要素内のテキストの重要性を伝えるために声のトーンが変わります。strong要素を定義するには、テキストコンテンツを<strong>タグで囲みます。

ネストとインデント

HTMLコメント

HTMLコメントはブラウザには表示されません。これにより、自分のコードにコメントを付けられるようになり、他の開発者や未来の自分自身がそれを読んで、コード内で分かりにくいかもしれない何かについての文脈を得ることができます。

VSCodeのキーボードショートカット

コメントの構文を入力するのが面倒だと感じる場合、以下のショートカットを使うと、新しいコメントをすばやく作成したり、任意の行をコメントに変換したり、コメントを解除したりできます:

  • Macユーザー: Cmd + /
  • WindowsとLinuxユーザー: Ctrl + /

これらのショートカットは英語のキーボードレイアウト用であり、それ以外の非英語レイアウトでは必ずしも機能するとは限らないことを知っておくことが重要です。あなたのキーボードレイアウトにおけるこれらのショートカットの対応版を、きっと見つけられるはずです。
