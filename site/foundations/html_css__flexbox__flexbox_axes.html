Axes 日本語訳

Learn about flexbox axes, and how to manipulate them.

イントロダクション

flex-directionプロパティを使って、フレックスコンテナ内のアイテムの向きをどのように制御できるかを見ていきましょう。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • フレックスコンテナの2つの「軸」について学びます。
  • コンテンツを行ではなく列に配置するために、それらの軸を変更する方法を学びます。

軸

flexboxについて最も分かりにくいのは、水平方向にも垂直方向にも機能するということであり、扱っている方向によっていくつかのルールが少し変わってくることです。 フレックスコンテナのデフォルトの方向は水平、つまりrowですが、方向を垂直、つまりcolumnに変更することもできます。方向はCSSで次のように指定できます:

.flex-container {
  flex-direction: column;
}

どちらの方向を使用していても、フレックスコンテナには2つの軸、つまりメイン軸とクロス軸があると考える必要があります。flex-directionを変更したときに変わるのは、これらの軸の向きです。ほとんどの場合、flex-direction: rowはメイン軸を水平(左から右)にし、columnはメイン軸を垂直(上から下)にします。

言い換えると、私たちの一番最初の例では、divにdisplay: flexを設定し、それがその子要素を水平に配置しました。これはデフォルト設定であるflex-direction: rowのデモンストレーションです。次の例は非常によく似ています。flex-direction: columnと書かれた行のコメントを解除すると、それらのdivは垂直に積み重なります。

See the Pen [flex-direction example](https://codepen.io/TheOdinProjectExamples/pen/BaZKPdw) by TheOdinProject ([@TheOdinProjectExamples](https://codepen.io/TheOdinProjectExamples)) on [CodePen](https://codepen.io).

注意すべき点として、この例では、ショートハンドのflex: 1を使用すると、flex-direction: columnは期待通りには機能しません。今すぐ試してみてください(つまり、flex: 1 1 auto;の行のflexの値を変更してみてください)。flex: 1を使用した場合になぜうまくいかないのか分かりますか?それらのdivには明らかにheightが定義されているにもかかわらず、潰れてしまいます。

この理由は、 flexショートハンドがflex-basisを0に展開するためであり、これはすべてのflex-growとflex-shrinkの計算が0から始まることを意味します。空のdivはデフォルトで高さが0であるため、私たちのフレックスアイテムがコンテナの高さを満たすためには、実際には高さがまったく必要ないのです。

上記の例では、flex: 1 1 autoを指定することでこれを修正し、フレックスアイテムに与えられたheightをデフォルトにするよう指示しています。親の.flex-containerに高さを設定するか、ショートハンドの代わりにflex-grow: 1を使うことでも修正できたでしょう。

もう一つ気づくべき詳細があります。flex-directionをcolumnに変更すると、flex-basisはwidthではなくheightを指すようになります。文脈からすると明らかかもしれませんが、意識しておくべきことです。

少し話が逸れてしまいました……flex-directionと軸について話していたのでした。話を戻すと、デフォルトの動作はflex-direction: rowであり、これは物事を水平に配置します。これがCSSの他の詳細を変更しなくてもうまくいくことが多い理由は、ブロックレベル要素がデフォルトで親の幅いっぱいになるからです。flex-direction: columnを使って垂直に変更すると複雑さが増します。なぜなら、ブロックレベル要素はデフォルトでそのコンテンツの高さになりますが、この場合コンテンツが存在しないからです。

右から左に書かれる言語、あるいは縦書きの言語を使用している場合、flex-directionの動作が変わる可能性がある状況もありますが、アラビア語や満洲語でウェブサイトを作り始める準備ができるまでは、それについて心配する必要はありません。
