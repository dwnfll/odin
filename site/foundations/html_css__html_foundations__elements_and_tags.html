Start building HTML with elements and tags.

イントロダクション

HTML(HyperText Markup Language)は、ウェブページの構造とコンテンツを定義します。私たちは、一般的なウェブページを構成するすべての段落、見出し、リスト、画像、リンクを作成するためにHTML要素を使用します。このレッスンでは、HTML要素がどのように機能するかを見ていきます。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • HTMLタグとは何かを説明する。
  • HTML要素とは何かを説明する。

要素とタグ

HTMLページ上のほとんどすべての要素は、開始タグと終了タグで囲まれたコンテンツの断片にすぎません。

HTMLタグは、ウェブページの構造とコンテンツを定義する、不可欠な構成要素です。

開始タグは、ここがHTML要素の始まりであることをブラウザに伝えます。開始タグは、山括弧<>で囲まれたキーワードで構成されます。例えば、段落の開始タグはこのようになります: <p>。

終了タグは、要素がどこで終わるかをブラウザに伝えます。開始タグとほぼ同じですが、唯一の違いはキーワードの前にスラッシュが付くことです。例えば、段落の終了タグはこのようになります: </p>。

完全な段落要素はこのようになります:

<p>some text content</p>

分解してみましょう:

  • <p>が開始タグです。
  • some text contentは、開始タグと終了タグの間に囲まれたコンテンツを表します。
  • </p>が終了タグです。

要素はコンテンツを入れる容器だと考えることができます。開始タグと終了タグは、その要素がどのようなコンテンツを含んでいるかをブラウザに伝えます。ブラウザはその情報を使って、コンテンツをどのように解釈し整形すべきかを判断できます。

HTMLには、あらゆる種類の要素を作成するために使用できる膨大な定義済みタグの一覧があります。コンテンツに正しいタグを使用することは重要です。正しいタグを使用することは、あなたのサイトの2つの側面に大きな影響を与えることがあります。1つは検索エンジンでのランク付け、もう1つはスクリーンリーダーのような支援技術に頼ってインターネットを利用するユーザーにとってのアクセスのしやすさです。

コンテンツに正しい要素を使用することは、セマンティックHTMLと呼ばれます。これについては、カリキュラムの後半でさらに深く掘り下げます。

ボイド要素

HTML要素の中には、終了タグを持たないものがあります。これらの要素は、<br>や<img>のように、単一のタグだけを持ちます。これらは、いかなるコンテンツも持たない、つまり中に何もないため、ボイド要素(void element)として知られています。終了タグがないということは、他のタグのようにコンテンツを囲むことができないということです。

これらは自己終了タグ(self-closing tag)と呼ばれることもあります。しかしそれらは、<br />や<img />のように、末尾にスラッシュ(/)が付いたボイド要素にすぎません。歴史的な理由から、自己終了タグが使われているのをよく目にすることになるでしょう。ブラウザは問題なくそれらをレンダリングできますが、最新版のHTML仕様ではその使用は推奨されておらず、無効なものとみなされます。
