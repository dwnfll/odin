Data Types and Conditionals 日本語訳

In this lesson we learn about basic data types and conditionals.

イントロダクション

JavaScriptで出会うことになる、非常に一般的なデータの型がいくつかあり、これらの基礎に関するレッスンは、それらすべてについて本当にしっかりとした土台を与えてくれます。しかし、深く掘り下げ始める前に、このJavaScriptで最も一般的なデータ型の概要を読んでみてください。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • JavaScriptの8つのデータ型を挙げる。
  • シングルクォート、ダブルクォート、バッククォートの違いを理解する。
  • 文字列に変数や式を埋め込む。
  • メソッドとは何かを理解する。
  • 3つの論理演算子を挙げる。
  • 比較演算子とは何かを理解する。
  • 条件分岐とは何かを理解する。
  • ネストとは何かを理解する。
  • truthyな値とfalsyな値とは何かを理解する。

文字列

どのような種類の作業をしているかによっては、数値よりもテキストの断片を扱うことの方が多くなるかもしれません。文字列とはテキストの断片のことであり……この言語の基本的な構成要素です。

  1. このJavaScriptの文字列についてのMDNチュートリアルを読んで、一緒にコードを書いてみましょう。Concatenation in contextセクションは、後のDOM Manipulationのレッスンで扱う概念をカバーしているので飛ばしてください。
  2. W3Schoolsの文字列メソッドについてのレッスンに目を通して、文字列でできることについてもう少し学びましょう。メソッドとは、言語や特定のデータ型に組み込まれた機能の断片です。
  3. 前のリソースが示していたよりも、はるかに多くの組み込み文字列メソッドがあります。これをすべて読んだり、まして暗記したりする必要はありませんが、文字列についてのMDNドキュメントの存在は知っておくべきです。ここには文字列についてのはるかに多くの情報と、組み込みメソッドの網羅的なリファレンスがあるので、ブックマークしておきましょう!

条件分岐

さあ、いよいよ楽しいことをする時間です……ここまでのところ、私たちがプログラミングで行ってきたことは、基本的な算数のスキルでもできないことではありませんでした。確かに、コンピューターに計算のやり方を教えたことで、それがより速くなりましたが、プログラミングの本質は、より複雑なことをするための意思決定の仕方をコンピューターに教えることです。条件分岐は、それを行うための手段です。以下のリソースを読んでみてください:

  1. 条件分岐について学ぶ最初のステップは、比較についてしっかりと把握しておくことです。
  2. 条件分岐についてのMDNの記事は、条件付きコードを書くさまざまな方法への素晴らしい入門です。
  3. if/elseについてのJavaScript.infoのレッスンは同じ基本概念を扱っており(復習として読んでみましょう!)、さらに重要なことに、ページ下部にいつものタスクを用意してくれています!
  4. 論理演算子についてのJavaScript.infoのレッスンに目を通しましょう。この読み物のタスクについて少し注意点があります。かっこの中に数値や文字列が入ったalert()を見かける質問がいくつかあります。ここで何が起きているかについては、カリキュラムの後半で説明します。答えの一部は今は意味が分からないかもしれませんが、それらは正確なものであり、カリキュラムを進めていくうちに理解できるようになります。今はあまり気にしすぎないでください!
  5. 複数の条件があるときに便利なswitch文について学びましょう。

課題

十分な練習をしてもらうために、あなたが取り組めるJavaScriptの演習を用意しました。これらには、あなたのコードが意図通りに動作することを確認するために使われるテストが含まれています。returnを見かけたら、それは単に、関数の実行が終わったときに、returnの後に続くものを返すという意味です。今後のレッスンでは、これらの概念についてさらに詳しく扱いますので、今のところはとりあえず頑張ってください!
