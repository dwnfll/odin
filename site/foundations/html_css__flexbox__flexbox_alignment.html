Alignment

日本語訳

← foundations

Learn how to get flex-items where they need to be on your page.

イントロダクション

これまでflexboxで扱ってきたものはすべて、すべてのフレックスアイテムにflex: 1というルールを使用しており、これによりアイテムは利用可能なスペースをすべて埋めるように均等に伸び縮みします。しかし、これが望む効果ではないこともよくあります。Flexは、特定のサイズを持つアイテムを配置するのにも非常に役立ちます。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • フレックスコンテナ内でアイテムを垂直方向と水平方向の両方で揃える方法を学びます。

ここまで来れば、.itemにflex: 1を設定したらどうなるか予測できるはずです。先に進む前に試してみてください!

.itemにflex: 1を追加すると、各アイテムは利用可能なスペースを埋めるように成長しますが、幅は同じまま、コンテナ内での分布のさせ方だけを変えたい場合はどうすればよいでしょうか?それも可能です!

.itemからflex: 1を削除し、.containerにjustify-content: space-betweenを追加してください。そうすると、次のようになるはずです:

justify-contentはメイン軸に沿ってアイテムを整列させます。ここで使用できる値はいくつかあります。残りについては課題の読み物で学びますが、今のところはcenterに変更してみてください。これによりボックスがメイン軸に沿って中央揃えになるはずです。

クロス軸に沿ったアイテムの配置を変更するにはalign-itemsを使用します。.containerにalign-items: centerを追加して、ボックスをコンテナの中央に持ってきてみましょう。望ましい結果は次のようになります:

justify-contentとalign-itemsはコンテナのメイン軸とクロス軸に基づいているため、フレックスコンテナのflex-directionを変更すると、それらの動作も変わります。例えば、flex-directionをcolumnに変更すると、justify-contentは垂直方向に整列し、align-itemsは水平方向に整列するようになります。しかし、最も一般的な動作はデフォルトのもの、つまりjustify-contentがアイテムを水平方向に整列させ(メイン軸はデフォルトで水平だからです)、align-itemsが垂直方向に整列させるというものです。初心者がflexboxでつまずく最大のポイントの一つが、この動作が変わったときの混乱です。

gap

flexの非常に便利な機能の一つがgapプロパティです。フレックスコンテナにgapを設定すると、アイテム自体にmarginを追加するのと似た形で、フレックスアイテム間に指定したスペースが追加されます。gapは新しいプロパティなので、まだ多くのリソースには載っていませんが、すべてのモダンブラウザで確実に動作するため、安心して使える非常に便利なものです!上記の中央揃えの例にgap: 8pxを追加すると、以下のような結果になります。

以下の読み物で学ぶべきことはまだありますが、この時点で、flexboxがどれほど計り知れないほど便利であるかはきっと分かってきたはずです。すでに扱ったプロパティだけでも、印象的なレイアウトを組み立てられるようになっています!

時間をかけて読み物に取り組んでください。ここですでに扱った項目の復習も含まれていますが、さらに深く掘り下げ、まだ触れていないいくつかのことにも触れています。今のところ、細かいことをすべて暗記しようとしてストレスを感じすぎないでください。ただ例と一緒にコードを書き、flexboxで可能なことをすべて自分の中に取り込むよう最善を尽くしてください。練習問題に取り組む際には、これらのリソースに再び頼る必要が出てきますが、それはまったく問題ありません。これを使えば使うほど、頭の中により定着していきます……そしてあなたはこれを常に使うことになります。楽しんでください!
