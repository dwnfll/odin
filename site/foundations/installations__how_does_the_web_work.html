How Does the Web Work?

日本語訳

← foundations

It's tough to program web sites without understanding how the web actually works!

イントロダクション

ウェブをプログラムする方法を理解する前に、あなたが今おそらく持っている以上の、ウェブそのものについてのより厳密な理解が必要です。これらの概念は、あなたがこれから働くことになるエコシステムについてのより包括的な理解を与えてくれ、自分の仕事について他の開発者と知的に話せるようにしてくれます。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • インターネットとは何かを説明する。
  • パケットとは何か、そしてそれがどのようにデータ転送に使われるかを説明する。
  • ウェブページ、ウェブサーバー、ウェブブラウザ、検索エンジンの違いを理解する。
  • クライアントとは何かを簡単に説明する。
  • サーバーとは何かを簡単に説明する。
  • IPアドレスとは何かを説明する。
  • DNSサーバーとは何かを説明する。

課題

  1. インターネットの仕組みについての概要を紹介する、このBBCのショート動画を見てみましょう。
  2. 「インターネットはどのように機能するのか?」についてのMozillaの記事を読んでみましょう。
  3. 5分でわかるインターネットの仕組みを見てみましょう。
  4. ウェブページ、ウェブサーバー、検索エンジンの違いについて読んでみましょう。
  5. ウェブブラウザとは何かを説明するGoogleのショート動画を見てみましょう。その後、このサイトを使って現在使用しているウェブブラウザとそのバージョンを確認してみましょう。
  6. ウェブのさまざまな部分がどのように互いにやり取りするかについて読み、DNSリクエストがどのように機能するかについてのMDNの記事も読んでみましょう。あるいは、こちらのDNSリクエストがどのように機能するかについての動画もあります。
