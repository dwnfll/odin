Introduction to CSS Grid

イントロダクション

次のいくつかのレッスンでは、CSS Gridを扱い、ページレイアウトをずっと簡単にしていきます。まず、Flexbox(Flexboxを覚えていますか!?)をさっと振り返り、それからGridについて学びます。

以降のレッスンでは、グリッドの作成方法、グリッドアイテムの位置指定、そしていくつかの高度なプロパティの使い方を紹介していきます。それから、FlexboxとGridの違いについてより深く見ていきます。最終的には、Gridを使ってダッシュボードのプロジェクトを構築することを目指していきます。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • FlexboxとGridの基本を比較します。
  • FlexboxよりもGridを使うべき状況を説明します。

flexの振り返り

Foundationsコースでは、Flexboxについてたくさん学びました。ここまでの道のりであちこちでFlexを使ってきたなら、このセクションはGridに入る前のさっとした復習になるでしょう。もしFlexについて完全に迷子になっているなら、Flexのレッスンをもう一度見直して、ペースを取り戻すのが役立つかもしれません。

Flexのレッスンでは、2つのflex軸(mainとcross)に沿ってアイテムを位置指定する方法や、それらのflexアライメントの設定方法を扱いました。また、flexアイテムを大きくしたり小さくしたり、サイズを変えたりする方法も学びました。これこそがFlexboxの真の美しさで、アイテムはまさに「flex(たわむ)」して伸びたり縮んだりできるのです。

1次元のレイアウトについては、Flexはfloatやその他のCSSのハックに頼ることなく、アイテムを適切に整列させるための便利なツールを提供してくれます。

2次元のレイアウトについては、flex-wrapについて少し学びました。これを使うと、flexアイテムを取り、次の行に折り返すことができます。これは、行が別の行に折り返すこともできますし、列が別の列に折り返すこともできます。

この演習でカードレイアウトを解くのがどれほど楽しかったか、覚えていますか?

あれがイライラするものだったことは分かっていますが、それがポイントの一部でもあります。Flexboxは行と列を組み合わせたレイアウトを構築できるようにしてくれますが、それは必ずしも簡単ではありません。

Gridとは何か?

GridはCSSの中では比較的新しいモジュールですが、このレイアウトツールは長い間開発され続けてきました。豆知識ですが、CSSの共同創作者であるBert Bos博士(Wes Bosとは関係ありません)は、1996年にこのレイアウトモデルの開発に取り組み始めました。このアイデアは、新聞や雑誌など他の形式のメディアで使われているグリッドのようなレイアウトから着想を得たものでした。長年にわたる徹底的な実演と開発の末、CSS Gridは2017年についにすべての主要ブラウザに導入されました。

上記で示したように、Gridは2次元のレイアウトでアイテムを簡単に配置できることでよく称賛されます。しかし、Gridは1次元のレイアウトにも使うことができます。開発者にとっての一つの利点は、最初はアイテムの行が一つだけであっても、後から追加の行を加えられるということです。

FlexとGridの間には多くの類似点があることに気づくでしょう。どちらも、子アイテムを持つ親コンテナを使います。アライメントや位置指定のためのプロパティ名も似ています。しかし、この2つの間には多くの違いもあり、それぞれのモジュールをどう使うべきかについての意見の相違にも出会うことになるでしょう。例えば、もしあなたがFlexアイテムをすべて均等なサイズに揃えるのに苦労してきたなら、Gridはこの種のレイアウトをずっと簡単にしてくれます。

古いリソースを見直すときは、これらのモジュールが更新されるにつれて、FlexとGridの違いも変わり得るということを心に留めておいてください。CSS Gridの大きな見どころの一つはgapプロパティの使用でしたが、これについては次のレッスンで扱います。これはかつてGridでしか利用できませんでしたが、今ではFlexでもサポートされています。

CSS GridがFlexboxを置き換えるためにここにあると考えた人もいましたが、これらのレッスンの終わりまでに、Gridは単に道具箱に加わったもう一つの道具に過ぎないということを学ぶでしょう。実際、これらのモジュールはそれぞれ独自のユースケースを持っているだけでなく、FlexとGridを組み合わせて使うことが役立つと分かることもあるでしょう。しかし、それについては最後のまとめのレッスンですべて扱います。まずは、実際にグリッドを作る方法を学んでいきましょう!
