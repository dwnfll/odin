イントロダクション

Gridを使う練習をたくさん積んできたので、今度は完全なダッシュボードのデザインを構築していきます。このプロジェクトでは、必要なツールは何でも使って構いませんが、レイアウト作業の大部分にはGridを頼りにするようにしてください。復習が必要な場合は、レッスンや練習課題に戻ってみてください。

課題

ステップ1: セットアップと計画

  1. Gitリポジトリをセットアップしてください(復習が必要な場合は過去のプロジェクトを参照してください)。
  2. すべてが正しくリンクされていることを確認するためだけに、ダミーコンテンツでHTMLとCSSファイルをセットアップしてください。
  3. プロジェクトのデザインファイルのフル解像度版をダウンロードし、HTMLドキュメントでどのようにレイアウトする必要があるかについて大まかなイメージをつかんでください。

ステップ2: レイアウト

  1. まず、サイドバー、ヘッダー、メインコンテンツのコンテナのためのHTML要素を書き出すことから始めてください。
  2. CSSファイルで、この基本的なレイアウトが構築できるまでGridのプロパティを適用してください。

ステップ3: ネスト

  1. 一度に一つのセクションずつ取り組みながら、HTML内の親要素の下に子要素をネストし始めてください。グリッドコンテナの中にグリッドコンテナを作り続けられることを覚えておいてください。
  2. サイドバーでは、さらにグリッドを使ってナビゲーションとブランディングのセクションをレイアウトしてください。
  3. ヘッダーでは、さらにグリッドを使って検索バー、ユーザー情報、ボタンをレイアウトしてください。
  4. メインコンテンツでは、さらにグリッドを使ってプロジェクト、お知らせ、トレンド項目をレイアウトしてください。
  5. すべてのグリッドアイテムを位置指定できるように、ダミーコンテンツとプレースホルダー画像で埋めてください。

ステップ4: アセットを集める

  1. グリッドレイアウトが完成したら、上記のダッシュボードの例を再現するか、自分自身のデザインでスタイリングするか選ぶことができます。
  2. すべてのアイコンなどは、Material Design IconsからSVGとしてダウンロードできます。
  3. 好きなフォントを選んでください!このデザイン例ではRobotoを使っており、これはGoogle Fontsで利用できます。(プロジェクトに外部フォントを組み込む方法についての情報は、More Text Stylesのレッスンを復習するとよいかもしれません)。

ステップ5: いくつかのヒント!

  1. レイアウトを構築する際は、グリッドを視覚化しやすくするために、コンテナに背景色や枠線を適用してください。
  2. グリッドトラックにピクセルを使うか、fr単位を使うか、あるいは両方を使うかはあなた次第です。
  3. このプロジェクトはレスポンシブである必要はありませんが、もしそうしたいなら、ブラウザウィンドウをリサイズしたときにプロジェクトカードのセクションを拡大・縮小させることができます。
  4. デザイン例とピクセル単位で完全に一致させる必要はありません。これを、自分自身のデザインでCSSのスキルを練習する機会だと考えてください。
  5. 完成したダッシュボードをGitHubにプッシュするのを忘れないでください。GitHub Pagesを使って世界に公開しましょう!

ステップ6: セクションのフィードバック

  1. 先に進む前に、Intermediate HTML and CSSコースについてのフィードバックを送っていただけると嬉しいです。
