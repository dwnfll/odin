Positioning Grid Elements

日本語訳

← intermediate_html_css

Learn how to manipulate elements within a grid.

イントロダクション

このレッスンでは、グリッドのさまざまな部分を調べ、グリッドアイテムを位置指定するために使える一般的なプロパティを探っていきます。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • トラック、ライン、セルの違いを説明します。
  • 開始ラインと終了ラインを定義してアイテムを位置指定します。
  • ショートハンド記法を使います。

トラックの振り返り

位置指定にまっすぐ飛び込む前に、グリッドのさまざまな部分をよりよく理解するために、いくつかの用語を確立しておきましょう。前のレッスンで、grid-templateを使ってグリッドを定義するとき、グリッドが持つことになるトラックを定義しているのだと学びました。グリッドトラックとは、グリッド上の任意の単一の行または列だと考えることができます。

例を挙げると、100ピクセルの行と100ピクセルの列を持つ3x3のグリッドを作りたい場合、高さ100ピクセルの水平トラックを3つ、幅100ピクセルの垂直トラックを3つ定義する必要があります:

See the Pen 3x3 Layout | CSS Grid by TheOdinProject (@TheOdinProjectExamples) on CodePen.

このCodePenでは、2つのCSSの行がコメントアウトされていることに気づくでしょう。.first-rowクラスセレクタのプロパティのコメントを外して、1行目と2行目のグリッドライン間のグリッドトラックを見てみてください。

次に、.last-columnクラスセレクタのプロパティのコメントを外して、3列目と4列目のグリッドライン間のグリッドトラックを見てみてください。

ライン

グリッドトラックを作成すると、グリッドラインは暗黙的に作成されます。これは重要なことです。グリッドラインは、グリッドトラックが定義された後にのみ作成されます。グリッドラインを明示的に作成することはできません。

すべてのトラックには開始ラインと終了ラインがあります。ラインは1から始まり、左から右、上から下に番号が振られます。ですので、上記の私たちの3x3グリッドには、列については1から4までの垂直ラインがあり、行については1から4までの水平ラインがあります。

グリッドラインは、グリッドアイテムを位置指定するために使うものです。それについてはすぐ後で扱いますが、まずは開発者ツールを使ってグリッドラインをより深く見てみましょう。

Chromeで開発者ツールを開くと、Layoutペインに移動して、Gridオーバーレイの表示設定を見つけることができます。ラインの番号を表示するが有効になっていることを確認してください。Gridオーバーレイから正しい要素を選択してください(例えば、私たちのCodePenを検証しているなら、これは私たちのdiv.containerかもしれません)。これで、グリッドラインのオーバーレイが表示されるはずです。

開発者ツールは、正のラインとは反対側に負のラインも表示することに注目してください。今のところ負のラインについて心配する必要はありませんが、これがグリッドアイテムを位置指定する際に使えるもう一つの選択肢を与えてくれるということは知っておいてください。

セル

単一の行トラックと単一の列トラックが共有するグリッド上のスペースは、グリッドセルと呼ばれます。グリッドセルは、スプレッドシートのセルのようなもの、つまり行、列の座標によって定義されるスペースだと考えることができます。

デフォルトでは、グリッドコンテナの各子要素は一つのセルを占有します。上記の例では、グリッドに9個のセル(3行x3列)があり、それぞれに自動的に位置指定された子要素が一つ入っています。「A」の文字が付いた要素は、行トラック1(行グリッドライン1と2の間)と列トラック1(列グリッドライン1と2の間)にあるセルを占有しています。「H」の文字が付いたアイテムは、行トラック3(行グリッドライン3と4の間)と列トラック2(列グリッドライン2と3の間)にあるセルにあります。

しかし、グリッドアイテムの順序を変えたい場合はどうなるでしょうか?あるいは、アイテムに複数のセルを占有させたい場合はどうでしょうか?

位置指定

アイテムがどう位置指定できるかの感覚をつかむために、あるアパートの間取り図の模型を作ってみましょう。まず、アパートの総面積(グリッドコンテナ)を5x5のグリッドに分割することから始めましょう。この例をもう少し分かりやすくするために、背景色を使ってコンテナのスペースを区別します。ここでは、コンテナがブロックレベルのボックスのようにスペースを取って広がってしまわないように、display: inline-gridも使っていることに注意してください。これは、スペースをよりよく視覚化するのに役立つだけです。

See the Pen Positioning 1 | CSS Grid by TheOdinProject (@TheOdinProjectExamples) on CodePen.

今のところは、かなり寂しい部屋です。空っぽの箱というよりもっと家らしくするために、さまざまな部屋を表すいくつかのアイテムをグリッドコンテナに追加していきましょう。

See the Pen Positioning 2 | CSS Grid by TheOdinProject (@TheOdinProjectExamples) on CodePen.

ほとんどの部屋は単一のグリッドセルを表しています。しかし、私たちは自分たちに広いリビングルームを与えました(やった!)。このアイテムはgrid-column-startとgrid-column-endを使って位置指定しました。それらのプロパティの値は、開始・終了させたい列グリッドラインを表しています。

このアイテムの行の位置指定のためのプロパティ値もコメントアウトされていることに気づくでしょう。grid-row-startとgrid-row-endプロパティのコメントを外して、1行目と3行目のグリッドライン間のグリッドトラックを占有することでリビングルームがさらに大きくなる様子を見てみてください。

これらのプロパティを使うと、既存のグリッドラインを利用して、それぞれのアイテムが何行・何列にまたがるべきかをアイテムに伝えることができます。少し時間を取って、ここでプロパティの値をいろいろ試してみてください。ライン番号がややこしい場合は、開発者ツールでコンテナを検証してグリッドオーバーレイを表示してください。

次に、スペースをもっと効率的に使う必要があります。残りの部屋を複数のグリッドセルにまたがるようにして、アパートの残りの部分を埋めていきます。

See the Pen Positioning 3 | CSS Grid by TheOdinProject (@TheOdinProjectExamples) on CodePen.

これでアパート全体の設計図ができました。#kitchenセレクタを見てみると、ここでショートハンドプロパティを使ったことが分かるでしょう。grid-columnは、単にgrid-column-startとgrid-column-endをスラッシュで区切って組み合わせたものです。そしてgrid-rowは、アイテムの行の位置指定を設定するためのショートハンド版です。

私たちの間取り図の一つの問題は、バスルームとキッチンがアパートの反対側の端にあることです。この2つの部屋を隣り合わせに配置すれば、配管の費用を節約できるでしょう。少し時間を取って、バスルームがキッチンのすぐ隣に来るように、バスルーム、ベッドルーム、クローゼットの開始・終了位置を変えられるか試してみてください。ここでは、長い方のプロパティでもショートハンドのプロパティでも、どちらを使っても構いません。

grid-area

これで、行と列のラインを使ってグリッドアイテムを位置指定する方法が分かりました。しかし、アイテムを位置指定する方法は他にもあり、ここで少しややこしくなることがあります。

開始・終了ラインでグリッドアイテムを位置指定するための、さらに短いショートハンドがあります。grid-row-start/grid-column-start/grid-row-end/grid-column-endを、grid-areaを使って一行に組み合わせることができます。

上記の私たちのリビングルームは、次のように書くことができます:

/* styles.css */

#living-room {
  grid-area: 1 / 1 / 3 / 6;
}

しかし、grid-areaはいくつかの異なるものを指すこともできます。

グリッド上のすべてのアイテムを位置指定するのにグリッドラインを使う代わりに、グリッドの視覚的なレイアウトを言葉で作ることができます。これを行うには、grid-areaを使ってグリッド上の各アイテムに名前を付けます。

ですので、私たちのリビングルームは次のように書くこともできます:

/* styles.css */

#living-room {
  grid-area: living-room;
}

これをすべてのグリッドアイテムに行い、それぞれの部屋に名前としてgrid-areaの値を与えることができます。そして、grid-template-areasを使ってグリッドコンテナで構造全体をマッピングすることができます。

See the Pen grid-template-areas 1 | CSS Grid by TheOdinProject (@TheOdinProjectExamples) on CodePen.

すごいですね!CodePenのブラウザを開いて大きくし、grid-template-areasのレイアウトを1行ずつじっくり読んでみたくなるかもしれません。しかし、このツールはアイテムを位置指定するまったく異なる方法を私たちに与えてくれます。

空のセルを示すために.を使うこともできます。私たちのアパートに給湯器と洗濯機・乾燥機が追加されるかもしれないとしましょう。正確なレイアウトはまだ分かりませんが、バスルームとキッチンにもう少しスペースを空けることで、簡単にそのスペースを視覚化できます:

See the Pen grid-template-areas 2 | CSS Grid by TheOdinProject (@TheOdinProjectExamples) on CodePen.

これで、グリッドアイテムにgrid-areaを使う、まったく異なる2つの方法が分かりました。「grid area」という用語がセルのグループを指すのを目にすることもあるかもしれません。例えば、リビングルームのグリッドセルすべてを合わせたものが一つのグリッドエリアです。このアパートのたとえが役立つはずです。グリッドアイテムは、アパートの中の4つの壁で囲まれた部屋のように、複数のセルを占有してグリッドの一つの領域を形成することができます。

まとめ

課題に取り組んでいく中で、グリッドアイテムをトラックにまたがって位置指定する際の、spanやautoのようなさらなる用語に出会うことになります。Flexboxと同様に、グリッドアイテムを整列・配置するためのプロパティもあります。この用語すべてとアイテムの位置指定の仕方を学ぶ一番の方法は、たくさん練習することです!
