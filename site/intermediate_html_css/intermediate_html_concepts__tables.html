Tables 日本語訳

Tables are great when used appropriately!

イントロダクション

HTMLテーブルを使うと、行と列で構成される2次元のテーブルを作成できます。このレッスンでは、HTMLテーブルについて知っておく必要のあることをすべて学びます。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • 高度なHTMLテーブルを作成する。

HTMLテーブル

データによっては、テーブルで表示する必要が本当にあるものもあります。HTMLテーブルは、ここまで学んできたボタン、リンク、リストなどに比べると、あまり一般的には使われないかもしれませんが、それが最適なツールになる場合もあります。より高度な機能のいくつかは正しく設定するのが少し厄介になることがありますが、テーブルを始めること自体はかなり簡単です。<table></table>タグでテーブルを作成し、それからそのテーブル要素の中に、行、列、ヘッダー、その他可能な要素を配置します。
