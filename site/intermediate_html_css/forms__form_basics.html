Form Basics

日本語訳

← intermediate_html_css

Learn the basics of creating forms in HTML.

イントロダクション

フォームは、あなたのサイトの最も重要な部分の一つです。フォームはユーザーがあなたのバックエンドに入っていくための入り口です。ユーザーがフォームにデータを入力し、あなたはそれを使って何かを行います。

一つのデータを収集する方法は複数ある場合が多いですが、ユーザーにとって最も簡単な方法は一つだけであるため、それぞれ可能なデータ項目に対して適切な種類の入力を指定する必要があります。

このレッスンでは、HTMLフォームの基本と、利用可能ないくつかの異なる種類の入力を探っていきます。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • HTMLでフォームを作成する。
  • フォームのスタイリングの基本的な考え方を持つ。

form要素

form要素は、カリキュラムの前の方で学んだdiv要素のようなコンテナ要素です。form要素は、ユーザーがフォーム上でやり取りするすべての入力をラップします。

form要素は2つの重要な属性を受け付けます。1つ目はaction属性で、これはフォームがそのデータを処理のためにどこに送るべきかを伝える、URLの値を取ります。 カリキュラムの後の方で、この属性を使ってバックエンドシステムをフロントエンドのフォームに接続する方法を学びます。今のところは、action属性が何に使われるかを知っておくだけで十分です。

2つ目はmethod属性で、これはフォームを送信するためにどのHTTPリクエストメソッドを使うべきかをブラウザに伝えます。 GETとPOSTのリクエストメソッドが、あなたが最もよく使うことになる2つです。

サーバーから何かを取得したいときにGETを使います。例えば、Googleは検索を行う際にGETリクエストを使います。なぜならそれは検索結果を取得する(gets)からです。

POSTは、サーバー上の何かを変更したいとき、例えばユーザーがアカウントを作成したり、ウェブサイトで支払いを行ったりするときに使われます。

form要素を作成するためのマークアップは、次のようになります:

<form action="example.com/path" method="post">

</form>

フォームコントロール

ユーザーデータの収集を始めるには、フォームコントロール要素を使う必要があります。これらは、テキストボックス、ドロップダウン、チェックボックス、ボタンなど、ユーザーがフォーム上でやり取りするすべての要素です。以降のいくつかのセクションでは、あなたが最も一般的に使うことになるフォームコントロールのいくつかを探っていきます。

input要素

input要素は、すべてのフォームコントロール要素の中で最も汎用性の高いものです。type属性を受け付け、これがブラウザにどんな種類のデータを期待すべきか、input要素をどう描画すべきかを伝えます。

テキスト入力は次のようになります:

<form action="example.com/path" method="post">
  <input type="text">
</form>

テキスト入力はどんなテキストの入力も受け付けます。例えば、これを使ってユーザーの名前や苗字のようなものを収集できます。

ラベル

入力だけでは、ユーザーがどんな種類のデータを提供すべきか分からないため、あまり役に立ちません。その代わり、入力にラベルを付けて、ユーザーにどんな種類のデータを入力することが期待されているかを伝えることができます。

ラベルを作成するには、<label>要素を使います。ラベルに表示したいテキストは、その開始タグと終了タグの間に置きます:

<form action="example.com/path" method="post">
  <label for="first_name">First Name:</label>
  <input type="text" id="first_name">
</form>

ラベルはfor属性を受け付け、これを特定の入力と関連付けます。ラベルと関連付けたい入力には、ラベルのfor属性と同じ値を持つid属性が必要です。

ラベルが入力と関連付けられていてクリックされると、その入力にカーソルがフォーカスし、ユーザーがデータを入力する準備が整います。これは、支援技術に頼っているユーザーにとって、私たちのフォームをよりアクセシブルにするのに役立ちます。

placeholder属性

フォーム要素に何を入力すべきかをユーザーに案内するために、入力フィールドにプレースホルダーテキストを含めることができます。

これは、入力にplaceholder属性を追加することで行います。値は、入力に表示したいプレースホルダーテキストになります:

<label for="first_name">First Name:</label>
<input type="text" id="first_name" placeholder="Bob...">

プレースホルダーテキストを使って、テキストがどう入力・フォーマットされるべきかを示してください。

name属性

入力フィールドに入力されたデータが何を表すのかをユーザーが理解できるように、ラベルを使う必要があります。それと同じように、私たちがデータを送信するバックエンドにも、それぞれのデータが何を表すのかを知らせる必要があります。

これは、入力にname属性を追加することで行います:

<label for="first_name">First Name:</label>
<input type="text" id="first_name" name="first_name">

name属性は、フォームコントロールに入力されたデータが、送信後にどのデータを指すかの参照として機能します。これは、入力のための変数名のようなものだと考えることができます。フォームの入力には常にname属性を持たせるべきです。そうしないと、フォームが送信されたときに無視されてしまいます。

これがどのようなものかをより深く理解するために、httpbinにフォームを送信してみましょう。このサービスは、送信されたデータを確認できるレスポンスを送り返してくれます。以下のフォームに記入して送信をクリックしてください:

See the Pen form-basics-name-attribute by TheOdinProject (@TheOdinProjectExamples) on CodePen.

レスポンスから注目すべき出力は「form」オブジェクトです。次のようなものになるはずです:

"form": {
    "age": "33",
    "first_name": "John",
    "last_name": "Doe"
  },

フォーム内のいくつかの入力フィールドのname属性を変更したり、その属性を完全に削除したりしてから、もう一度フォームを送信して、レスポンス内のフォームデータがどう変わるか見てみてください。

フォームの外でフォームコントロールを使う

HTMLが提供するフォームコントロールのどれでも、<form>要素の外で、たとえデータを送信できるバックエンドサーバーがない場合でも使うことができる、ということは言及する価値があります。

例えば、ユーザーから何らかのデータを取得する入力を用意し、それをJavaScriptでページの別の場所に表示したい場合があるかもしれません:

See the Pen using-form-controls-outside-of-form by TheOdinProject (@TheOdinProjectExamples) on CodePen.

カリキュラムの後の方のプロジェクトで、このようなフォームコントロールからのデータを操作する必要が出てきます。

type属性

Email入力は、メールアドレス専用の特殊なテキスト入力です。モバイルデバイスで@記号を含む異なるキーボードが表示され、メールアドレスの入力を簡単にしてくれるという点で、テキスト入力とは異なります。

また、ユーザーが正しくフォーマットされたメールアドレスを入力したことも検証してくれますが、バリデーションについては後でさらに詳しく扱います。

email入力を作成するには、type属性が"email"であるinput要素を使います:

<label for="user_email">Email Address:</label>
<input type="email" id="user_email" name="email" placeholder="you@example.com">

Password入力は、もう一つの特殊なテキスト入力です。入力されたデータを別の文字(通常はアスタリスク(*)や黒丸(•))でマスクし、入力された内容を誰にも見られないようにするという点で、通常のテキスト入力とは異なります。

password入力は、typeが"password"であるinput要素を使って作成できます:

<label for="user_password">Password:</label>
<input type="password" id="user_password" name="password">

number入力は数値のみを受け付け、ユーザーが入力しようとする他の文字はすべて無視します。

number入力は、type属性が"number"であるinput要素を使って作成します:

<label for="amount">Amount:</label>
<input type="number" id="amount" name="amount">

ユーザーから日付を収集するには、date入力を使うことができます。この入力は、日付選択カレンダーを描画することで、日付を選ぶ際のより良いユーザー体験を提供してくれるという点でユニークです。

date入力を作成するには、type属性が"date"であるinput要素を使います:

<label for="dob">Date of Birth:</label>
<input type="date" id="dob" name="dob">

テキストエリア

厳密にはinput要素ではありませんが、text area要素は、ユーザーコメントやレビューのような複数行にまたがるテキストを受け付けられる入力ボックスを提供します。また、右下の角をクリックしてドラッグすることで、大きくしたり小さくしたりリサイズすることもできます。

テキストエリアを作成するには、<textarea>要素を使います:

<textarea></textarea>

input要素とは異なり、Textarea要素には終了タグがあります。これにより、テキストエリアに表示させたい初期コンテンツをラップできます:

<textarea>Some initial content</textarea>

Text area要素は、他のフォームコントロールにはないいくつかの独自の属性を受け付けます。それらはrows属性とcols属性です。これらを使うと、テキストエリアの初期の高さ(rows)と幅(cols)をコントロールできます:

<textarea rows="20" cols="60"></textarea>

選択要素

時には、あらかじめ定義されたリストからユーザーに値を選択させたい場合があります。これが、select要素が役立つ場面です。

セレクトドロップダウン

select要素は、ユーザーがオプションを選択できるドロップダウンリストを描画します。構文的には、select要素は順序なしリストと似たマークアップを持ちます。select要素は、選択可能なオプションであるoption要素をラップします。

セレクトドロップダウンを作成するには、<select>要素を使います。select要素の中に表示したいオプションは、<option>要素を使って定義します:

<select name="Car">
  <option value="mercedes">Mercedes</option>
  <option value="tesla">Tesla</option>
  <option value="volvo">Volvo</option>
  <option value="bmw">BMW</option>
  <option value="mini">Mini</option>
  <option value="ford">Ford</option>
</select>

すべてのoption要素はvalue属性を持つべきです(そうしないと、中のテキストコンテンツが使われます)。この値は、フォームが送信されたときにサーバーに送信されます。

ブラウザが最初にフォームを描画するときにデフォルトで選択される要素を、オプションの一つにselected属性を与えることで設定できます:

<select name="Car">
  <option value="mercedes">Mercedes</option>
  <option value="tesla">Tesla</option>
  <option value="volvo" selected>Volvo</option>
  <option value="bmw">BMW</option>
  <option value="mini">Mini</option>
  <option value="ford">Ford</option>
</select>

<optgroup>要素を使って、オプションのリストをグループに分けることもできます。optgroup要素はlabel属性を取り、ブラウザはこれを各グループのラベルとして使います:

<select name="fashion">
  <optgroup label="Clothing">
    <option value="t_shirt">T-Shirts</option>
    <option value="sweater">Sweaters</option>
    <option value="coats">Coats</option>
  </optgroup>
  <optgroup label="Foot Wear">
    <option value="sneakers">Sneakers</option>
    <option value="boots">Boots</option>
    <option value="sandals">Sandals</option>
  </optgroup>
</select>

ラジオボタン

セレクトドロップダウンは、ユーザーに選んでもらいたいオプションの広範なリストがある場合に、ページ上のスペースを節約するのに優れています。しかし、選択肢が5個以下の小さなリストの場合は、ドロップダウンの裏に隠すのではなく、ページ上に表示する方が良いユーザー体験になることが多いです。

この場合、ラジオボタンを使うことができます。ラジオボタンを使うと、ユーザーが一つを選べる複数のオプションを作成できます。ラジオボタンを作成するには、再びあの融通の利くinput要素を、type属性を"radio"にして使います:

<h1>Ticket Type</h1>
<div>
  <input type="radio" id="child" name="ticket_type" value="child">
  <label for="child">Child</label>
</div>

<div>
  <input type="radio" id="adult" name="ticket_type" value="adult">
  <label for="adult">Adult</label>
</div>

<div>
  <input type="radio" id="senior" name="ticket_type" value="senior">
  <label for="senior">Senior</label>
</div>

一つのラジオボタンを選択してから別のものを選択すると、最初のものの選択が解除されます。ラジオボタンがこれを行う理由は、同じname属性を持っているからです。これにより、ブラウザはこれらの要素が同じオプションのグループの一部であることを知ります。

checked属性を追加することで、デフォルトで選択されるラジオボタンを設定できます:

<h1>Ticket Type</h1>
<div>
  <input type="radio" id="child" name="ticket_type" value="child">
  <label for="child">Child</label>
</div>

<div>
  <input type="radio" id="adult" name="ticket_type" value="adult" checked>
  <label for="adult">Adult</label>
</div>

<div>
  <input type="radio" id="senior" name="ticket_type" value="senior">
  <label for="senior">Senior</label>
</div>

チェックボックス

チェックボックスは、あらかじめ定義されたオプションのセットからユーザーが選択できるという点で、ラジオボタンと似ています。しかし、ラジオボタンとは異なり、一度に複数のオプションを選択できるようにします。

チェックボックスを作成するには、type属性が"checkbox"であるinput要素を使います:

<h1>Pizza Toppings</h1>

<div>
  <input type="checkbox" id="sausage" name="topping" value="sausage">
  <label for="sausage">Sausage</label>
</div>

<div>
  <input type="checkbox" id="onions" name="topping" value="onions">
  <label for="onions">Onions</label>
</div>

<div>
  <input type="checkbox" id="pepperoni" name="topping" value="pepperoni">
  <label for="pepperoni">Pepperoni</label>
</div>

<div>
  <input type="checkbox" id="mushrooms" name="topping" value="mushrooms">
  <label for="mushrooms">Mushrooms</label>
</div>

何かをtrueにするかfalseにするかをユーザーに切り替えてもらいたい場合、単一のチェックボックスを使うこともできます。例えば、アカウントを作成する際にニュースレターに登録する場合などです:

<div>
  <input type="checkbox" id="newsletter" name="news_letter">
  <label for="newsletter">Send me the news letter</label>
</div>

checked属性を与えることで、ページ読み込み時にデフォルトでチェックされるようにチェックボックスを設定できます:

<div>
  <input type="checkbox" id="newsletter" name="news_letter" checked>
  <label for="newsletter">Send me the news letter</label>
</div>

ボタン

button要素は、ユーザーがフォームを送信したり他のアクションをトリガーしたりするためにやり取りできる、クリック可能なボタンを作成します。

ボタンを作成するには、<button>要素を使います。ボタンの中に表示したいコンテンツやテキストは、開始タグと終了タグの中に入れます:

<button>Click Me</button>

button要素はまた、ブラウザにどんな種類のボタンを扱っているかを伝えるtype属性も受け付けます。私たちが使える3種類のボタンがあります。

送信ボタン

ユーザーがフォームへの入力を終えたら、それを送信する方法が必要になります。これには専用のボタンがあります。送信ボタンです。送信ボタンがクリックされると、それが含まれているフォームを送信します。type属性は、typeが指定されていないか提供された値が無効な場合、デフォルトでsubmitという値を持ちます。

送信ボタンを作成するには、type属性が"submit"であるbutton要素を使います:

<button type="submit">Submit</button>

リセットボタン

リセットボタンは、ユーザーがフォームに入力したすべてのデータをクリアし、フォーム内のすべての入力を最初の状態に戻します。

リセットボタンを作成するには、type属性が"reset"であるbutton要素を使います:

<button type="reset">Reset</button>

汎用ボタン

3つ目で最後のボタンのタイプは、何にでも使える汎用ボタンです。インタラクティブなUIを作成するためにJSと一緒によく使われます。

汎用ボタンを作成するには、type属性が"button"であるbutton要素を使います:

<button type="button">Click to Toggle</button>

フォーム内でのボタンのtypeのデフォルト

typeの値がsubmit(たまたまデフォルトの値でもあります)であるフォーム内のボタンは、常に新しいリクエストを試みてデータをサーバーに送り返そうとする、ということを覚えておくことが重要です。したがって、データを送信すること以外の目的でフォーム内で使われるボタンについては、フォーム送信の意図しない影響を避けるために、常にtype属性を指定すべきです。

フォーム要素を整理する

ユーザーに入力してもらいたいデータに対して正しい入力を使うことは、フォームをユーザーフレンドリーにする上で大きな効果があります。しかし、より大きなフォームでは、記入すべき入力がたくさんあると、ユーザーは簡単に圧倒され、やる気をなくしてしまうことがあります。

幸いなことに、HTMLにはフォームを視覚的に区別され消化しやすいセクションに整理するのを簡単にしてくれる、いくつかの要素が用意されています。

fieldset要素

fieldset要素は、関連するフォーム入力を一つの論理的な単位にグループ化できるコンテナ要素です。

fieldsetを作成するには、<fieldset>要素を使います。グループ化したいフォーム入力は、fieldsetの開始タグと終了タグの中に入れます:

<fieldset>
  <label for="first_name">First Name</label>
  <input type="text" id="first_name" name="first_name">

  <label for="last_name">Last Name</label>
  <input type="text" id="last_name" name="last_name">
</fieldset>

legend

legend要素は、field setに見出しやキャプションを与え、ユーザーが入力のグループが何のためのものかを見られるようにするために使われます。

legendを作成するには、<legend>要素を使い、表示したいテキストを開始タグと終了タグの中に入れます。legendは常に、fieldsetの開始タグの直後に来るべきです:

<fieldset>
  <legend>Contact Details</legend>

  <label for="name">Name:</label>
  <input type="text" id="name" name="name">

  <label for="phone_number">Phone Number:</label>
  <input type="tel" id="phone_number" name="phone_number">

  <label for="email">Email:</label>
  <input type="email" id="email" name="email">
</fieldset>

<fieldset>
  <legend>Delivery Details</legend>

  <label for="street_address">Street Address:</label>
  <input type="text" id="street_address" name="street_address">

  <label for="city">City:</label>
  <input type="text" id="city" name="city">

  <label for="zip_code">Zip Code:</label>
  <input type="text" id="zip_code" name="zip_code">
</fieldset>

これらの要素の一般的な使用例は、fieldsetを使ってラジオボタンをグループ化し、legendを使ってそれぞれのオプションが最終的に何のためのものかをユーザーに伝えることです:

<fieldset>
  <legend>What would you like to drink?</legend>

  <div>
    <input type="radio" name="drink" id="coffee" value="coffee">
    <label for="coffee">Coffee</label>
  </div>

  <div>
    <input type="radio" name="drink" id="tea" value="tea">
    <label for="tea">Tea</label>
  </div>

  <div>
    <input type="radio" name="drink" id="soda" value="soda">
    <label for="soda">Soda</label>
  </div>
</fieldset>

フォームのスタイリングについての注意

次に続く課題のセクションで、フォームのスタイリングを深く掘り下げるリソースを提供します。しかし、課題に入る前に、HTMLフォームをスタイリングすることのいくつかの課題と、それらをどう乗り越えられるかについて話しておくべきでしょう:

デフォルトのブラウザスタイル

各ブラウザはフォームコントロールに独自のデフォルトスタイルを持っており、使っているブラウザによってユーザーにとってフォームの見た目が視覚的に異なるものになります。

すべてのブラウザで一貫したデザインにするためには、これらのデフォルトスタイルを上書きし、自分たちでスタイリングする必要があります。

スタイリングが厄介、あるいはまったく不可能なフォームコントロール

text、email、password、テキストエリアのようなテキストベースのフォームコントロールは、比較的スタイリングが簡単です。これらは他のHTML要素と同じように動作し、ほとんどのCSSプロパティを使うことができます。

ラジオボタンやチェックボックス用にカスタムスタイルを作成しようとすると、もっと厄介になります。しかし、カスタムチェックボックススタイリングについてのこのガイドのように、望むデザインを達成するために使えるガイドがたくさん出回っています。また、ラジオボタンやチェックボックスのスタイリングをずっと簡単にするための新しいCSSプロパティも、最近になって利用可能になりました。

他の要素の特定の側面は、例えばカレンダーや日付ピッカーのように、まったくスタイリングが不可能なものもあります。これらにカスタムスタイルを適用したい場合は、JavaScriptでカスタムフォームコントロールを構築するか、既製のソリューションを提供してくれる多数のJavaScriptライブラリのいずれかを使う必要があります。

課題

フォームの基本

  1. MDNの「Introductory Tutorials」(フォームについて)を読んで、一緒に手を動かしてみてください。
  2. MDNの「The Different Form Controls」ガイドを読んで、一緒に手を動かしてみてください。

フォームのスタイリング

  1. MDNのForm Styling Tutorialsを読んで、一緒に手を動かしてみてください。「Customizable select elements」と「Customizable select listbox」のチュートリアルは、まだ多くのブラウザでサポートされていない非常に新しいCSS機能に依存しているため、スキップしても構いません。
  2. internetingishardのフォームについてのガイドを読んで、一緒に手を動かしてみてください。
