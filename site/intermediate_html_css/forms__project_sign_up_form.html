イントロダクション

このプロジェクトは、過去数レッスンで吸収してきた新しい項目のいくつかを実際に活かす機会を与えることを意図しています。今回は、架空のサービスのためのサインアップフォームです。

課題

ステップ1: セットアップと計画

  1. gitリポジトリをセットアップしてください(復習が必要な場合は過去のプロジェクトを参照してください)。
  2. すべてが正しくリンクされていることを確認するためだけに、ダミーコンテンツでHTMLとCSSファイルをセットアップしてください。
  3. デザインファイルのフル解像度版をダウンロードし、HTMLドキュメントでどのようにレイアウトする必要があるかについて大まかなイメージをつかんでください。

ステップ2: アセットを集める

  1. デザインには大きな背景画像があるので、そのセクションに使いたい画像を探してダウンロードしてください。デザインで使われているものはunsplash.comで見つけることができますが、自分自身で選んでも構いません。画像の作成者のクレジットを必ず表示してください!
  2. 「ロゴ」セクション用に外部フォントを選んでください。私たちはNorse Boldを使いましたが、好きなフォントを使って構いません。
  3. 画像サイドバーには、このOdinのロゴを使いました。

ステップ3: いくつかのヒント!

  1. このプロジェクトにどう取り組むかは基本的にあなた次第ですが、まずページの構造を骨組みとして作り、それからさまざまなセクションに一つずつ取り組んでいくのが賢明です。
  2. 「ODIN」のロゴの背後にあるエリアは、暗いけれど半透明の背景色を持つdivです。これにより、賑やかな背景画像に対するテキストの可読性が高まります。
  3. 「Create Account」ボタンに選んだ色は、背景画像に見られる色調に似せています。具体的には#596D48です。
  4. 入力欄はデフォルトで非常に薄い枠線(#E5E7EB)を持っていますが、私たちは2つのバリエーションを含めました。まず、パスワード入力は、無効なパスワードが含まれている場合は赤い枠線を持つべきです。これは、前のレッスンで学んだ:user-invalid疑似クラスで処理できます。
  5. もう一つのバリエーションは、選択されている入力で、青い枠線と控えめなbox-shadowを持つべきです。これは、以前のレッスンで学んだ:focus疑似クラスで実現できます。
  6. モバイルであなたのプロジェクトを見栄えよくすることについては心配しないでください。レスポンシブデザインは、カリキュラムのもっと後になるまで扱いません。
  7. パスワードフィールドが互いに一致していることを検証するには、JavaScriptが必要です。JavaScriptを使ってフォームを検証することは、今後のレッスンで扱います。今のところは、それぞれのフィールドを個別に検証するだけにしてください。
