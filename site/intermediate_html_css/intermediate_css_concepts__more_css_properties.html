CSS can do quite a lot! Here we cover some more properties you can use to make your sites pop!

イントロダクション

これまで、たくさんのCSSプロパティを使ってきました。ここまでは、それらのプロパティが何であるかを実際に定義することなく使ってきましたが、CSSプロパティの残りを説明していくにつれて、CSSプロパティに関するドキュメントを読むこと自体に、もう少し焦点を当てていきます。このレッスンでは、これから遭遇することになる、いくつかの一般的なCSSプロパティを紹介します。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • 一般的なCSSプロパティのリストと、その使い方を学びます。

Opacity

opacityプロパティは、指定した要素がどれだけ透明であるかを定義します。これは0(完全に透明)から1(完全に不透明)までの値を取り、その間の値はある程度透明になります。

OpacityについてのMdnドキュメントを読んで、それがどのように機能するかを理解してください。

Background

backgroundプロパティは、実際には他の多くの個別のbackground関連プロパティをまとめたショートハンドプロパティです。背景色や背景画像など、要素の背景に関連するほぼすべてのことをコントロールするために使うことができます。

Backgroundについてのmdnドキュメントを読んで、それが何を行い、どのように機能するかを理解してください。

Borders

これまでにボーダーをいくらか扱ってきましたが、ボーダーに関連するCSSプロパティにはまだ多くのニュアンスがあります。ボーダーの丸め方など、知っておくべき重要な追加のトピックがいくつかあります。

Borderについてのmdnドキュメント、そして具体的にはborder-radiusについてのmdnドキュメントを読んで、それらがどのように機能するかを理解してください。

Box-shadow

想像通り、box-shadowはある要素に影を追加します。前のレッスンで学んだtext-shadowと考え方は似ていますが、これは要素全体に適用されます。

Box-shadowについてのmdnドキュメントを読んで、それがどのように機能するかを理解してください。

Overflow

overflowプロパティは、要素のコンテンツがその要素のボックスに対して大きすぎる場合に何が起こるかをコントロールします。

Overflowについてのmdnドキュメントを読んで、それがどのように機能するかを理解してください。
