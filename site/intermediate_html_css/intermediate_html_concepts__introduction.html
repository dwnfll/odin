Lets go deeper into the world of HTML and CSS!

イントロダクション

これは、HTMLとCSSをさらに深く掘り下げる2部構成のコースの最初の部分です。

私たちのFoundationsのレッスンは、意図的に可能なことの表面をなぞる程度にとどめていました。あなたができるだけ早く先に進み、ある程度生産的になれるように、始めるための最低限必要なものだけを提供したかったのです。しかし今こそ、ペースを落として深く掘り下げる時です!

おそらく今頃には、私たちがFoundationsのコンテンツで触れたよりも、はるかに多くのHTML要素があることに気づいているでしょう。このコース全体を通して、フォームやテーブルといった、残りの重要な要素を扱っていきます。

変数、関数、シャドウ、そしてもちろんグリッドレイアウトなど、このコースを通して学ぶことになる、CSSでできることもたくさんあります!覚悟してください!このコースを終える頃には、インターネット上で見つけられるほぼどんなウェブデザインでも再現できるようになります……これは今後持ち続けるべき重要なスキルです。フロントエンド専門の仕事を目指していなくても、ポートフォリオ作品を見栄え良くできることは、自分を際立たせる上で重要です。

アニメーション、アクセシビリティ、レスポンシブデザインについては、カリキュラムの後半、Advanced HTML and CSSコースで学びます。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • このコースで扱う追加のHTML要素とCSSの概念についての概要をつかむ。

課題

  1. このHTML要素のリファレンスを読み通して、他にどんなHTML要素が利用できるかについての概要をつかんでください。重要な部分は進めていく中で学んでいくので、これを暗記する必要はありませんが、今ざっと見ておくことで、後で内容が定着しやすくなります。
  2. 少し圧倒されるような見た目のCSSチートシートにざっと目を通してみてください。繰り返しになりますが、このリストから何か特定のことを学んだり暗記したりする必要はありません。ただ、まだ学ぶべきことがどれくらい残っているかの感覚をつかむために使ってください!
