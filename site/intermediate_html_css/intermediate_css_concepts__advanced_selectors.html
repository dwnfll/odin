Advanced Selectors

日本語訳

← intermediate_html_css

You can do a lot more than just target specific classes and ids in your CSS...

イントロダクション

ここまでで、基本的なCSSセレクタには慣れ、タイプ・クラス・IDで要素を選択することに苦労はしないはずです。しかし、本物のCSSの達人になるには、時にはもっと専門的な道具が必要です。このレッスンでは、高度なCSSセレクタを見ていき、より細かい粒度で要素をターゲットにする方法を紹介します。

これらのセレクタは、HTMLマークアップを変更できない(あるいは変更したくない)場合に特に役立ちます。

高度なセレクタはたくさんあるので、一つ一つすべてを扱うのはこのレッスンの範囲を超えています。しかし、最も便利で一般的なものをいくつか取り上げ、さらに自分で学びを深めるための概念と語彙を身につけてもらいます。

いつものように、コードエディタを開いて、これらのセレクタで自分自身の実験を行ってみてください。実践あるのみです!

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • 親セレクタと兄弟セレクタの使い方を理解します。
  • 疑似クラスと疑似要素の違いを認識します。
  • 最も便利で一般的な疑似要素と疑似クラスのいくつかについて学びます。
  • 属性やその一部を選択するさまざまな方法について学びます。

子コンビネータと兄弟コンビネータ

クラスを参照せずにさまざまな要素にアクセスできる、さらにいくつかの方法を見てみましょう。まさにそれを行うための3つの新しいセレクタがあります。

  • > - 子コンビネータ
  • + - 隣接兄弟コンビネータ
  • ~ - 一般兄弟コンビネータ

このサンプルマークアップを使って、いくつかの実践的な例に取り組んでいきます。

<main class="parent">
  <div class="child group1">
    <div class="grand-child group1"></div>
  </div>
  <div class="child group2">
    <div class="grand-child group2"></div>
  </div>
  <div class="child group3">
    <div class="grand-child group3"></div>
  </div>
</main>

ここまでで、Intro to CSSで学んだ子孫コンビネータを使ってルールを書くことにかなり慣れているはずです。例えば、mainの中のchildとgrand-childの両方のdivをすべて選択したい場合は、次のように書けます:

main div {
  /* かっこいいCSS */
}

しかし、もっと具体的にchildまたはgrand-childのdivだけを選択したい場合はどうでしょうか?そこで役立つのが子コンビネータ>です。子孫コンビネータとは異なり、直接の子要素のみを選択します。

/* これにより、クラス"child"を持つdivが選択される */
main > div {
  /* かっこいいCSS */
}

/* これにより、クラス"grand-child"を持つdivが選択される */
main > div > div {
  /* さらにかっこいいCSS */
}

別の言い方をすると、子セレクタはインデントが1レベル下の要素を選択します。ターゲットの隣(直後)にある要素、つまり同じインデントレベルの要素を選択するには、隣接兄弟コンビネータ+を使うことができます。

/* これにより、クラス"child group2"を持つdivだけが選択される */
.group1 + div {
  /* かっこいいCSS */
}

/* これにより、クラス"child group3"を持つdivだけが選択される */
.group1 + div + div {
  /* さらにかっこいいCSS */
}

最後に、最初の一つだけでなく、ある要素に続くすべての兄弟要素を選択したい場合は、一般兄弟コンビネータ~を使うことができます。

/* .group1のdivの兄弟すべて - この場合、2番目と3番目の.child divが、これにより選択される */
.group1 ~ div {
  /* かっこいいCSS */
}

子孫コンビネータと同様に、これらのセレクタには特別な詳細度のルールはありません。それらの詳細度スコアは、単にその構成要素によって決まります。

これらについてさらに学びたい場合は、このコンビネータについてのMDNの記事が良い概要を提供してくれます。

疑似セレクタ

疑似セレクタに飛び込む前に、疑似クラスと疑似要素の違いについて簡単に触れておきます。疑似クラスセレクタはコロン1つを前に付け、HTMLにすでに存在する要素をターゲットにする別の方法です。疑似要素はコロン2つを前に付け、マークアップに通常は存在しない要素をターゲットにするために使われます。すぐにはピンとこなくても心配いりません。以下でいくつかの例を見ていきます。

疑似クラス

疑似クラスは、HTML内の要素をターゲットにするさまざまな方法を提供してくれます。かなりたくさんの種類があり、いくつかの異なる系統に分かれます。HTML内での位置や構造に基づくものもあれば、特定の要素の状態や、ユーザーが現在それとどうやり取りしているかに基づくものもあります。ここで詳細をすべて扱うには多すぎますが、最も便利なものをいくつか見ていきます。疑似クラスは通常のクラスと同じ詳細度(0, 0, 1, 0)を持ちます。通常のクラスと同様に、ほとんどのものは連結できます。

CSSの詳細度の記法を計算する

上記の(0,0,1,0)は、詳細度を計算するための記法です。それがどのように機能するかについてさらに知りたい場合は、このCSSの詳細度についての記事の「Calculating CSS Specificity Value」のセクションにざっと目を通してください。

いつものように、利用可能なものの全体像を確認するために、疑似クラスについてのMDNのドキュメントを確認することを忘れないでください。

動的・ユーザーアクション疑似クラス

これらの種類の便利な疑似クラスは、あなたのページをよりダイナミックでインタラクティブに感じさせることができます。

:focusは、ユーザーがカーソルで選択するか、キーボードを使うことで、現在選択されている要素に適用されます。

:hoverは、ユーザーのマウスポインタの下にあるものすべてに影響します。これは、ボタンやリンクがインタラクト可能であることを強調するために追加のパンチを与えたり、ドロップダウンメニューをトリガーしたりするために使うことができます。

:activeは、現在クリックされている要素に適用され、ユーザーのアクションに効果があったというフィードバックをユーザーに与えるのに特に役立ちます。これは、ボタンやその他のインタラクティブな要素に、より「触覚的な」フィードバックを与えるのに最適な方法です。

スタイルのないHTMLで、なぜリンクが青く、クリックすると紫に変わるのか不思議に思ったことはありませんか?それは、ブラウザがデフォルトでそのスタイルを実装しているからです。リンクに独自のカスタムスタイルを実装するには、:linkと:visited疑似クラスを活用してください。デフォルトのブラウザスタイルを単純化したバージョンは、次のようなものになります:

  /* このルールはすべてのリンクに適用される */
  a {
    text-decoration: underline;
  }

  /* これは未訪問のリンクに適用される */
  a:link {
    color: blue;
  }

  /* そしてお察しの通り、これはユーザーがクリックしたすべてのリンクに適用される */
  a:visited {
    color: purple;
  }

構造的疑似クラス

構造的疑似クラスは、DOM内での位置に基づいて要素を選択する強力な方法です。

:rootは、ドキュメントの最上位レベルを表す特別なクラスです。つまり、親を持たない唯一の要素です。一般的にウェブで作業する際、これはhtml要素と同等ですが、:rootとhtmlの間にはいくつかの微妙な違いがあります。

:rootは一般的に、カスタムプロパティやCSS変数、あるいはbox-sizing: border-box;のようなルールなど、どこでも利用可能にしたい「グローバルな」CSSルールを置く場所です。

:first-childと:last-childは、最初または最後の兄弟である要素にマッチします。

同様に、:emptyは子要素を全く持たない要素にマッチし、:only-childは兄弟要素を全く持たない要素にマッチします。

よりダイナミックなアプローチとして、:nth-childを使うことができます。これはいくつかの異なる使い方ができる柔軟な疑似クラスです。

  .myList:nth-child(5) {/* クラスmyListを持つ5番目の要素を選択 */}

  .myList:nth-child(3n) { /* クラスmyListを持つ3番目ごとの要素を選択 */}

  .myList:nth-child(3n + 3) { /* クラスmyListを持つ3番目ごとの要素を、3番目から始めて選択 */}

  .myList:nth-child(even) {/* クラスmyListを持つ偶数番目の要素をすべて選択 */}

疑似要素

疑似クラスが状態や構造に基づいてHTML要素とやり取りする別の方法を提供してくれるのに対し、疑似要素はより抽象的です。要素ではまったくないHTMLの一部に影響を与えることができます。これらの特別な要素は、通常の要素と同じ詳細度(0, 0, 0, 1)を持ちます。さまざまな創造的な方法で利用できる、便利な疑似要素がいくつかあります。

::markerを使うと、<li>要素の弾丸や番号のスタイルをカスタマイズできます。

::first-letterと::first-lineを使うと、(お察しの通り!)テキストの最初の文字や行に特別なスタイルを与えることができます。

::selectionを使うと、ユーザーがページ上のテキストを選択したときのハイライトを変更できます。

::beforeと::afterを使うと、HTMLではなくCSSでページに追加の要素を加えることができます。これを使ってさまざまな方法でテキストを装飾するのは、よくある使用例の一つです。

<style>
  .emojify::before {
    content: '😎 😄 🤓';
}

  .emojify::after {
    content: '🤓 😄 😎';
}
</style>

<body>
  <div> Let's <span class="emojify">emojify</span>this span!</div>
</body>

これらの疑似要素をこのように使うと、次のような結果が得られます:

Let's 😎 😄 🤓 emojify 🤓 😄 😎 this span!

まだまだたくさんあります!可能なことのすべてのリストを見るには、疑似要素のドキュメントをざっと見てみてください。

属性セレクタ

道具箱に加える最後のツールは、属性セレクタです。属性とは、HTML要素の開始タグの中にある何か、例えばsrc='picture.jpg'やhref="www.theodinproject.com"のようなものであることを思い出してください。

属性の値は自分で書くものなので、特定の値をターゲットにできる、もう少し柔軟なシステムが必要です。

属性セレクタは、クラスや疑似クラスと同じ詳細度(0, 0, 1, 0)を持ちます。

基本的な使い方の例をいくつか見てみましょう。

  • [attribute] - この一般的なセレクタは、与えられた属性が存在するものすべてを選択します。その値は問題になりません。
  • selector[attribute] - オプションとして、属性セレクタをクラスセレクタや要素セレクタなど、他の種類のセレクタと組み合わせることができます。
  • [attribute="value"] -本当に具体的にしたい場合は、=を使って特定の属性を特定の値にマッチさせることができます。
  [src] {
    /* これはsrc属性を持つあらゆる要素をターゲットにする */
  }

  img[src] {
    /* これはsrc属性を持つimg要素だけをターゲットにする */
  }

  img[src="puppy.jpg"] {
    /* これはsrc属性の値が正確に"puppy.jpg"であるimg要素をターゲットにする */
  }

時には、これらの属性へのアクセス方法をもっと一般的にする必要があります。例えば、src属性の値が.jpgで終わるimg要素だけに関心がある場合があるかもしれません。このような場合のために、属性の値の一部にマッチする属性セレクタがいくつかあります。以前に正規表現に出会ったことがあれば、これらの属性は似たような構文を使います。

  • [attribute^="value"] - ^= 先頭から文字列にマッチします。
  • [attribute$="value"] - $= 末尾から文字列にマッチします。
  • [attribute*="value"] - *= ワイルドカードセレクタは、文字列の内側のどこでもマッチします。
[class^='aus'] {
  /* クラスも属性です!
    これは'aus'で始まるあらゆるクラスをターゲットにします:
    class='austria'
    class='australia'
  */
}

[src$='.jpg'] {
  /* これは'.jpg'で終わるあらゆるsrc属性をターゲットにします:
  src='puppy.jpg'
  src='kitten.jpg'
  */
}

[for*='ill'] {
  /* これは内側のどこかに'ill'を持つあらゆるfor属性をターゲットにします:
  for="bill"
  for="jill"
  for="silly"
  for="ill"
  */
}

大文字小文字を区別しない検索や、ハイフンで区切られた部分文字列の検索など、属性セレクタで達成できる他のことについては、属性セレクタについてのMDNのドキュメントをざっと見てみてください。
