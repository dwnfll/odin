Positioning

日本語訳

← intermediate_html_css

Learn some new methods for moving items around on a webpage.

イントロダクション

ここまでで、margin、padding、flexboxなどを使って、画面上で要素を動かす練習をかなり積んできました。これらのテクニックはすべて、CSSのデフォルトの「ポジショニングモード」に依存していました。このデフォルトのポジショニングモードは直感的で、レイアウトのほとんどのニーズには引き続きこれを使っていくことになります。しかし、状況によっては非常に役立つ、他の方法も用意されています。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • 絶対位置指定(absolute positioning)の使い方を学びます。
  • 固定位置指定(fixed positioning)の使い方を学びます。
  • 追従位置指定(sticky positioning)の使い方を学びます。
  • 各プロパティの違いと、それらを組み合わせる方法を知ります。

静的位置指定と相対位置指定

あなたが慣れ親しんできたデフォルトのポジショニングモードはposition: staticです。staticとrelativeの違いはかなりシンプルです。staticはすべての要素のデフォルトの位置であり、top、right、bottom、leftのプロパティは要素の位置に影響を与えません。一方relativeは、staticとほとんど同じですが、top、right(など)のプロパティが、ドキュメントのフローにおけるその通常の位置を基準に、要素をずらします。

絶対位置指定

position: absoluteを使うと、周囲の他の要素を乱すことなく、画面上の正確な位置に何かを配置できます。より具体的には、ある要素に絶対位置指定を使うと、その要素は通常のドキュメントフローから取り除かれると同時に、祖先要素を基準として位置指定されます。言い換えると、ドキュメントの通常のフローから取り除かれた要素は、他の要素に影響を与えず、また他の要素からも影響を受けません。絶対位置指定を使うと、top、right、bottom、leftのプロパティを使って、画面上のどこにでも要素を配置できます。このプロパティは、他の要素を一切乱すことなく、画面上の正確な位置に何かを配置したい場合に本当に便利です。絶対位置指定の良い使用例としては、次のようなものがあります:

  • モーダル
  • キャプション付きの画像
  • 他の要素の上に重ねるアイコン

固定位置指定

固定要素も同様にドキュメントの通常のフローから取り除かれ、viewportを基準に位置指定されます。基本的にはtop、right、bottom、leftのプロパティを使ってそれを配置し、ユーザーがスクロールしてもそこにとどまります。これはナビゲーションバーやフローティングのチャットボタンなどに特に役立ちます。

追従位置指定

追従(sticky)要素は、それを通り過ぎてスクロールするまでは通常の要素のように振る舞い、それから固定要素のように振る舞い始めます。これらもドキュメントの通常のフローから取り除かれることはありません。少し分かりにくく聞こえるかもしれないので、この追従位置指定の例を見てみると、はっきりするかもしれません。これはセクションの見出しなどに役立ちます。ショップをスクロールしている間、今見ているカテゴリーがまだ表示されているのを覚えていますか?これはこうやって実現されているのです!
