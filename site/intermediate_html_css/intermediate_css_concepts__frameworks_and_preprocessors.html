Frameworks and Preprocessors are useful tools that you may want to investigate.

イントロダクション

ここまでで、あなたはかなりの量のバニラのHTMLとCSSを書き、開発者として成長していく中で使い続けることになる、多くのデザインテクニックを学んできました。あなたの経験を通して、CSSフレームワークやプリプロセッサ(別名プリコンパイラ)についての情報に出会ったことがあるかもしれません。これら両方の種類のツールは、CSSを書くことをより合理的で退屈でないものにしてくれます。

CSSフレームワークやプリプロセッサについて知っておくべき有用な理由は、それらが職場で一般的に見られるということです。エントリーレベルの職種の面接官は(たとえその仕事が特定のフレームワークやプリプロセッサを使っていたとしても)CSSの基礎により重点を置く可能性が高い一方で、これらのツールが何であるか、そしてそれらを学ぶ必要があると判断したときにどこで探せばよいかを知っておくことは、あなたにとって役立つでしょう。

学習のこの段階では、プロジェクトで引き続きバニラCSSを使うことが推奨されるということを承知しておくべきです。これらのフレームワークやプリプロセッサはすべてCSSを基盤としているため、強固な基礎を築くことで、将来どんなフレームワークやプリプロセッサでも学んだり切り替えたりすることが格段に容易になります。このコースの間に一つを学ぼうとすることは、基本的なCSSスキルを向上させることに比べて、長期的にはそれほど生産的でも価値があるものでもありません。

フレームワークの概要

異なるフレームワークは異なる目標を持っています。Bootstrapのようなフレームワークは、一般的に使われるCSSコードをあなたのためにパッケージ化するという重労働の多くを、アイコンやインタラクション(メニューのドロップダウンなど)まで含めて、行ってくれます。これらは、直感的で再利用可能でレスポンシブな要素をコーディングするプロセスを抽象化するよう設計されています。Tailwindのようなものは、通常それぞれが単一行のCSSだけを適用する、あらかじめ名前が付けられたクラスを提供することで、異なる構文を通してCSSの適用方法を変えることを目指しています。CSSフレームワークとは、結局のところ、フレームワークによって定義されたクラスを使って利用しアクセスできる、CSSの束に過ぎません。例えば、多くのフレームワークは、あなた自身でCSSを一切書くことなく、ボタンに必要なすべてのスタイルを追加してくれる.btnというクラスを提供します。一般的に、フレームワークを使うためには、それがあなたのウェブサイトをどう構造化することを期待しているか、そしてその特定のスタイルのセットを適用するためにどのクラスを使うかを理解する必要があります。

かなりたくさんのフレームワークが利用可能であることを承知しておくべきです。他に出会うかもしれない2つのフレームワークとしてBulmaとFoundationがありますが、他にもたくさんあります。

フレームワークの欠点

フレームワークは、エンドユーザーが簡単にやり取りできるインターフェースを持つサイトを迅速に作り出すのに優れています。しかし、人気のあるフレームワークのいくつかを一通り見てみると、フレームワークの似たような使い方のために、あなたが出会う多くのサイトの間にひどく多くの類似性があることに気づき始めるでしょう。その問題に加えて、あまりに多くの新しい開発者が、学習の早すぎる段階でフレームワークの学習に飛びついてしまうということもあります。バニラCSSを書く練習をしなくて済むという見込みは、非常に魅力的です。その結果、多くの開発者は、この非常に重要な言語の基礎を固めるのに十分なCSSの練習を積むことができていません。

さらに、CSSの基礎が弱いと、フレームワークのスタイリングを上書きしたり、ページ上のスタイルの問題をデバッグしたりするプロセスが非常に難しくなります。フレームワークが「裏側で」何をしているかを理解することは、後になってこれらの問題に対処できるようにするために不可欠です(そして信じてください、あなたは必ずそれに対処することになります)。

結局のところ、フレームワークは素早く始動するのに役立ちますが、長期的にはあなたを制約する可能性があります。一度フレームワークを使ってプロジェクトを始めると、それを取り除くのが難しくなることがあります。将来、あなた(またはあなたの雇用主!)は、あるプロジェクトにフレームワークを使うかどうか、使うとすればどれを使うかを決めなければならないかもしれません。

プリプロセッサの概要

プリプロセッサ(別名プリコンパイラ)は、CSSをより簡単に書けるようにしてくれる言語です。コードの繰り返しを減らし、例えばループや条件分岐を書けるようにしたり、複数のスタイルシートを結合できるようにしたりするなど、あらゆる種類の時間節約・コード節約機能を提供してくれます。

CSSプリプロセッサは、基本的には、いくつかの追加機能を提供する、バニラCSSへの拡張です。プリプロセッサを実行すると、あなたのコードを受け取り、プロジェクトにインポートできるバニラCSSに変換してくれます。

プリプロセッサには独自の便利なツールがいくつかありますが、それらの最も便利な機能の多くはバニラCSSにも実装されているため、これらの機能が本当に必要だと思わない限り、一つを学ぶオーバーヘッドの価値はないかもしれません。例えば、あなたはすでにカスタムプロパティについて学びましたが、これはかつてプリプロセッサでしか可能ではなかったものです。CSSのネストもかつては一部のプリプロセッサの一般的な利点でしたが、今ではバニラCSSに取り入れられ、最近ではより多くのブラウザサポートを得るようになってきています。

使われている標準的なプリプロセッサのいくつかは、SASS、LESS、Stylusです。

課題

  1. CSSフレームワークについてのこの簡単な概要を読んでください。
  2. SASS、LESS、Stylusの概要にざっと目を通してください。
  3. CSSプリプロセッサを使うことのいくつかの欠点について読んでください。この記事が書かれて以降、CSSにはネストと、カスタムプロパティによる変数が加わったことに注意してください。
