Creating a Grid

日本語訳

← intermediate_html_css

Let's get started by creating a Grid.

イントロダクション

CSS Grid Layoutが何であるかが分かったところで、今度は自分自身のグリッドを作成する方法を学びます。このレッスンでは、グリッドコンテナの作成、列と行の追加、Gridの背後にある明示的(explicit)と暗黙的(implicit)という概念、そしてグリッドの間隔の空け方を扱います。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • グリッドコンテナを作成します。
  • グリッドトラックを定義します。
  • 暗黙的なグリッドと明示的なグリッドの違いを説明します。
  • グリッドセル間のギャップを設定します。

グリッドをセットアップする

このレッスンでは、あまり手間をかけずにグリッドレイアウトを作るのがいかに簡単かを紹介します。今後のレッスンで、位置指定や複雑なグリッドの作り方についてさらに知ることになりますが、今のところは基本的なものから始めましょう。

グリッドコンテナ

CSS Gridは、コンテナとアイテムという観点で考えることができます。ある要素をグリッドコンテナにすると、それはグリッド全体を「含む(contain)」ことになります。CSSでは、要素はdisplay: gridまたはdisplay: inline-gridというプロパティによってグリッドコンテナに変わります。

See the Pen My First Grid | CSS Grid by TheOdinProject (@TheOdinProjectExamples) on CodePen.

この例では、class="container"が付いた親要素がグリッドコンテナになり、その下の直接の子要素それぞれが自動的にグリッドアイテムになります。CSS Gridの簡単なところは、それぞれの子要素にプロパティを割り当てる必要がないということです。

ここでグリッドアイテムになるのは直接の子要素だけであることに注意してください。もしこれらの子要素の一つの下に、さらに別の要素が子として存在していた場合、それはグリッドアイテムにはなりません。以下の例では、paragraph要素はグリッドアイテムではありません:

<!-- index.html -->

<div class="container">
  <div>Item 1</div>
  <div>Item 2
    <p>I am not a grid item!</p>
  </div>
  <div>Item 3</div>
  <div>Item 4</div>
</div>

しかし、flexboxのレッスンで学んだのと同じように、グリッドアイテムはまたグリッドコンテナにもなり得ます。ですので、望むならグリッドの中にグリッドを作ることもできます。

グリッドのラインとトラック、なんとまあ!

例に沿ってコードを書いているなら(そうですよね?)、まだあまりグリッドらしく見えないことに気づくでしょう。CSS Gridについての多くのリソースは、最初からボックスや枠線付きのグリッドテーブルを見せたがります。しかし、グリッドコンテナとグリッドアイテムに枠線がなければ、これらのラインはページ上には実際には見えません。ですから心配いりません、ちゃんとそこにあります!

開発者ツールを使ってウェブページ上でこれらの要素を検証すると、コード内のグリッド要素にグリッドバッジが表示されることに気づくでしょう。開発者ツールのLayoutオプションでは、これらの目に見えないライン、トラック、グリッドの領域を表示できるオーバーレイを選択できます。以下の課題でブラウザの開発者ツールの使い方について読み、次のレッスンでラインやトラック、領域についてさらに詳しく学びます。

列と行

グリッドコンテナといくつかのグリッドアイテムがすべてセットアップできたので、次は列と行を指定していきましょう。これによってグリッドトラック(グリッド上のライン間のスペース)が定義されます。ですので、列トラックを設定して列の間にスペースを作り、行トラックを設定して行の間にスペースを作ることができます。トラックとラインの詳細については次のレッスンで扱いますが、今のところはいくつかの列と行を作ってみましょう。

grid-template-columnsとgrid-template-rowsプロパティを使うと、列と行のトラックを簡単に定義できます。このレッスンでは、列と行の定義にピクセルを使い続けます。今後のレッスンでは、パーセンテージやフラクショナル単位を使った定義についても学びます。

See the Pen Columns and Rows 1 | CSS Grid by TheOdinProject (@TheOdinProjectExamples) on CodePen.

グリッドにさらに列や行を追加したい場合は、これらの値を定義して別のトラックを作ることができます。例に3列目を追加したいとしましょう:

See the Pen Columns and Rows 2 | CSS Grid by TheOdinProject (@TheOdinProjectExamples) on CodePen.

CSS Gridには、行と列を定義するためのショートハンドプロパティも用意されています。先ほどの例では、grid-template-rowsとgrid-template-columnsプロパティを、ショートハンドのgrid-templateプロパティに置き換えることができます。ここでは、行と列を一度に定義できます。このプロパティでは、スラッシュの前に行を、スラッシュの後に列を定義します。同じ列と行の値を保ったまま、代わりにショートハンドプロパティを使ってみましょう:

/* styles.css */

.container {
  display: grid;
  grid-template: 50px 50px / 50px 50px 50px;
}

列と行は、必ずしもすべて同じ値を共有する必要はありません。1列目が他の列の5倍の幅になるように、列のプロパティ値を変えてみましょう:

See the Pen Columns and Rows 3 | CSS Grid by TheOdinProject (@TheOdinProjectExamples) on CodePen.

明示的グリッドと暗黙的グリッド

4つのグリッドアイテムのための2x2レイアウトという、元の例に戻りましょう。grid-template-columnsやgrid-template-rowsプロパティを変更せずに、コンテナに5つ目のアイテムを追加したらどうなるでしょうか?

See the Pen Implicit Grid | CSS Grid by TheOdinProject (@TheOdinProjectExamples) on CodePen.

5つ目のアイテムがグリッド上に配置され、私たちが定義していない3行目に収まっていることに気づくでしょう。これは暗黙的グリッドという概念によるもので、これがCSS Gridが、レイアウトを明示的に定義していないグリッドアイテムを自動的に配置できる仕組みです。

grid-template-columnsとgrid-template-rowsプロパティを使うとき、私たちはグリッドアイテムをレイアウトするためのグリッドトラックを明示的に定義しています。しかし、追加のコンテンツのためにグリッドがさらに多くのトラックを必要とするとき、グリッドは暗黙的に新しいグリッドトラックを定義します。さらに、grid-template-columnsやgrid-template-rowsプロパティから確立されたサイズの値は、これらの暗黙的なグリッドトラックには引き継がれません。しかし、暗黙的なグリッドトラックに値を定義することはできます。

grid-auto-rowsとgrid-auto-columnsプロパティを使って、暗黙的なグリッドトラックのサイズを設定できます。こうすることで、暗黙的なグリッドが追加のコンテンツのために作る新しいトラックが、私たちが定義した値に設定されるようにできます。

新しい行を、明示的な行トラックのサイズと同じ値に保ちたいとしましょう:

/* styles.css */

.container {
  display: grid;
  grid-template-columns: 50px 50px;
  grid-template-rows: 50px 50px;
  grid-auto-rows: 50px;
}

デフォルトでは、CSS Gridは追加のコンテンツを暗黙的な行で追加します。つまり、追加の要素は縦方向にグリッドのさらに下へと追加され続けるということです。グリッドに沿って水平方向に追加のコンテンツを加えたい状況はずっと少ないでしょうが、しかしそれはgrid-auto-flow: columnプロパティを使って設定でき、それらの暗黙的なトラックのサイズはgrid-auto-columnsプロパティで定義できます。

Gap

グリッドの行と列の間のギャップは、gutter(みぞ)やalley(通路)として知られています。ギャップのサイズは、column-gapとrow-gapプロパティを使って行と列で別々に調整できます。さらに、gapと呼ばれるショートハンドプロパティを使って、row-gapとcolumn-gapの両方を設定することもできます。

最初のグリッドのまとめ

グリッドを作ってみたことで、CSS Gridで要素のレイアウトをコントロールするのがいかに簡単かが見え始めてきたはずです。CSS Gridが一般的なレイアウトの問題をどう解決できるかも実感できるかもしれません。次のいくつかのレッスンでは、要素の位置指定と高度なグリッド属性を扱います。しかしその前に、グリッドの基本をより詳しく扱った以下のリンクをチェックしてみてください。
