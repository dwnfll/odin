イントロダクション

CSSでサイズを定義するために使用できる、さまざまな単位がたくさんあります。このレッスンでは、最も重要なものを紹介し、残りのものについてどこで学べるかを示します。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • 相対単位と絶対単位の違いを学びます。
  • さまざまな単位をいつ使うのが適切かを学びます。

絶対単位

絶対単位とは、どんな文脈でも常に同じであるものです。pxは絶対単位です。なぜなら、ピクセルのサイズはページ上の他の何とも相対的に変化しないからです。実際、ウェブプロジェクトで使用すべき絶対単位はpxだけです。それ以外の単位は、in(インチ)やcm(センチメートル)のような物理的な単位に関連しているため、印刷の設定においてより意味を成します。

相対単位

相対単位とは、その文脈に基づいて変化し得る単位です。あなたが出会い、使いたいと思うことになりそうなものがいくつかあります。

emとrem

emとremはどちらもフォントサイズを指しますが、CSSでは他のサイズを定義するためによく使われます。どちらもよく見かけることになるので両方を説明しますが、経験則としてはremを優先してください。

1emは要素のfont-sizeです(あるいは、font-sizeを設定するために使っている場合は、その要素の親のfont-sizeです)。例えば、ある要素のfont-sizeが16pxの場合、その幅を4emに設定すると、幅は64pxになります(16 * 4 == 64)。

1remはルート要素(:rootまたはhtml)のfont-sizeです。計算方法はemのときと同じようにremでも機能しますが、親のフォントサイズを追跡するという追加の複雑さがありません。emに頼ると、文脈が変わった場合に特定のサイズが変わってしまう可能性があり、これはおそらくあなたが望む動作ではないでしょう。

ウェブサイト全体でフォントサイズを定義するためにremのような相対サイズを使うことはお勧めされています。多くのブラウザでは、可読性を高めるためにユーザーが基本フォントサイズを変更できるようになっています。可能な限り、フォントサイズに関するユーザーの希望を尊重することが望ましいです。これについては、課題の読み物でさらに詳しく学びます。

ビューポート単位

vhとvwという単位は、ビューポートのサイズに関連しています。具体的には、1vhはビューポートの高さの1%に等しく、1vwはビューポートの幅の1%に等しくなります。これらは、何かをビューポートに対して相対的なサイズにしたいときにいつでも役立ちます。例えば、全高のヒーローセクションや、アプリのような全画面インターフェースなどです。

たくさんの単位!

CSSで利用可能なすべての異なる単位を調べてみると、長さの単位だけでも、とんでもない数があることが分かります。どれをいつ使えばよいのか、どうやって分かるのでしょうか?

どんな状況でどの単位を使うべきかというルールを探そうとしないようにしてください。それぞれの単位は異なることを行うので、他のコードと同じように、何かをどう振る舞わせたいか、どんな指示を書きたいかを考え、それからどの単位がそれに役立ちそうかを調べてください。

あるmarginのサイズを、ルートのフォントサイズに基づかせたい(つまり、それに合わせて拡大縮小させたい)場合があるかもしれません。その場合はremを使うことになります。しかし別のmarginにremを使うのは意味を成さず、実際にはpxの値に固定したい場合もあります。あるいは、このdivの幅を親の半分にしたい場合、50%の幅が意味を成しますが、あちらのdivをビューポートの幅がどうであれその半分にしたい場合は、%は意味を成さずvwが意味を成します。これらをすぐに暗記することにはならないでしょうし、そうすることがあまり役立つわけでもないので、必要なときに調べることを気にしないでください(これはあなたのプログラミングの旅のあらゆることに当てはまります)。
