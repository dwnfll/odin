More Text Styles

日本語訳

← intermediate_html_css

Here we cover some more properties you can use to style text on your websites.

イントロダクション

私たちのFoundationsのレッスンで、すでに少しテキストの操作を行いました。このレッスンでは、テキストを扱う際に使用できる、さらにいくつかの便利なCSSプロパティを扱います。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • ウェブプロジェクトでカスタムフォントを使用する方法を学びます。
  • テキストに関連するさらなるCSSプロパティを学びます。

フォント

Foundationsのレッスンでは、要素のfont-familyを変更する方法を扱いましたが、その時には省いたニュアンスや詳細がいくつかあります。

システムフォントスタック

font-familyプロパティを使ってImpactやTimes New Romanのようなフォントに変更し、それらのフォントがたまたまユーザーのコンピューターにインストールされていない場合、フォールバックフォントが表示されます。フォールバックを定義していない場合、デフォルトのHTMLフォントが使用されますが、これはしばしば多少見苦しいものです。このため、プロジェクトでは多少長いフォントのスタックがリストされているのをよく見かけます。

人気のあるスタックの一つが、CSS Tricksのシステムフォントスタックです。

body {
  font-family: system-ui, "Segoe UI", Roboto, Helvetica, Arial, sans-serif, "Apple Color Emoji", "Segoe UI Emoji", "Segoe UI Symbol";
}

このいくらかばかげたfont-familyの文字列の目的は、システムのユーザーインターフェースのデフォルトフォントを使おうとすることです。システムにインストールされているものが見つかるまで、それらのフォントを一つずつ試していき、それを使用します。このようなスタックを使うことで、特にある程度「ニュートラル」なフォントスタイルを目指している場合、心地よい結果が得られることがよくあります。

ウェブフォント

ユーザーのデバイスで利用できないフォントを使いたい場合、フォントライブラリか、あなたのサイト上のアセットのいずれかの、オンラインのソースからフォントをインポートする必要があります。どちらの方法も、フォントをインポートし、あなたのCSSのfont-familyプロパティでアクセスできるようにします。

フォールバックフォントを追加することが重要であることを心に留めておいてください。外部APIにリンクしている場合、URLが変わらない保証も、外部APIがいつか停止しない保証もありません。妥当なフォールバックを用意しておくことで、何か問題が起きても、少なくともあなたのサイトが完全に壊れて見えることはなくなります。

インポートされたファイルを使用することには、パフォーマンス上の問題があり、これについては課題でさらに詳しく読みます。そのため、デザインが許すのであれば、インポートされたフォントの代わりにフォントスタックを使うのが最善です。しかし、インポートされたフォントを使いたい場合もあります。

オンラインフォントライブラリ

ユーザーのデバイスにインストールされていないフォントを入手するための、人気があり簡単な方法の一つは、オンラインフォントライブラリを使うことです。

これらのライブラリの一つからフォントを使うには、ウェブサイトに行き、フォントを選択し、それからそのサーバーからあなたのウェブサイトへそのフォントをインポートするためのコードの断片を、そのウェブサイトからコピーします。次のような<link>タグをHTMLに入れるよう指示されるか……

<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Roboto&display=swap" rel="stylesheet">

……あるいは、CSSファイルの先頭に入れられる@importタグが与えられます。

@import url('https://fonts.googleapis.com/css2?family=Roboto&display=swap');

一般的なオンラインフォントライブラリには、Font Library、Font Bunny、Google Fontsなどがあります(これらに限定されるわけではありません)。

しかし、フォントライブラリを使用する際の重要な考慮事項は、そのライブラリのプライバシーポリシーと、あなたが遵守する必要があるかもしれない規制です。例えば、Google Fonts APIの使用は欧州のGDPRに違反します。そのような規制の遵守が心配な場合は、ライブラリからフォントをダウンロードして自分でホストすることができます。

セルフホストフォント

ウェブからダウンロードしたフォントを使用することも可能です。CSSファイルで、@font-faceルールを使ってカスタムフォントをインポートし定義し、それから他のfont-familyと同じように使用します。フォントファイル形式には複数の種類があり、fileinfo.comのFont File Formatsのページでそれらについてさらに詳しく読むことができます。ただし、一部のフォントファイル形式はブラウザで普遍的にサポートされているわけではないので、選ぶ際は注意してください。ブラウザとそれらがサポートするフォント形式の一覧は、W3SchoolsのCSS Web Fontsのページにあります。

@font-face {
  font-family: my-cool-font;
  src: url(../fonts/the-font-file.woff);
}

h1 {
  font-family: my-cool-font, sans-serif;
}

この方法はサードパーティのフォントAPIに頼るよりも信頼性が高いかもしれませんが、常にフォールバックを含めておくのが賢明です。

テキストスタイル

Foundationsのレッスンでフォントを操作する基本を学びましたが、テキストスタイルの操作に関しては、CSSでできることがまだたくさんあります。これらのルールはどれも比較的シンプルで自明です。疑問があれば、ドキュメントを参照してください。

font-style

通常、フォントを斜体にするために使用されます。斜体フォントを使用するHTMLの<em>タグについて学びましたが、<em>はまた、それが囲むテキストが重要であること、あるいは何らかの形で強調されるべきであることも示します。従うべき良い経験則は、単にテキストを斜体(あるいは太字、下線、ハイライトなど)にしたいだけならCSSプロパティを使うということです。そうでなく、テキストに何らかの意味的な強調を持たせるべきなら、正しいHTML要素を使ってください。

例えば、すべての見出しのテキストを斜体にしたい場合は、それを達成するためにfont-styleを使うべきです。文の途中の一部のテキストを強調するために斜体で表示したい場合は、em要素を使うのが適切です。Emphasis要素についてのMDNドキュメントは、上記の私たちの論点を強調しています。

スタイリングの目的で斜体が必要な場合は、font-style: italic;を使用すべきです。

h1 {
  font-style: italic;
}

強調のために斜体が必要な場合は、em要素を使用すべきです。

<p>I <em>never</em> said he stole your money</p>
<p>I never said <em>he</em> stole your money</p>
<p>I never said he stole <em>your</em> money</p>

letter-spacing

letter-spacingは、想像通りのことをします……単語内の文字間のスペースを変更します。これは、スペースが多すぎる、あるいは少なすぎると感じるカスタムフォントを調整するのに役立ちます。また、見出しなど、場合によっては美的に心地よいこともあります。

See the Pen Letter Spacing | CSS Text Styles by TheOdinProject (@TheOdinProjectExamples) on CodePen.

言うまでもなく、これは控えめに、注意して使用してください。サイトを読みにくくしないでください!

line-height

line-heightは、折り返されたテキストの行間のスペースを調整します。少しline-heightを加えることで、可読性を高めることができます。

See the Pen Line Height | CSS Text Styles by TheOdinProject (@TheOdinProjectExamples) on CodePen.

text-transform

text-transformは、与えられたテキストの大文字・小文字を変更します。例えば、これを使って見出しタグをすべて大文字にしたり、すべての単語の先頭を大文字にしたりできます。

使い方は、これらのMDN web docsにある分かりやすい例で見ることができます。

text-shadow

想像通り、text-shadowは選択した要素内のテキストの周りに影を追加します。これは控えめに使うのが最善ですが、見出しやその他の装飾的なテキストで非常に効果的に使用できます。

text-shadowについてのMDNリファレンスページの例が、その使い方を示しています。

ellipsis(省略記号)

これは単一のプロパティではありませんが、ツールボックスに入れておくと便利なテクニックです。text-overflowプロパティを使うと、はみ出したテキストを省略記号で切り詰めることができます。しかし、オーバーフローを発生させるには、他にいくつかのプロパティを使う必要があります。なぜなら、コンテナの外にテキストが表示されるデフォルトの動作は、技術的にはoverflowとはみなされないからです(分かりにくいですよね。すみません。)

完全なコードの断片は次の通りです:

.overflowing {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

詳細と例は、このellipsisオーバーフローについてのCSS Tricksの記事で見ることができます。(これを使いたいと思うたびに、その記事を調べに行く準備をしておいてください。)
