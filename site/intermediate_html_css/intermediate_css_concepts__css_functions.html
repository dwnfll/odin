CSS Functions 日本語訳

Learn the function syntax, and some useful ways you can do calculations in CSS.

イントロダクション

CSSで扱ったことのあるプロパティの値の中には、少し違った構文を持つものがあることに気づいたかもしれません。値が、情報を含む一対の括弧()が続く単語である場合 - background-color: rgb(0, 0, 0)のように - それはCSS関数を使っていることになります。

このレッスンでは、関数とは何かの基本と、CSSでそれらがどのように一般的に使われるかを扱います。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • CSS関数の基本的な構成要素を認識します。
  • calc()、min()、max()、clamp()関数について、それぞれの使い方を学びます。

関数とは何で、CSSでどう使われるのか?

プログラミング言語と同様に、CSSの関数は特定のタスクを実行する再利用可能なコードの断片です。関数には括弧の間に「引数」が渡され、それぞれが関数によって特定の方法で使用されます。いくつかの一般的な例は次の通りです:

color: rgb(0, 42, 255);
background: linear-gradient(90deg, blue, red);

ここで、colorの値は関数rgb()であり、これは数値の形式で引数を受け取ります。それらの数値を処理して、与えられた3つの値に対応するrgbカラーを計算します。同様に、backgroundプロパティはlinear-gradient(90deg, blue, red)という値を持ちます。linear-gradientは、与えられたパラメータを使ってグラデーション画像を生成します。少なくとも2つの色の引数、つまり間を遷移させる色が必要です。さらに、(例で行ったように)グラデーションラインの方向の角度を設定したり、さらに色の値を追加したりすることもできます。

TOPで使うプログラミング言語とは異なり、CSSでは自分自身の関数を作成することはできません。その代わり、この言語には、最も一般的なスタイリングの問題を解決するのに役立つ、あらかじめ用意された関数のリストが同梱されています。

色を定義すること以外にも、ウェブサイトのレイアウトやサイズ調整をデザインする際に役立つ、いくつかのCSS関数があります。これらは、レスポンシブデザインについて考える際に重要になります。

これらの関数のいくつかを見ていきましょう: calc()、min()、max()、そしてclamp()です。

calc()

calcの最も強力な使用例には、次のようなものがあります:

  • 単位の混在
  • calc( calc () - calc () )のようにネストできる能力

See the Pen calc() | CSS Functions by TheOdinProject (@TheOdinProjectExamples) on CodePen.

calc()がここでどう使われているか見てみましょう:

:root {
--header: 3rem;
--footer: 40px;
--main: calc(100vh - calc(var(--header) + var(--footer)));
}
  • --header、--footer、--mainはすべてCSS変数の例です。これらについては次のレッスンで学びます。

mainを、次の結果と等しく設定しています: 100vh - (3rem + 40px)。 別の言い方をすると: main = 100vh - (header + footer)。 vh、rem、pxの単位を混在させているにもかかわらず、calc()が計算を代わりに処理してくれています。 CSS変数と組み合わせることで、calc()はCSSルールを繰り返す頭痛の種から私たちを救ってくれます。

上記のCodePenの埋め込みでcalc()がどう使われているかを把握できるはずです。先に進む前に、要素のさまざまな単位やサイズをいろいろ試して、どんな結果が得られるか見てみることをお勧めします。

calc()の例

上記はcalc()がレイアウトにどう影響するかの単なる一例に過ぎませんが、calc()がそれを行うための最善の方法とは限らないことを覚えておいてください。レイアウトについては今後のレッスンでさらに詳しく話します。

min()

min()は、レスポンシブなウェブサイトを作成する上で優れた働きをしてくれます。この例を見てみましょう:

See the Pen min() | CSS Functions by TheOdinProject (@TheOdinProjectExamples) on CodePen. 

#iconHolder {
  width: min(150px, 100%);
  height: min(150px, 100%);
  box-sizing: border-box;
  border: 6px solid blue;
}

min()関数は、JavaScriptのMath.min()やRubyのArray#minメソッドと同じように機能します。カンマで区切られた値のリストを受け取り、その中で最も小さいものを返します。

これは、親要素の幅の100%が150pxより小さいかどうかをチェックします。もし100%が150pxより狭くなる場合、その要素はコンテナの幅いっぱい(100%)を占めます。そうでなければ、幅は150pxになります。

min()の中で基本的な計算を行うこともできます。例えば、width: min(80ch, 100vw - 2rem);のように(この場合、calc()すら必要ありません)。

max()

max()はmin()と同じように機能しますが、逆方向であり、JavaScriptのMath.max()やRubyのArray#maxメソッドに似ています。括弧の中から可能な限り最大の値を選択します。

width: max(100px, 4em, 50%);

上記は3つの値をすべて比較し、要素の幅をそのうち最も大きいものに設定します。もし親コンテナの50%が100pxと4emより大きい場合、幅は50%になります。もし4emが他より大きければ、4emが使われます。

max関数は、表示ウィンドウが非常に小さい場合や、ユーザーがブラウザのズーム機能を使ってコンテンツのサイズを大きくした場合に最も役立ちます。 最初はmaxをあまり使う機会がないかもしれませんが、アクセシビリティが重要なプロジェクトのために知っておくべき良いツールです。

clamp()

clamp()は、要素を流動的でレスポンシブにする素晴らしい方法です。 clamp()は3つの値を取ります:

h1 {
  font-size: clamp(1.5rem, 5vw, 3rem);
}
  1. 最小値1.5rem
  2. スケーリング値5vw
  3. 最大値3rem

clamp() CSS関数は、これらの値を使って最小値、スケーリング値、最大値を設定します。上記の例では、これは許容される最小のfont-sizeが1.5remで、最大が3remになることを意味します。

その間には5vwのfont-sizeが設定されます。値5vwは、ビューポートの幅に応じてfont-sizeをスケーリングできるようにしますが、そのサイズは設定した最小値と最大値によって制限されます。
