Getting Started

日本語訳

← nodeJS

You'll go through a basic Node tutorial and write some real server-side code.

イントロダクション

イントロダクションのレッスンで学んだように、Node.jsは実質的にJavaScriptに過ぎません。そのため、Nodeを理解するには、JavaScriptについての基本的な理解が必要です。この理由から、このコースを続ける前に、前提条件であるJavaScriptコースを受講することを強くお勧めします。

このレッスンでは、Node.jsを使い始めて動かすために必要な、基本的なモジュールと関数を教えてくれるチュートリアルに沿って進めていきます。このセクションの最後にあるプロジェクトでは、Nodeを使って、Index、About、Contact Meページを含む基本的なウェブサイトを作成することになります。そのため、このレッスンでトピックを学びながら、プロジェクトを完成させるのに役立ちそうなものにも注意を払っておいてください。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • Node.jsが一般的に何のために使われるかを説明する。
  • Node.jsでモジュール(組み込みのものとユーザーが作成したものの両方)を作成し使う。
  • HTTPモジュールを使って、Node.jsで基本的なウェブサーバーをセットアップする。
  • Node.jsからファイルを読み込み、作成し、更新し、削除する。
  • URLモジュールを使って、URLアドレスをパースし、読みやすい部分に分割する。
  • NPMの使い方を理解する。
  • 自分自身のイベントを作成し、発火させ、リッスンする。

重要な注意事項

最近、NodeJS.devのチームは、そのウェブサイトから大量のコンテンツを削除しました。削除されたページのいくつかは、このレッスンでリンクされていました。そのコンテンツの代わりが見つかるまでは、彼らのGitHubリポジトリ上のMarkdownファイルに直接リンクします。フォーマットは少し奇妙に見えるかもしれませんが、内容は変わらず優れたものであるはずです。

早速、Nodeのサーバーサイドのコードを見ていきましょう!これからNodeJS.orgのドキュメントのレッスンをあちこち見て回るので、それに沿って進めてください。

  1. ターミナルからNode.jsのスクリプトを実行する方法を学んでください。
  2. HTTP Module
    • NodeでHTTPリクエストを行う方法を学んでください。
    • NodeのhttpモジュールのDocsをチェックしてください。特に、http.createServerをチェックしてください。ドキュメントには、それが受け取れるオプションのパラメータが示されており、使うかどうかはあなた次第です。今のところは、createServerメソッドが、リクエストを受け取るたびに実行されるハンドラを受け付けるHTTPサーバーを作成する、ということだけを知っておけば十分です。
  3. File System
    • まず、Nodeでファイルを扱う際に頻繁に使うfsモジュールを見てみましょう。
    • それから、Nodeでファイルを書き込むことを始めましょう。
    • 最後に、Nodeでファイルを読み込む方法を学びます。
  4. The URL Class
    • このURLクラスについてのドキュメントをチェックしてください。コードのサンプルをいろいろ試して、それがどう機能するか見てみてください!
  5. Events
    • Event Emitterのセクションに沿って進めてください。
    • Nodeのeventsモジュールを調べてみてください。
