Mini Message Board

日本語訳

← nodeJS

We take a break from the main tutorial and create a simple message board.

イントロダクション

ここまで来れば、Expressを使って楽しいインタラクティブなウェブアプリを作るのに十分な知識が身についているはずです!メッセージボードを作っていきましょう。

課題

  1. ExpressとEJSをインストールして、基本的なExpressアプリをセットアップしてください。基本的なindexルートをセットアップし、サーバーを実行してください。前のレッスンで説明した通りに、必要なフォルダとファイルを作成してください。
  2. index("/")と「新しいメッセージ」フォーム("/new")の、2つのルートを用意します。

  3. indexルーターの一番上にmessagesという配列を作成し、その中に以下のようないくつかのサンプルメッセージを入れてください:

    const messages = [
  {
    text: "Hi there!",
    user: "Amando",
    added: new Date()
  },
  {
    text: "Hello World!",
    user: "Charles",
    added: new Date()
  }
];

  4. 次に、("views"フォルダの中にある)indexテンプレートの中で、messages配列をループし、それぞれについてユーザー、テキスト、メッセージが追加された日付を表示してください。res.renderの「locals」オブジェクトに含めることで、メッセージをテンプレートで使えるようにするのを忘れないでください(例えばres.render("index", { title: "Mini Messageboard", messages: messages }))。

  5. 次に、新しいメッセージ用のフォームをセットアップしましょう。ルーターの中に、"/new"ルート用のrouter.get()を追加し、"form"という名前のテンプレートを指すようにしてください。viewsディレクトリの中にformテンプレートを作成してください。見出し、2つの入力欄(投稿者名用とメッセージテキスト用)、そして送信ボタンを追加してください。フォームにネットワークリクエストを送らせるためには、以下のようにmethodとactionの両方を指定してフォームを定義する必要があります(フォームの扱い方については後のレッスンで学びます):

    <form method="POST" action="/new">
   put your inputs and buttons in here!
</form>

  6. このようにフォームをセットアップすると、送信ボタンをクリックしたときに、action属性で指定されたURLへPOSTリクエストが送信されるはずです。そこで、indexルーターに戻り、"/new"用のrouter.post()を追加してください。

  7. フォームからのデータを取得して使うためには、router.post()の中で、req.bodyというオブジェクトとしてフォームの内容にアクセスする必要があります。body オブジェクトの中の個々のフィールドは、入力欄のname属性に従って名付けられます(<input name="messageText">の値は、router.post関数の中ではreq.body.messageTextとして現れます)。これが意図した通りに動作するためには、フォームデータをreq.bodyに解析するための、express.urlencoded()というアプリケーションレベルのExpressミドルウェアを使う必要があります。これは、アプリのセットアップに以下の行を追加することでセットアップできます:

    app.use(express.urlencoded({ extended: true }));

  8. router.post()の中で、フォーム送信の内容を受け取り、以下のようなオブジェクトとしてmessages配列にpushしてください:

    messages.push({ text: messageText, user: messageUser, added: new Date() });

  9. router.post()関数の最後で、res.redirect("/")を使って、新しいメッセージを送信した後にユーザーをindexページへ送り返してください。

  10. ここまでできれば、/newにアクセスし(indexページにそのルートへのリンクを追加しておくとよいでしょう)、フォームに記入して送信すると、それがindexページに表示されるようになるはずです!
  11. メッセージの詳細を表示する新しいページを開くための「open」ボタンまたはリンクを、それぞれのメッセージの横に追加してください。
  12. プロジェクトをGitHubにプッシュしてください。
  13. アプリをウェブにデプロイする方法は次のレッスンで学びます。完了したら、忘れずに戻ってきて、以下の提出欄に提出してください!
