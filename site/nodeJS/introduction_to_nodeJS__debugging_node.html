Debugging Node

日本語訳

← nodeJS

You'll learn how to effectively debug NodeJS code.

イントロダクション

ここまでは、コードをデバッグするためにブラウザのDevToolsだけに頼ってきたかもしれません。Nodeやサーバーサイドのコードをデバッグするとなると、VS Codeには便利な組み込みのデバッガーがあり、これを使ってエディタの中で直接デバッグできます!カリキュラムの前の部分ですでにこれを使ったことがあることを願っていますが、いずれにせよ、このレッスンでは、VS CodeのNodeデバッガーに慣れ親しんでもらいます。これは、あなたの学習のこの時点において重要なツールであり、おそらく実務生活の中でも毎日使う主要なツールになるでしょう。

レッスン概要

このセクションでは、このレッスンで学ぶトピックの概要を説明します。

  • VS Codeの組み込みNodeデバッガーを使う。

課題

  1. このVS CodeでのNode.jsのデバッグについての動画チュートリアルを見て、そのプロセスを実際に確認してください。
  2. 公式のVS Code Nodeデバッガーのドキュメントをチェックしてください。JavaScript Debug Terminalに注目してください。これは、デバッガーを簡単に動かす方法です!
