Installing PostgreSQL

日本語訳

← nodeJS

How to install PostgreSQL on a local machine.

イントロダクション

データの永続化は、ウェブアプリケーションの大多数にとって不可欠なものです。データの永続化は、データベースを通じて実現されます。自分のデータベースをどう構造化し、構築し、クエリするかを理解できることは、あらゆるフルスタック開発者にとって重要なスキルです。

例えば、The Odin Projectについて考えてみてください。あなたのユーザー名はどこに保存されているのでしょうか?プロジェクトの提出物はどこに保存されているのでしょうか?今まさにあなたが読んでいる、このレッスンのコンテンツはどこに保存されているのでしょうか?そう、データベースです!

私たちはカリキュラムのデータベースとしてPostgreSQLを選びました。以前のコースで学んだSQLの知識はすべて、PostgreSQLにそのまま応用できるはずです。また、PostgreSQL特有の新しいことも学んでいきます。Fireshipによるこの楽しくて短いPostgreSQLの入門動画を見てみてください。

このレッスンではPostgreSQLをインストールし、次のレッスンでは、それをExpressアプリケーションの中でどう使うかを学びます。

PostgreSQLシェル

SQLコースを完了してください

必ずSQLコースを完了しておいてください。

このレッスンおよびそれ以降のすべてのレッスンは、あなたがSQLの構文と概念を理解していることを前提としています。

psqlとしても知られるPostgreSQLシェルは、ユーザーがSQLクエリを対話的に実行し、データベースを管理できるようにする、PostgreSQL用のターミナルベースのフロントエンドです。

これは通常PostgreSQLのインストールに含まれており、コマンドラインからアクセスできます。その範囲には、クエリの実行、データベース構造の作成や変更、コマンドライン環境でのデータベースとの対話が含まれており、psqlはスクリプトの記述やさまざまなタスクの自動化を容易にするための、多くのメタコマンドやシェルライクな機能を提供しています。

psqlターミナルが使うデータベースは、ファイルシステムやローカルマシンの内部にあります。というのも、PostgreSQLはデータベースをファイルシステム内の通常のファイルとして保存するからです。データディレクトリのデフォルトの場所は、オペレーティングシステムによって異なる場合があります。
