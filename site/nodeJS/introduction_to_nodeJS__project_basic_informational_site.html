Basic Informational Site

日本語訳

← nodeJS

Use what you've learned to build a very simple website skeleton

イントロダクション

ここまでで、そこそこ危険なくらいには知識が身についているはずです。学ぶべきことは間違いなくまだまだありますが、実際に何かを作れるくらいには、すでにNodeについて十分知っています!では、やってみましょう!index、about、contact-me、404という4つのページを含む、非常に基本的な情報サイトを作成することになります。これらのページの内容自体は、それほど重要ではないことを覚えておいてください。そのため、それらを埋めたり、見た目をきれいにしたりすることに、多くの時間をかける必要はありません。

もし途中で行き詰まったら、遠慮なくGetting Startedのレッスンに戻ってください。

課題

  1. プロジェクトディレクトリを作成し、そのディレクトリの中に以下のファイルを作成してください:

    • index.html
    • about.html
    • contact-me.html
    • 404.html

  2. node.jsのサーバーファイルindex.jsを作成し、URLに応じて正しいページを提供するために必要なコードを追加してください。

    • localhost:8080は、ユーザーをindex.htmlに導く必要があります
    • localhost:8080/aboutは、ユーザーをabout.htmlに導く必要があります
    • localhost:8080/contact-meは、ユーザーをcontact-me.htmlに導く必要があります
    • 404.htmlは、ユーザーが上記に記載されていないページにアクセスしようとしたときは常に、表示される必要があります。
