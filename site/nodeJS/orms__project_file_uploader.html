File Uploader

日本語訳

File uploader project

イントロダクション

このプロジェクトでは、Google Drive(あるいは他の個人向けストレージサービス)の簡略版を構築していきます。

課題

  1. ExpressとPrismaを使って、新しいプロジェクトをセットアップしてください。Passportなど、必要なすべての依存関係をインストールしてください。
  2. Passport.jsを使って、セッションベースの認証をセットアップしてください。セッションをデータベースに永続化するために、Prisma session storeライブラリを使ってください。
  3. 認証されたユーザーがファイルをアップロードできるフォームを追加してください。今のところ、ファイルはあなたのファイルシステムに保存してください。multerミドルウェアを統合する必要があります。他のすべての機能が動くようになったら、これらのファイルをアップロードするようにします。
  4. フォルダを追加してください。ユーザーはフォルダをCRUDし、その中にファイルをアップロードできるべきです。そのために必要なルートとデータベースのやり取りをセットアップしてください。
  5. 名前、サイズ、アップロード日時といった、特定のファイルの詳細を表示するルートを追加してください。ユーザーがファイルをダウンロードできるように、ダウンロードボタンがあるべきです。
  6. 最後に、ファイルをアップロードするロジックを追加してください。データベースに保存することもできますが、このユースケースにはクラウドストレージサービスを使うことをおすすめします。CloudinaryやSupabase storageを使うことができます。ファイルがアップロードされたら、そのファイルのURLをデータベースに保存してください。
  7. ファイルをバリデーションしてください!どのように行うかはあなた次第です。アップロードできるファイルの種類を制限したり、大きすぎるファイルを制限したりできます。

発展課題

  • フォルダ共有機能を追加してください。ユーザーがフォルダ(とそのすべての中身)を共有したいとき、期間(1日、10日など)を指定するフォームがあるべきです。これにより、誰とでも(認証されていないユーザーとでも)共有できるリンクが生成されるべきです。例えば、そのリンクは以下のような形式になります: https://yourapp.com/share/c758c495-0705-44c6-8bab-6635fd12cf81
